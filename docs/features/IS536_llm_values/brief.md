# IS536 | Бриф: лексемы-кандидаты через нейронку, v2

Ишью #536, ветка `IS536_llm_values` от `master`. Решения —
`decisions.md`, техника — `plan-backend.md` и `plan-app.md`.

## Этапы

Бэкенд уезжает в прод по этапам, мобилка — одним релизом после всей
фичи. У этапа свой ишью и ветка от `IS536_llm_values` с PR обратно в
неё; документы общие, у планов — раздел на этап.

1. **IS537 — леммы из текста.** Бэкенд: операция `lemmas/from-tokens`
   с «Языками», прокладкой лимитов и аккаунтом; `words/lookup` как
   есть. Телефон: снимок → перевод и три списка, «не разобрано»,
   пометка «в словаре»; без тапа по слову и значений.
2. **Значения по тапу.** Бэкенд: операция `lexemes/from-lemma` вместо
   `words/lookup`. Телефон: карточка под словом, правка, слово «в
   словаре» с «Проверить по тексту», добавление по одному слову с
   уходом из списка, вопрос при закрытии; запрос из карточки слова
   леммой. Без замены сохранённой лексемы присланной — отложено.
   Ишью — когда закроется первый.

## Цель

Юзер снимает текст и через несколько секунд видит его слова в словарной
форме: смысловые, имена и служебные — отдельными списками. Значения слова
грузятся только по тапу и выбираются по тексту — не надо полминуты
ждать, пока нейронка разберёт каждое слово, включая with, the, of.
Добавлять в словарь можно по одному слову, сразу или позже. Слово, которое
уже есть в словаре, показывает свои сохранённые значения и по кнопке
проверяет, то ли значение в этом тексте.

## Сценарий

1. Юзер снимает текст.
2. Через несколько секунд видит перевод текста свёрнутым блоком и слова
   текста в словарной форме тремя списками: смысловые, имена, служебные.
   Слова, которые уже есть в словаре, помечены.
3. Тапает слово и видит его значения, выбранные по тексту и разложенные
   по компонентам словаря. Значение из текста помечено «в тексте».
4. Нажимает «Добавить» — слово в словаре и ушло из списка. Или
   «Удалить» — слово уходит из списка без записи. Можно тапать другие
   слова и добавлять позже.
5. У слова из словаря по тапу видны его сохранённые значения. «Проверить
   по тексту» показывает значения по тексту: совпавшие помечены «уже в
   словаре», другие можно добавить или заменить ими сохранённое.
6. Закрывает окно. Если остались загруженные, но не добавленные слова,
   видит предупреждение.

## Границы

Входит:

- извлечение словарных форм одним вызовом нейронки: перевод текста и
  словарные формы его слов, один к одному, без повторов, тремя списками
  — смысловые, имена собственные, служебные; названия из нескольких слов
  разбиваются на слова; своих списков служебных слов на сервере нет
- словарная форма — как в словаре: снимается только словоизменение —
  число, 's, время и лицо, причастие в роли глагола, степень сравнения,
  род; словообразование и часть речи не трогаются; строчные, кроме имён;
  ошибки распознавания исправлены; лемма — по тексту
- карточка под словом по тапу на любое слово: словарная форма ищется в
  базе, значения только из Викисловаря языка перевода, отбор по тексту,
  пометка «в тексте», порядок «перевод, определение, часть речи, род,
  примеры», лексемы выглядят как в карточке слова; «Замечания» и
  «Сопоставление» — в карточке под словом
- добавление по одному слову: «Удалить» у любого слова списка,
  добавленное слово уходит из списка, при закрытии окна —
  предупреждение; общей кнопки «Добавить» нет
- слово из словаря: пометка, сохранённые значения без сервера,
  «Проверить по тексту»; перевод сравнивает приложение; у нового
  значения выбор «добавить» или «заменить» сохранённое, пишет одна
  «Добавить» у слова, замена сохраняет лексему и статистику квизов
- лимит: пока прокладка без логики — операция зовёт «начать работу» и
  «закончить работу», ответ всегда «можно», ничего не списывается; работа
  — извлечение, значения по тапу, проверка по тексту; предел слов на
  извлечение и на запрос значений; лимит токенов нейронки остаётся
- слово, которому нейронка не дала пары, и обрывки уходят в «не
  разобрано», юзер их видит; извлечение не удалось — ошибка и повтор;
  словарной формы нет в базе — «не найдено»
- язык, которого нет в базе: отказ сразу, и на снимке тоже, а сервер
  ведёт учёт таких языков — какой и сколько раз просили

Не входит:

- языки перевода без своего Викисловаря в базе
- кнопка словаря в карточке слова — остаётся как в v1
- проверка сохранённых значений без нажатия — риск на юзере

## Разрез

Бэкенд:

- запрос извлечения словарных форм: перевод текста и три списка, правила
  формы — в промпте и схеме
- значения слова — нынешний поиск по одному слову с текстом и переводом
  из извлечения
- контракт лимитов в работах без логики списания, предел слов на
  извлечение и на запрос значений
- отказ по языку на извлечении, учёт таких языков и задача его просмотра
  на сервере
- спеки LFT, LFL, TFP, сервисные ACC и LIM, контракт

Приложение:

- экран после снимка: перевод, три списка слов, пометка «в словаре»,
  добавленное слово уходит из списка
- карточка под словом по тапу: загрузка и ошибка на слове, «в тексте»,
  порядок компонентов, вид как в карточке слова, «Добавить» и «Удалить»
- слово из словаря: сохранённые значения, «Проверить по тексту», выбор
  «добавить» или «заменить» у нового значения
- предупреждение при закрытии
- запрос из карточки слова уходит леммой, на экране всё как в v1
- спеки AWP и WCL

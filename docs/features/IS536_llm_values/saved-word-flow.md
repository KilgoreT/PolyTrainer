# Слово «в словаре» в окне снимка — черновик флоу

> [!NOTE]
> Черновик для согласования, не спека и не HLD. Согласован 2026-10-29,
> открытых вопросов нет; тогда же перенесён в спеку AWP v3 (флоу Ш6–Ш10,
> тезисы, решения Д122–Д131), HLD `hld-awp.md` «Этап 3», план Э11–Э12 и
> код. Дальше правится спека, этот документ — история обсуждения.

## Пример

- Словарь en → ru, в нём слово «sister» с одним значением:
  «Перевод: медсестра».
- Снимок абзаца. В списке «Смысловые» есть «sister» с пометкой
  «в словаре».

## Шаги

### 1. Тап по слову

- Тап по «sister» раскрывает под ним то, что уже лежит в словаре. На
  сервер ничего не уходит.
- Повторный тап сворачивает всё под словом, плашки словаря и плашки
  нейронки; следующий тап раскрывает как было, без нового запроса.

### 2. Плашки словаря

- Под словом по плашке на каждое слово словаря с этим текстом: одно
  «sister» — одна плашка, два — две.
- В плашке: группа слова или «Все», дата добавления, лексемы слова —
  здесь «Перевод: медсестра».
- Слово написано один раз, заголовком над плашками; плашки различаются
  группой и датой. Станет неудобно — добавим слово в каждую.
- Слово в словаре без лексем — плашка пустая: группа и дата, значений
  нет. Проверка принесёт лексемы-кандидаты, и выбор тот же: в это пустое
  слово или в новое.
- Под плашками две кнопки: «Проверить по тексту» и «Убрать из списка».
  Вторая убирает слово из списка снимка, словарь не трогает.
  - Решено 2026-10-29: кнопка запроса остаётся «Проверить по тексту»
    (перебрали двадцать вариантов, «Из контекста» отменено); кнопка
    уборки слова — «Убрать из списка», пока так (было «Удалить»,
    читалось как удаление из словаря).
- Выбора «куда класть» на этом шаге нет.

### 3. Проверка по тексту

- «Проверить по тексту» шлёт на сервер лемму слова с исправленным текстом
  снимка и переводом — так же, как для нового слова.
- Пока сервер думает — признак загрузки под плашками словаря, плашки на
  месте.

### 4. Плашки нейронки

- Ниже плашек словаря появляются плашки с ответа сервера: по плашке на
  каждую лексему-кандидата, например «Перевод: сестра».
- Та лексема-кандидат, которую сервер счёл употреблённой в тексте снимка,
  помечена «в тексте». Её плашка первая.
- Лексема-кандидат, у которой ядро совпало с сохранённой лексемой любого
  слова словаря с этим текстом, помечена «уже в словаре» и в запись не
  идёт. Выбор в «Куда» на пометку не влияет.
- Правки внутри плашки как у нового слова: удалить значение, править
  текст, сменить опцию.

### 5. Перенос по одной

- У каждой плашки нейронки своё поле «Куда». По умолчанию в нём «новое
  слово». По тапу можно выбрать любое из слов словаря с этим текстом.
  «Новое слово» есть всегда, и при одном слове в словаре.
- Своя группа у плашки есть только при «Куда: новое слово». Запись в
  существующее слово его группы не трогает.
- Кнопка у плашки по выбору: «Перенести» — в выбранное слово, «Создать»
  — в новое слово. Нажал — лексема записана одной транзакцией, плашка
  ушла. Сохранённые лексемы слова не меняются.
- Переносят по одной: выбрал слово для первой, нажал, потом следующую.
  Так всегда, сколько бы лексем ни пришло и есть ли слово в словаре:
  каждая лексема — осознанный выбор.
- «Создать» у первой плашки заводит новое слово. Тут же, без нового
  снимка, над плашками нейронки появляется плашка словаря этого слова с
  перенесённой лексемой. У оставшихся плашек «Куда» само переключается
  на это слово, кнопка становится «Перенести». Смена умолчания на глазах:
  пользователь видит, что слово появилось.
- «Перенести» — лексема тут же видна в плашке словаря выбранного слова.
  Плашки словаря обновляются сразу после каждой записи.
- Не переносить — «Не нужно» у плашки: лексема-кандидат уходит без
  записи (решено 2026-10-29, было «Удалить»).
- Ушла последняя плашка нейронки, перенесённая или ненужная, — слово
  уходит из списка снимка вместе со своими плашками словаря. Плашки
  словаря только для наглядности, на уход слова не влияют.

### Слова нет в словаре

- Тап сразу шлёт запрос, плашек словаря нет. Дальше те же плашки нейронки
  по лексеме: «Создать» у первой заводит слово, у остальных «Куда» само
  становится этим словом, они уходят в него по одной «Перенести». Пока
  слов с этим текстом нет, «Куда» можно не показывать.

## Что меняется против сегодняшнего окна

- **«Куда класть»** — было у карточки с самого раскрытия, станет только у
  плашек нейронки, после проверки. По умолчанию было самое новое слово
  словаря, станет «новое слово».
- **Сохранённые значения** — было только у самого нового слова, станет по
  плашке на каждое слово с этим текстом.
- **Запись** — было «Добавить» у слова, все лексемы-кандидаты разом в
  одно слово; станет по плашке на лексему, у каждой своё «Куда» и своя
  кнопка «Перенести» или «Создать», запись по одной лексеме.
- **Кнопки** — «Проверить по тексту» остаётся, «Удалить» у слова →
  «Убрать из списка», крестик у лексемы-кандидата → «Не нужно».
- **Пометка «уже в словаре»** — было по ядрам выбранного слова, станет по
  всем словам словаря с этим текстом.
- **Своя группа** — была у любой карточки, станет только при «новое
  слово»; подсказка «Слово войдёт в группу … вместе со своими N старыми
  значениями» уходит, существующее слово в группу не кладётся.
- **Плашки словаря живые** — было: леммы словаря читаются один раз при
  сборке окна; станет: после каждой записи плашки словаря под словом
  обновляются сразу, созданное слово появляется тут же. Это же закрывает
  запись бэклога «форма не обновляется после записи слова».
- **Уход слова из списка** — было после «Добавить»; станет когда ушла
  последняя плашка нейронки.

## Решения по ходу обсуждения (2026-10-29)

- Рассмотрена и отклонена модель «адрес у плашки, одна кнопка «Добавить»
  внизу»: быстрее, но без осознанного выбора каждой лексемы.
- Лемма ответа не равна слову списка («children» → «child») — считать
  ошибкой на каком-то этапе, не вариантом экрана; в списках словарные
  формы, тапнуть форму нельзя. Строка спеки AWP-43.7 под вопросом. На
  каком этапе и как показывать — позже.
- Хвосты — «не найдено», ошибки, отказ записи — обсуждаем отдельно, здесь
  только ядро.

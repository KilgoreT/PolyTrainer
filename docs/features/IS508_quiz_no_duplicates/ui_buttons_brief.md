# IS508 / чат-фикс 2 | Кнопки «Показать ответ» и «Пропустить» — в ленту чата

Issue: https://github.com/KilgoreT/PolyTrainer/issues/508 (ветка та же,
`IS508_quiz_no_duplicates` — в ней собираются все фиксы квиз-чата).
Источник: Backlog, «Срочное» → «Квиз-чат: замечания юзера (2026-09-28)»,
пункт «кнопки должны скроллиться вместе с чатом».
Анализ: [ui_buttons_analysis.md](ui_buttons_analysis.md).

## Контекст

Экран чата (`modules/screen/quiz/chat`): `ChatScreen` → `Scaffold` →
`Box(...imePadding())` → `ChatWidget` = `Column { лента (LazyColumn,
weight 1) ; [Row кнопок] ; поле ввода }`. Кнопки «Показать ответ» и
«Пропустить» — отдельный `Row` между лентой и полем ввода, показывается
по флагу `ChatState.showUserActions` (редьюсер: ставит на
`NextQuestion`, снимает на `UserAttempt` / `GetAnswer` / `Skip`).

## Проблема

Кнопки — фиксированная полоса над полем ввода: не прокручиваются с
лентой, при открытии клавиатуры поднимаются вместе с полем ввода
(`imePadding` на контейнере экрана), визуально «прилипли к клавиатуре».

## Требование

1. Кнопки — часть прокручиваемой ленты: уезжают вверх вместе с
   сообщениями, при скролле к ранним сообщениям не висят над полем
   ввода.
2. Поведение показа не меняется: появляются с вопросом, исчезают после
   попытки / «Показать ответ» / «Пропустить», не показываются на финале
   сессии и в сводке.
3. Порядок и подписи кнопок, сообщения `Msg.GetAnswer` / `Msg.Skip` и
   переходы редьюсера — без изменений.

## Не входит

- Автопрокрутка ленты к концу при появлении клавиатуры — отдельный
  пункт Backlog («клавиатура закрывает последние сообщения»); связь
  описана в анализе §6.
- Анимации сообщений, поведение поля ввода при скролле — отдельные
  пункты.

## Решения

- **Р1. Где живут кнопки в ленте** — отдельный элемент списка или
  кнопки внутри сообщения-вопроса. См. анализ §5, решается на триаже.
- **Р2. Внешний вид** — текущие чипы справа или полноширинные кнопки
  сообщения (как на финале сессии). Зависит от Р1.

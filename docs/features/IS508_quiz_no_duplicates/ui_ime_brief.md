# IS508 / чат-фикс 4 | Жест клавиатуры: скролл за конец ленты вытягивает IME, скролл от конца прячет

Issue: https://github.com/KilgoreT/PolyTrainer/issues/508 (ветка
`IS508_quiz_no_duplicates`, все фиксы квиз-чата).
Источник: замечание юзера 2026-09-28 после чат-фикса 3.
Анализ: [ui_ime_analysis.md](ui_ime_analysis.md).

## Контекст

После чат-фикса 3 лента чата — `LazyColumn(reverseLayout = true)`,
конец ленты у поля ввода; экран сжимается на высоту клавиатуры через
`imePadding()` на `Box` в `ChatScreen`. Клавиатура показывается тапом
в поле ввода и прячется кнопкой «назад»; со скроллом ленты она никак
не связана.

## Требование (концепция юзера)

Клавиатура — продолжение ленты:

1. Клавиатура скрыта, лента в конце. Тяну дальше «за конец» (палец
   вверх) — вместо ленты едет клавиатура: выезжает за пальцем.
2. Клавиатура видна. Тяну обратно (палец вниз) — сначала уезжает
   клавиатура (окно чата расширяется), и только потом крутится лента.
3. После отпускания — доанимация в «полностью показана» /
   «полностью скрыта» по положению и скорости.

## Не входит

- Поведение поля ввода при скролле в историю (Backlog «поле ввода
  прячется…») — отдельная фича.
- Android < 11 (API < 30): системный API управления анимацией insets
  недоступен, жест не работает — принимается (minSdk 24, no-op).

## Решения

- **Д1. Реализация — `Modifier.imeNestedScroll()`** (Compose
  foundation-layout, `@ExperimentalLayoutApi`): готовый nested-scroll
  контроллер IME ровно с этой семантикой; официальный сэмпл —
  `Box(imePadding().imeNestedScroll()) { LazyColumn(reverseLayout =
  true) }`, наша связка.
- **Д2. Куда вешать** — на ленту (`ChatMessageWidget`, модификатор
  `LazyColumn`), не на контейнер экрана: клавиатурой управляет только
  скролл ленты, а не внутренний скролл многострочного поля ввода. См.
  анализ §4.
- **Д3. Фокус** — система показывает IME жестом только при
  сфокусированном поле; наше поле само запрашивает фокус при появлении
  (после «Начать») и держит его всю сессию. Дополнительных запросов
  фокуса не делаем; если фокуса нет — жест молча бездействует
  (анализ §3). Проверяется M8.

## Словарь логов

Снимать: `adb logcat -d | grep -E "###CHAT###"`.
Очистка перед кейсом: `adb logcat -c`.

### Сборка порции (`###CHAT###`)

- `getRandomWriteQuizList: groupFilter=<id|all>` — групповой фильтр
  IS500 (существующий).
- `getRandomWriteQuizList: portion grades=<n> earliest=+<a>/<cand>
  errors=+<b>/<cand> total=<t> words=<w>` — состав порции сессии:
  - `grades=` — сколько дали корзины + добор (≤ `limit` = 10);
  - `earliest=+a/cand` / `errors=+b/cand` — сколько добавка реально
    добавила из скольких кандидатов; `+0/5` = все кандидаты уже в
    порции (Д3, норма); `+0/0` = включена, кандидатов нет; опция
    выключена — `off`;
  - `total=` — размер порции, повторов лексем нет по построению;
  - `words=` — число разных слов; `words == total`, пока в пуле есть
    слова без второй лексемы (Д4).
- `addQuizData: size = N` — размер сессии ПОСЛЕ graceful skip
  (лексемы без тренируемого значения выброшены), `N ≤ total`.

### Debug-статистика в чате

Меню чата → «Show debug» → первое сообщение сессии содержит
`### Total: N` — размер порции ДО graceful skip (равен `total=` в логе).

## M1. Маленькая группа: Total = W, добавки 0 {#m1}

**Что доказывает.**

Ядро фикса: корзины забирают все W слов группы, добавки «давние» и
«ошибки» видят те же W строк и не дублируют их. До фикса порция была
W + 4.

**Вход.**

* Debug-сборка с IS508. Группа IS500 из ровно 5 слов, у каждого одна
  лексема с переводом; выбрана в пикере карточки квиза.
* Меню чата: «Самые давние» ON, «Частые ошибки» ON, «Show debug» ON.

**Шаги.**

1. Таб «Квизы» → пикер → выбери группу из 5 слов.
2. Зайди в чат, нажми «Начать».
3. Прочитай первое сообщение сессии: строку `### Total:`.
4. Пройди сессию до конца.

**Ожидание глазами.**

`### Total: 5`; в сессии 5 вопросов, ни один не повторился.

**Маркеры в логах.**

```
getRandomWriteQuizList: portion grades=5 earliest=+0/5 errors=+0/<n> total=5 words=5
```

**Анти-проверки.**

* `Total` не 9 (так было до фикса).
* В сводке сессии ни одно слово не стоит дважды.

**Прогон 2026-09-28:** ✅ `Total: 5` (строка `portion` уехала из
256K-буфера logcat; после — буфер 8M).

## M2. Слово с двумя лексемами: обе входят, когда места хватает {#m2}

**Что доказывает.**

Д1: единица уникальности — лексема, не слово. Слово с двумя переводами
— два разных вопроса; при `limit = 10` и группе меньше 10 слов места
хватает всем, и вторая лексема добирается вторым проходом (других
кандидатов нет). Повторов ЛЕКСЕМ при этом нет: `total` = число
квиз-строк группы.

Предпочтение разных слов (Д4) на маленькой группе глазами не видно —
оно проявляется, только когда строк больше `limit`; на девайсе его
проверяет M5 (`words == total` на большом словаре).

**Вход.**

* Группа из 5 слов, у одного слова две лексемы (два перевода) —
  итого 6 квиз-строк. Обе опции OFF, «Show debug» ON.

**Шаги.**

1. Выбери группу, зайди в чат, «Начать».
2. Прочитай `### Total:` и пройди сессию, следя за словом с двумя
   лексемами.

**Ожидание глазами.**

`Total: 6`; слово с двумя лексемами встретилось дважды — разные
вопросы, один ответ (второй раз ответ уже знаком — ожидаемо). Ни один
вопрос не повторился.

**Маркеры в логах.**

```
… grades=6 earliest=off errors=off total=6 words=5
```

**Анти-проверки.**

* `Total` не 7 и не больше (второй лексеме — ровно одна строка,
  unique-индекс Д5).
* `words` = 5, не 6: `words` считает слова, `total` — вопросы.

**Прогон 2026-09-28:** ✅ `Total: 6`, лог `grades=6 … total=6 words=5`.

## M3. «Частые ошибки» без ошибок дают 0 {#m3}

**Что доказывает.**

Д6: опция «Частые ошибки» добавляет только слова с `error_count > 0`.

**Вход.**

* Группа из 5 слов (6 квиз-строк), по части строк уже были ошибки.
  «Частые ошибки» ON, «Самые давние» OFF. «Show debug» ON — заголовок
  каждого вопроса показывает `errorCount: N`.

**Шаги.**

1. Выбери группу, зайди в чат, «Начать».
2. Пройди сессию до конца, запоминая `errorCount` в заголовках.

**Ожидание глазами.**

`Total` = число квиз-строк группы (добавка ничего не добавила — все
кандидаты уже в порции). Число вопросов с `errorCount ≥ 1` равно
`cand` в маркере `errors=+0/cand`.

**Маркеры в логах.**

```
… earliest=off errors=+0/<k> total=6 words=5
```

`k` = число строк группы с `error_count > 0`; вопросы с `errorCount: 0`
в `k` не входят (Д6).

**Анти-проверки.**

* `k` не больше числа вопросов с `errorCount ≥ 1` (до фикса опция
  видела и строки с нулём ошибок).
* Исключение нулевых строк на девайсе доказывает DAO-тест
  `QuizGroupFilterDaoTest.frequentMistakes_zeroErrors_excluded`
  (connectedDebugAndroidTest, 2026-09-28: 137/0).

**Прогон 2026-09-28:** ✅ `errors=+0/6`, все 6 вопросов с
`errorCount` 2–6, `Total: 6`. Первая попытка не в счёт — перепутаны
тумблеры (`earliest=+0/6 errors=+0/0`), проверено по байтам
`lexemePrefStore.preferences_pb`; после этого выключенная опция
печатается как `off` (прогон был до правки маркера).

## M5. Большой словарь: порция без повторов {#m5}

**Что доказывает.**

На боевом словаре (сотни слов) добавки работают и порция без дублей:
`total` = 10 + реально добавленные, `words == total`.

**Вход.**

* Пикер квиза — «Все» на большом словаре; обе опции ON, debug ON.

**Шаги.**

1. Зайди в чат, «Начать», прочитай `### Total:`.
2. Пройди сессию.

**Ожидание глазами.**

`Total` от 10 до 14 (10 + добавки), ни один вопрос не повторился.

**Маркеры в логах.**

```
… grades=10 earliest=+2/10 errors=+<b>/<cand> total=<12..14> words=<= total>
```

**Анти-проверки.**

* `total` не больше 14.
* Если `words < total` — в сессии ровно одно слово встретилось дважды с
  разными вопросами, и это слово с двумя лексемами.

**Прогон 2026-09-28:** ✅ `Total: 14`, лог `grades=10 earliest=+2/10
errors=+2/10 total=14 words=14`; сессией раньше при выключенных
«давних» — `earliest=off … total=12 words=12` (маркер `off` проверен).

## Чат-фикс 2: кнопки «Показать ответ» / «Пропустить» в ленте

### M6. Кнопки действий в ленте {#m6}

**Что доказывает.**

Кнопки действий — элемент ленты: прокручиваются с сообщениями,
появляются с вопросом, исчезают после попытки / «Показать ответ» /
«Пропустить», на финале и в сводке их нет. Известное ограничение (Р1):
при открытой клавиатуре чипы уходят под неё вместе с последними
сообщениями — лечит фикс клавиатуры (Backlog).
Снято чат-фиксом 3 — см. M7 шаг 3.

**Вход.**

Debug-сборка с фиксом; «Show debug» ON (заголовки вопросов длинные —
лента быстро становится длиннее экрана); группа ≥ 5 слов.

**Шаги.**

1. Таб «Квизы» → чат → «Начать». Под первым вопросом справа — два
   чипа «Показать ответ» / «Пропустить»; над полем ввода полосы нет.
2. Прокрути ленту к приветствию — чипы уехали вверх вместе с
   сообщениями; прокрути обратно — на месте под вопросом.
3. «Пропустить» — чипы исчезли, появился пузырь «Пропустить», затем
   следующий вопрос и чипы под ним; лента докручена до чипов.
4. Введи ответ → отправь — чипы исчезли вместе с появлением пузыря
   ответа; оценка; следующий вопрос + чипы.
5. «Показать ответ» — то же, что шаг 3.
6. Тап в поле ввода → клавиатура. Чипы под клавиатурой (ограничение
   Р1); докрути — видны над полем ввода. Закрой клавиатуру.
   Снято чат-фиксом 3 — см. M7 шаг 3.
7. Поверни экран при видимых чипах — один набор чипов, лента в конце.
8. Два быстрых тапа по «Пропустить» — один пузырь «Пропустить», один
   следующий вопрос. Тап по чипу в момент докрутки — одно действие
   либо ничего (докрутка остановилась), не два.
9. Дойди до финала — чипов нет, три кнопки в пузыре. «Сводка» — чипов
   нет. «Продолжить» — чипы только с первым вопросом новой сессии, не
   с пузырём «Продолжаем».

**Ожидание глазами.**

Чипы всегда под последним вопросом, справа, 12dp от пузыря; зазор до
поля ввода 16dp (было 8 — осознанно, П1). У длинного вопроса чипы
видны, верх вопроса — докрутить вверх (раньше обрезался низ).

**Маркеры в логах.**

```
(UI — маркеров нет; anti: adb logcat -d | grep -E "FATAL|non-negative" пуст)
```

**Анти-проверки.**

* Нет двух наборов чипов одновременно; нет чипов до «Начать», на
  финале и в сводке.
* Нет пустой полосы над полем ввода после скрытия чипов.
* Нет `FATAL EXCEPTION`, нет `Index should be non-negative`.

**Прогон 2026-09-28:** ✅ шаги 1–10 глазами («вроде ок»); в логе две
сессии (`SessionOver` ×2, `CONTINUE`), «Пропустить» ×5, «Показать
ответ» ×9, поворот — тот же pid; `FATAL` / `non-negative` — нет.

## Чат-фикс 3: лента от низа

### M7. Лента от низа: чипы у поля ввода, клавиатура {#m7}

**Что доказывает.**

Лента привязана к низу: короткий чат у поля ввода, при клавиатуре
конец ленты виден без докрутки; цепочки, аватары, отступы, кнопки
финала и чипы (M6) — без изменений.

**Вход.**

Debug-сборка с фиксом; «Show debug» ON (заголовки вопросов длинные —
двух вопросов хватает, чтобы лента стала длиннее экрана); группа ≥ 5
слов.

**Шаги.**

1. Открой чат (до «Начать»): приветствие — внизу, над кнопкой
   «Начать», не под аппбаром. Взгляни на фон-иллюстрацию: пузырь
   закрывает её низ — оцени, не перекрыт ли важный фрагмент (если да —
   отдельное решение, не этот фикс).
2. «Начать» → пузырь «Начали», первый вопрос и чипы — прямо над полем
   ввода; сверху пусто.
3. Тап в поле ввода → клавиатура: вопрос и чипы над клавиатурой, без
   докрутки. Закрой клавиатуру — на месте.
4. Введи любой ответ, отправь: пузырь оценки и следующий вопрос —
   цепочка из двух системных подряд. Аватар только у нижнего
   (вопроса), у верхнего (оценки) — скругление «в цепочке»; зазор
   между ними мал (4dp), зазор между твоим ответом и оценкой заметно
   больше (12dp). Признак длинной ленты — приветствие ушло за верх.
5. «Пропустить», затем «Показать ответ»: конец всегда у поля ввода,
   новый вопрос и чипы внизу; у вопроса выше экрана видны низ и чипы,
   верх — докруткой вверх (как M6).
6. Прокрути вверх к приветствию, открой клавиатуру: нижний видимый
   пузырь остался у нижнего края (теперь над клавиатурой), верхние
   ушли под аппбар; лента НЕ уехала к чипам. Закрой клавиатуру — тот
   же пузырь снизу. Прокрути вниз — упирается в чипы.
7. Дойди до финала: три кнопки в последнем пузыре внизу, чипов нет.
   «Сводка» → пузырь с кнопками «Продолжить»/«Завершить» внизу над
   полем ввода, начало сводки — прокруткой вверх, чипов нет.
   «Продолжить» → старая лента остаётся выше без разрыва, «Начали» +
   первый вопрос + чипы внизу.
8. Поверни экран — лента в конце, один набор чипов, в ландшафте те
   же ожидания. Верни.

**Ожидание глазами.**

Всё содержимое «сидит» на поле ввода; пустое место — сверху, никогда
снизу. Отступы как до фикса.

**Маркеры в логах.**

```
(UI — маркеров нет; anti: adb logcat -d | grep -E "FATAL|non-negative" пуст)
```

**Анти-проверки.**

* Нет пустого места между последним элементом и полем ввода.
* Зазоры не съехали: внутри цепочки системных 4dp, между сторонами
  12dp, вопрос→чипы 12dp (Б2).
* Аватар не у верхнего пузыря цепочки; кнопки финала не у не того
  сообщения.
* Нет `FATAL EXCEPTION`.

**Прогон 2026-09-28:** ✅ в чате тремя частями (M7a короткий чат +
клавиатура, M7b отступы + длинная лента + клавиатура в истории, M7c
финал/сводка/продолжить/поворот) — все «ок»; лог: `SessionOver` ×2,
`CONTINUE`, `EXIT`, тот же pid после поворота, `FATAL`/`non-negative`
— нет.

## Чат-фикс 4: жест клавиатуры

### M8. Жест клавиатуры: скролл за конец / от конца {#m8}

**Что доказывает.**

Клавиатура — продолжение ленты (`Modifier.imeNestedScroll()` на
`LazyColumn`, Android 11+): тяга «за конец» ленты вытягивает
клавиатуру за пальцем, тяга вниз при видимой клавиатуре сначала прячет
её, потом крутит ленту; отпускание доанимирует в крайнее положение.
На API < 30 жест не работает — тап в поле и «назад» как раньше.

**Вход.**

Debug-сборка с фиксом, девайс Android 11+; сессия начата («Начать»
нажата — поле ввода есть и держит фокус).

**Шаги.**

1. Спрячь клавиатуру («назад»). Лента в конце. Медленно тяни вверх
   — клавиатура выезжает за пальцем; отпусти на середине — доедет
   вверх или вниз по скорости.
2. Клавиатура видна. Медленно тяни вниз — сначала уезжает
   клавиатура (чат растёт), потом крутится лента.
3. Прокрути ленту в историю, клавиатура скрыта. Тяни вверх до упора
   — сначала лента докручивается до чипов, затем выезжает клавиатура.
4. Клавиатура выехала жестом — набери текст: печатается в поле.
5. Тап в поле / «назад» — показ и скрытие как раньше.

**Ожидание глазами.**

Клавиатура едет за пальцем без рывков; лента всё время «сидит» на
её верхнем крае (фикс 3).

**Маркеры в логах.**

```
(UI — маркеров нет; anti: adb logcat -d | grep -E "FATAL" пуст)
```

**Анти-проверки.**

* Тяга по тексту внутри поля ввода клавиатуру не прячет (жест только
  на ленте).
* Нет `FATAL EXCEPTION`.

**Прогон 2026-09-28:** ✅ Pixel 7 Pro (API 37), в чате двумя частями
(M8a вытянуть/спрятать скроллом, M8b из истории + набор + тяга по
полю) — оба «ок»; `FATAL` — нет, pid не менялся.

## Чат-фикс 5: фон чата

## Чат-фикс 6: анимация ленты

### M10. Анимация ленты: въезд снизу, по одному {#m10}

**Что доказывает.**

Новые сообщения Lexeme и чипы въезжают из-под нижнего края на дистанцию
сдвига соседей той же кривой, что едут соседи — колонка идёт одним
куском, без наложений и «раздувания»; пауза бота перед каждым сообщением
(в т.ч. ответ, финал, сводка) — пузыри по одному. Цепочка системных
сообщений над вопросом не прыгает (элементы ленты не меняют высоту:
чипы — отдельный элемент, высотой ровно с пузырь). Состояние въезда —
по ключу элемента: старое сообщение, заново скомпонованное LazyList,
не въезжает и не мелькает.

Длительности намеренно замедлены (решение юзера 2026-09-29: проверка
анимаций глазами на магазинной сборке): анимация 1,5 с, пауза бота
2–2,1 с; рабочие значения — 350 мс и 400–650 мс.

**Вход.**

Debug-сборка с фиксом; «Show debug» OFF; группа ≥ 5 слов.

**Шаги.**

1. «Начать»: «Начали», вопрос и чипы въезжают снизу по одному.
2. Ответь на вопрос: чипы исчезли, твой пузырь на их месте; оценка и
   следующий вопрос въезжают; цепочка над ними не прыгает.
3. «Пропустить», затем «Показать ответ» — то же.
4. Лента длиннее экрана: новые входят из-под края.
5. Клавиатура жестом — без «желе»; поворот — ничего не въезжает
   повторно.

**Ожидание глазами.**

Анимацию не замечаешь: ничего не накладывается, не раздувается, не
прыгает; сообщения Lexeme приходят по одному.

**Маркеры в логах.**

```
(UI — маркеров нет; anti: adb logcat -d | grep -E "FATAL" пуст)
```

**Анти-проверки.**

* Нет наложения нового пузыря и соседа.
* Нет скачка цепочки над вопросом при ответе / «Пропустить».
* Нет `FATAL EXCEPTION`.

**Прогон 2026-09-28/29:** ❌❌❌❌❌✅ — M10a fade / M10b fade+рост
(наложение, «раздувается»), M10c въезд + чипы внутри вопроса («стало
лучше», но «чипы → пузырь» стрёмно), M10e складывание чипов / M10f
пузырь на месте чипов («прыгает» цепочка — смена высоты элемента в
реверсе), M10g/M10h въезд с чипами отдельным элементом («ок»), M10j

## Чат-фикс 6, часть 2: кнопки → пузырь, аватар по цепочке

### M11. Превращение кнопок в пузырь и спуск аватара {#m11}

**Что доказывает.**

Системные кнопки — элементы ленты и превращаются в пузырь юзера на
месте: «Начать» (широкая синяя по центру) сжимается до пузыря, уезжает
вправо, углы становятся пузырными, одновременно снизу разворачивается
поле ввода; «Пропустить» синеет на месте, сосед «Показать ответ» гаснет
раньше (фазы: гашение 0–45 % времени, перекраска с 30 %); «Показать
ответ» синеет и едет вправо на место «Пропустить», а «Пропустить» едет
с ним и тает за краем. Аватар при продолжении цепочки не перескакивает,
а съезжает с предыдущего пузыря на новый. Аватар — рисунок лаунчера
(`ic_logo_avatar`) белым в круге. Рамка поля ввода прозрачна и в
disabled.

**Вход.**

Debug-сборка; «Show debug» OFF; группа ≥ 5 слов.

**Шаги.**

1. Открой чат: синяя широкая «Начать» по центру; нажми — сжимается в
   пузырь и уезжает вправо, поле ввода разворачивается снизу; серой
   рамки у поля нет.
2. «Пропустить»: сосед гаснет, потом кнопка синеет на месте.
3. «Показать ответ»: едет вправо и синеет, «Пропустить» уезжает с ним и
   тает за краем; ответ бота въезжает следом.
4. Ответь текстом: оценка + вопрос — аватар съезжает с оценки на вопрос.
5. Финал → «Сводка» → «Продолжить» → ещё 2–3 хода: ничего не пропадает
   и не мелькает.

**Ожидание глазами.**

Каждое превращение — одно движение; стопка над кнопками не оседает
(кнопка по раскладке ровно с пузырь: `Surface` + `clickable`, без

```

**Анти-проверки.**

* Нет «качания вниз» при замене кнопок пузырём.
* Призрак уезжающей/гаснущей кнопки не кликабелен.
* Старые пузыри не морфятся и не въезжают повторно.
* Нет `FATAL EXCEPTION`.

**Прогон 2026-09-29:** ✅ — по частям M11a–M11o («заябись» по «Начать»,

## Чат-фикс 7: полёт ответа из поля в пузырь

### M12. Полёт ответа из поля в пузырь {#m12}

**Что доказывает.**

Набранный ответ не «появляется» пузырём, а улетает из поля: буквы
отрываются с места, где стояли (масштаб 17→15sp вокруг базовой линии),
летят к низу ленты, по пути вокруг них проявляется синий фон и текст
белеет; на конце копия неотличима от пузыря и подменяется им. Чипы
«Показать ответ» / «Пропустить» за это время гаснут на месте, а в поле
проявляется плейсхолдер — оба в одно окно с полётом, конец в момент
прилёта. Копия рисуется слоем поверх ленты и поля (лента режет
содержимое, поле — отдельный узел).

**Вход.**

Debug-сборка; «Show debug» OFF; группа ≥ 5 слов; слоу-мо (окно 6 с).

**Шаги.**

1. Открой чат, «Начать», дождись вопроса с чипами.
2. Набери короткий ответ, отправь: буквы отрываются от поля и летят
   вправо-вверх к месту чипов; фон пузыря проявляется по пути.
3. Смотри одновременно на чипы и поле: чипы гаснут, «Введите текст»
   проявляется, оба дотлевают ровно к прилёту текста.
4. Дождись следующего вопроса, отправь ещё ответ: на повторе — то же,
   без пропадания и повторного появления чипов.
5. Многострочный ответ (длинная фраза): полёт той же механикой; отметь,
   как выглядит первый кадр (переносы поля и пузыря разные).

**Ожидание глазами.**

Одно движение «поле → пузырь»; в конце полёта ни мелькания, ни второго
пузыря; клавиатура при отправке прячется, цель полёта едет вниз с
лентой, копия её догоняет.

**Маркеры в логах.**

```

**Анти-проверки.**

* Чипы не мигают на втором и последующих ответах (прогресс полёта
  обнуляется синхронно при отправке, не в корутине).
* Плейсхолдер не стоит под улетающими буквами непрозрачным.
* Пузырь в ленте не виден, пока летит копия; после — обычный.

**Прогон 2026-09-29:** ❌✅ — первый прогон: «вроде норм», но плейсхолдер

## Чат-фикс 8: въезд из-под поля со стыковкой

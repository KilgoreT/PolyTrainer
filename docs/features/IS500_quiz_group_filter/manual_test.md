## Словарь логов

Снимать: `adb logcat -d | grep -E "###QUIZ###|###CHAT###"`.
Очистка перед кейсом: `adb logcat -c`.

### quizGroupStore — selection-store (`###QUIZ###`)

- `quizGroupStore: read type=chat dict=<id> raw=<val|none>
  resolved=<id|all> fallback=<...>` — чтение с валидацией (Д3).
  - `raw=` — сырое значение pref'а (`none` — не записан);
  - `resolved=` — итоговый выбор (`all` = «Все»);
  - `fallback=` — причина фолбэка: `none` — фолбэка не было;
    `garbage` — мусор в pref'е; `dead` — группа удалена/чужая;
    `below_threshold` — группа усохла ниже порога.
  - За старт одной чат-сессии read пишется ДВАЖДЫ: фильтр выборки +
    имя для сабтайтла.
- `quizGroupStore: write type=chat dict=<id> group=<id|all>` — персист
  выбора.

### groupOptions — подписка плашки (`###QUIZ###`)

- `groupOptions: dict=<id> groups=<n> eligible=<m> allCount=<c>
  selected=<id|all>` — каждый эмит combine (счётчики/pref/словарь
  изменились).
- `groupOptions: failed | <exception>` — поток упал (карточка остаётся
  на рабочем дефолте).

### Reducer плашки (`###QUIZ###`)

- `Reduce ---message---: <Msg>` — входящее сообщение.
- `Reduce ---step---: applyGroupOptions | dict=.. groups=.. eligible=..
  allCount=..` — применение эмиссии.
- `Reduce ---step---: resolveSelection | selected=.. fallback=..` —
  применение валидированного выбора; `fallback=true` — выбор съехал
  на «Все» относительно прежнего state.
- `Reduce ---step---: setCardEnabled | enabled=..` — явный флаг карточки.
- `Reduce ---step---: pickGroup | group=..` — выбор юзера.
- `Reduce ---step---: no-op | reason=<card disabled|same selection|
  no dictionary|unknown quiz type|options failed>` — осознанный
  игнор.
- `persistGroupSelection: type=chat dict=<id> group=<id|all>` —
  event-лог эффекта персиста.

### Чат (`###CHAT###`)

- `getRandomWriteQuizList: groupFilter=<id|all>` — фильтр, ушедший в
  выборку сессии.
- `subtitle: group=<name|all>` — имя группы для сабтайтла аппбара.
- Существующие рядом: `addQuizData: size = N` (размер сессии),
  `loadData: fetchData returned empty list` (пустая выборка).

## M1. Дефолт «Все» — как до фичи {#m1}

**Что доказывает.**

Фича ничего не сломала в базовом сценарии: без выбора группы квиз идёт
по всему словарю, пикер показывает «Все».

**Вход.**

* Debug-сборка, словарь с ≥3 словами (с переводами), группы есть или нет — неважно.
* Pref выбора не записан (свежая установка или «Все»).

**Шаги.**

1. Открой таб «Квизы».
2. Убедись глазами: справа на карточке «Все ▾».
3. Тапни карточку, пройди 2-3 вопроса, выйди.

**Ожидание глазами.**

Карточка кликабельна, чат работает как раньше, сабтайтл аппбара
чата — «Все».

**Маркеры в логах.**

```
groupOptions: dict=<id> ... selected=all
quizGroupStore: read ... raw=none resolved=all fallback=none
getRandomWriteQuizList: groupFilter=all
subtitle: group=all
```

**Анти-проверки.**

* Ни одного `fallback=` кроме `none`.
* Нет `no-op | reason=card disabled`.

**Прогон 2026-09-26:** ✅ фильтр=all, size по словарю; UI-фиксы пикера по ходу (фон, право, без слова «Группа»)

## M2. Выбор группы сужает выборку {#m2}

**Что доказывает.**

Ядро фичи: выбранная группа ограничивает квиз ТОЛЬКО её словами.

**Вход.**

* Словарь ≥6 слов с переводами; группа «Быт» из 3-4 слов (создать на
  табе «Группы», добавить слова через карточку слова).

**Шаги.**

1. Таб «Квизы» → тап по «Все ▾».
2. Выбери «Быт» в списке (видны счётчики у пунктов).
3. Тапни карточку, пройди сессию целиком, глядя на слова вопросов.

**Ожидание глазами.**

Все вопросы — только слова из «Быт»; на карточке «Быт ▾»;
в аппбаре чата сабтайтл «Быт».

**Маркеры в логах.**

```
pickGroup | group=<id>
persistGroupSelection: type=chat dict=<id> group=<id>
quizGroupStore: write type=chat dict=<id> group=<id>
getRandomWriteQuizList: groupFilter=<id>
addQuizData: size = <меньше или равно числу слов группы>
```

**Анти-проверки.**

* НИ ОДНОГО вопроса со словом вне группы — главная ловля.
* `groupFilter=` не равен `all`.

**Прогон 2026-09-26:** ✅ groupFilter=4, size=4 из 1603, вопросы только из группы

## M3. Персист: процесс, словари {#m3}

**Что доказывает.**

Выбор помнится per (тип × словарь): переживает убийство процесса,
у каждого словаря — свой.

**Вход.**

* Два словаря: A с группой «Быт» (≥3 слов), B — любой (≥3 слов).
* В словаре A выбрана группа «Быт» (после M2).

**Шаги.**

1. Убей приложение (свайп из recents), запусти заново.
2. Таб «Квизы»: проверь «Быт ▾».
3. Смени словарь в аппбаре на B.
4. Проверь: «Все ▾».
5. Верни словарь A.
6. Проверь: «Быт ▾».

**Ожидание глазами.**

Шаги 2/4/6 — как написано, без лишних тапов.

**Маркеры в логах.**

```
groupOptions: dict=<A> ... selected=<id>   (шаги 2, 6)
groupOptions: dict=<B> ... selected=all    (шаг 4)
quizGroupStore: read ... fallback=none
```

**Анти-проверки.**

* На шаге 4 нет `write` — смена словаря НЕ трогает pref'ы.
* Нет `fallback=dead|below_threshold|garbage`.

**Прогон 2026-09-26:** ✅ холодный старт selected=4; словари изолированы

## M4. Порог: disabled-пункт оживает {#m4}

**Что доказывает.**

Группы ниже порога видны disabled-пунктами (не исчезают), живая
подписка оживляет пункт без перезахода при доборе слов.

**Вход.**

* Группа «Мелкая» из 2 слов (с переводами) в текущем словаре.

**Шаги.**

1. Таб «Квизы» → открой пикер.
2. Найди пункт «Мелкая · 2» — серый, тап по нему ничего не делает.
3. Закрой пикер, добавь в «Мелкая» третье слово (таб «Словарь» →
   карточка слова → группы).
4. Вернись на «Квизы», открой пикер.
5. Пункт «Мелкая · 3» — живой; выбери его.

**Ожидание глазами.**

Шаг 2 — серый некликабельный пункт с счётчиком; шаг 5 — обычный пункт,
выбор срабатывает.

**Маркеры в логах.**

```
groupOptions: ... eligible=<m>      (после шага 3 m вырос на 1)
pickGroup | group=<id>              (шаг 5)
```

**Анти-проверки.**

* На шаге 2 НЕТ `pickGroup` в логе — тап по disabled не рождает Msg.
* Пункт не исчезал из списка ни в один момент.

**Прогон 2026-09-26:** ✅ eligible 1→2 живой подпиской, pick→persist→эхо без рассинхрона

## M5. Удаление выбранной группы {#m5}

**Что доказывает.**

Молчаливый фолбэк Д3: удалённая группа → «Все» без снекбаров и крешей;
причина видна в логе.

**Вход.**

* Выбрана группа «Быт» (M2).

**Шаги.**

1. Таб «Словарь» → вкладка «Группы» → удали «Быт» (обычное удаление,
   без слов).
2. Вернись на таб «Квизы».
3. Проверь пикер: «Все ▾».
4. Зайди в чат, начни сессию.

**Ожидание глазами.**

Пикер молча на «Все», квиз по всему словарю, сабтайтл аппбара — «Все».
Никаких снекбаров/диалогов.

**Маркеры в логах.**

```
groupOptions: ... selected=all
resolveSelection | selected=all fallback=true
persistGroupSelection: type=chat dict=<id> group=all   (закрепление)
getRandomWriteQuizList: groupFilter=all
```

Store-фолбэк `fallback=dead` в норме не виден: плашка закрепляет
(стирает pref) раньше, чем чат читает; он остался страховкой гонки.

**Анти-проверки.**

* Нет креша, нет пустого чата (словарь ≥3 слов).
* Нет кадра со старым «Быт» после возврата (см. M10).

**Прогон 2026-09-26:** ✅ fallback=true, эмиссия до возврата на таб, без снекбаров

## M6. Усыхание: фолбэк закрепляется {#m6}

**Что доказывает.**

Группа ниже порога → «Все», и это ЗАКРЕПЛЯЕТСЯ (невалидный pref
стирается): исцеление группы выбор НЕ воскрешает — «Все» остаётся,
пока юзер сам не выберет группу заново (решение прогона 2026-09-26,
отменило «выбор дремлет» из ревью).

**Вход.**

* Выбрана группа «Быт» из ровно 3 слов.

**Шаги.**

1. Сними одно слово с группы (галка в карточке слова) — в группе 2.
2. Таб «Квизы»: пикер — «Все», пункт «Быт · 2» серый.
3. Верни слово в группу — снова 3.
4. Таб «Квизы»: пикер — ПО-ПРЕЖНЕМУ «Все», пункт «Быт · 3» живой.

**Ожидание глазами.**

Шаги 2 и 4 — как написано, без единого тапа по пикеру.

**Маркеры в логах.**

```
resolveSelection | selected=all fallback=true          (шаг 1-2)
persistGroupSelection: type=chat dict=<id> group=all   (закрепление)
quizGroupStore: write type=chat dict=<id> group=all
groupOptions: ... selected=all                          (шаг 4)
```

**Анти-проверки.**

* На шаге 4 выбор НЕ вернулся на «Быт» сам.
* Ровно ОДНО закрепление (write group=all) на фолбэк, не цикл записей.

**Прогон 2026-09-26:** ❌✅ v1-воскрешение забраковано юзером → закрепление фолбэка (1 write, цикла нет)

## M7. Disabled-карточка малого словаря {#m7}

**Что доказывает.**

Порог на «Все»: словарь < 3 слов — карточка disabled и объясняет
причину числом.

**Вход.**

* Свежий словарь с 1-2 словами (с переводами).

**Шаги.**

1. Переключись на малый словарь, открой таб «Квизы».
2. Прочитай сабтайтл карточки.
3. Тапни карточку.
4. Добавь слов до 3, вернись на «Квизы».
5. Тапни карточку.

**Ожидание глазами.**

Шаг 2: «Нужно минимум 3 слова — сейчас N», карточка приглушена, пикер
виден с «Все», но заморожен. Шаг 3: ничего не происходит. Шаг 5: чат
открылся.

**Маркеры в логах.**

```
setCardEnabled | enabled=false     (шаг 1)
no-op | reason=card disabled       (шаг 3, если тап дошёл до reducer)
setCardEnabled | enabled=true      (шаг 4)
```

**Анти-проверки.**

* На шаге 3 чат НЕ открылся.
* Высота карточки не прыгает между шагами 1 и 4.

**Прогон 2026-09-26:** ✅ сабтайтл причины, тап мёртв, оживление на смене словаря

## M8. Сабтайтл аппбара чата {#m8}

**Что доказывает.**

Внутри чата ВСЕГДА видно охват тренировки: сабтайтл аппбара — имя
группы либо «Все» (решение прогона 2026-09-26), с момента входа в
экран, ещё до «Начать».

**Вход.**

* Выбрана группа «Быт».

**Шаги.**

1. Зайди в чат с карточки, НЕ нажимая «Начать».
2. Посмотри на аппбар.
3. Выйди, выбери «Все», зайди снова.
4. Посмотри на аппбар.

**Ожидание глазами.**

Шаг 2: под «Квиз чат» серая строка «Быт» (до старта сессии). Шаг 4:
серая строка «Все».

**Маркеры в логах.**

```
subtitle: group=Быт     (шаг 1, на входе в экран)
subtitle: group=all     (шаг 3)
```

**Анти-проверки.**

* Сабтайтл не остался от прошлой сессии на шаге 4.
* Сабтайтл виден ДО нажатия «Начать».

**Прогон 2026-09-26:** ❌✅ имя грузилось только с «Начать» → init-эффект; сабтайтл теперь всегда (и «Все»)

## M9. Счётчик уровня 1: слова без лексем {#m9}

**Что доказывает.**

Счётчик считает только слова с лексемами: группа из «пустых» слов
честно показывает 0 и не проходит порог.

**Вход.**

* Группа «Пустая» из 3 слов, у которых удалены/не созданы переводы
  (слово есть, лексем нет).

**Шаги.**

1. Таб «Квизы» → открой пикер.
2. Найди пункт «Пустая · 0» — серый.
3. Добавь одному слову группы перевод.
4. Переоткрой пикер: «Пустая · 1».

**Ожидание глазами.**

Счётчик отражает слова С переводами, не все слова группы (на табе
«Группы» у этой группы при этом 3).

**Маркеры в логах.**

```
groupOptions: ... allCount=<без пустых слов>
```

**Анти-проверки.**

* «Пустая · 0» некликабельна.
* Расхождение счётчиков с табом «Группы» — ОЖИДАЕМОЕ (уровень 1).

**Прогон 2026-09-26:** ✅ 3 слова без лексем → «· 0» серый; перевод → allCount+1

## M10. Анти-мигания {#m10}

**Что доказывает.**

Возврат на таб и смена словаря не показывают кадров устаревшего
выбора/чужой группы.

* Два словаря с разными выбранными группами (после M3).

**Шаги.**

1. Выбери группу, уйди на таб «Группы», удали её, вернись на «Квизы»,
   глядя на пикер в момент появления таба.
2. Смени словарь в аппбаре, глядя на пикер.
3. Посмотри логи.

**Ожидание глазами.**

Ни в один кадр не видно: старого имени удалённой группы (шаг 1),
группы чужого словаря (шаг 2).

**Маркеры в логах.**

```
groupOptions: dict=<новый> ...   — эмиссии в правильном порядке
```

**Анти-проверки.**

* Нет «мигнул Быт → стал Все» на глаз.
* Нет `groupOptions: failed`.

**Прогон 2026-09-26:** ✅ миганий нет, 0 failed за весь прогон

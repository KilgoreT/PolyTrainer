# IS500 | Квиз по группе

Issue: https://github.com/KilgoreT/PolyTrainer/issues/500
Ветка: `IS500_quiz_group_filter`

## Контекст

IS493 внедрил группы слов: слова словаря добавляются в корневые
группы (membership через карточку слова и вкладку «Группы»). Квиз
(chat-квиз, вход с таба «Тренировки») про группы не знает и всегда
гоняет выборку по всему словарю.

## Цель

Пользователь может ограничить тренировку одной группой: учить порцию
слов (тематическую группу), а не весь словарь.

## Требования (ядро)

1. **Выбор группы в плашке входа в чат** (таб «Тренировки»):
   - элемент выбора группы; по умолчанию — «Все»;
   - выбор через всплывающий список: «Все» + группы текущего словаря.
2. **Фильтрация выборки**: при выбранной группе квиз собирает слова
   ТОЛЬКО из этой группы (membership `word_groups`); «Все» —
   поведение как сейчас, весь словарь.

## Не входит

- Мультивыбор групп.
- Вложенность групп (их нет — группы корневые).
- Изменение механики самого чата/вопросов — фильтруется только
  выборка слов.
- Псевдо-пункт «Без группы» и фильтр по группам в общем списке слов —
  возможные будущие фичи, здесь не думаем (Д5).

## Контекст-план таба (озвучен юзером при согласовании)

Таб «Тренировки» станет НАБОРОМ КАРТОЧЕК: карточка = тип квиза (chat
сейчас, flip-cards и другие — скоро). У каждой карточки свой пикер
группы и своя память выбора. Дизайн фичи закладывается под это.

## Решения (согласованы 2026-09-26)

- **Д1. Персист.** Ключ **(тип квиза × словарь)** → группа, дефолт
  «Все»; общий selection-store по образцу quiz_picker prefs. Смена
  словаря перечитывает выборы всех карточек (У2).
- **Д2. Порог годности.** Константа `MIN_QUIZ_WORDS = 3`, **одна на
  все типы** (У1); в общем слое выборки — параметр с дефолтом из неё
  (задел под per-тип override без перестройки слоя). Группы ниже
  порога показываются в списке **disabled-пунктами с счётчиком**
  (уточнение по ревью 2026-09-26: скрытие выглядело бы как «квиз не
  видит мои группы»; серым, некликабельно); правило действует и на
  «Все» (весь словарь). Нет ни одного пригодного пункта (включая
  «Все») — карточка квиза disabled и некликабельна, сабтайтл
  объясняет причину («Нужно минимум 3 слова — сейчас N»); состояние —
  явный флаг в state (не вычисление в composable).
- **Д3. Удалённая/усохшая группа при персисте.** Молча «Все», без
  снекбаров; валидация при чтении в selection-store — карточки
  получают уже валидированный выбор.
- **Д4. Место контрола.** Пикер группы («Группа: Все ▾», всплывающий
  список) — В САМОЙ плашке/карточке, не в меню аппбара чата. Общий
  Compose-виджет, переиспользуемый всеми будущими карточками.
- **Д5.** «Все» покрывает и слова вне групп; отдельного пункта нет.
- **Д6. Общий слой** из трёх кусков:
  1. домен — единая выборка «слова по (словарь, группа?, компонент?)»
     + «пригодные группы со счётчиками»; порог живёт здесь;
  2. персист — selection-store из Д1;
  3. UI — общий виджет из Д4.
  Chat-квиз — первый потребитель; новые типы подключаются к тем же
  трём кускам. В код конкретного квиза фильтр не зашивается.

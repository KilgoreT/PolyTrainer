# IS496 | Ручники фичи — полный набор

Немодальная панель ввода: живой фон, кликабельный отфильтрованный
список. Прогон на Mi A1 с реальной базой (2177 слов), 2026-08-30.

## Содержание

- [Словарь логов](#словарь-логов)
- M1–M6

## Словарь логов

### Панель и фильтр (`###LEXEME###` / `###GROUPS###`)

* `Reduce ---message---: OpenAddWordDialog` / `OpenCreateSheet` /
  `OpenRenameSheet` — панель открыта.
* `UpdateWordInput(value=…)` / `SheetInputChanged` — ввод (live-фильтр).
* `OpenWordCard(wordId=…)` — тап по слову; при открытой панели ветка
  reducer'а закрывает её (IS496 Р3) — отдельного Msg НЕТ, закрытие
  внутри той же ветки.
* `CloseAddWordDialog` / `DismissSheet` — закрытие (back / свайп-вниз /
  тап по слову на «Группах» — там шлётся ЯВНЫЙ DismissSheet из UI).

Снятие: `adb logcat -d | grep -E "###LEXEME###|###GROUPS###"`.
Анти-инвариант: FATAL за прогон — ноль.

## M1. «Слова»: живой фон, скролл и тап сквозь панель

**Что доказывает.** Ядро фичи: панель немодальна, фильтр — полноценный
живой список.

**Шаги.** FAB → ввод `ca` → скролл → тап по слову → назад.

**Ожидание глазами.** Фон без затемнения; скролл прячет клавиатуру,
панель остаётся; тап открывает карточку, панель закрыта, ввод сброшен.

**Прогон 2026-08-30:** ❌✅ (зазор панели над клавиатурой в высоту
BottomBar — imePadding не знал про бар; вылечено ручным подъёмом по
фактическому зазору до низа окна)

# IS496 | План реализации

База: [brief.md](brief.md) (Р1–Р7). Ветка `IS496_nonmodal_input_panel`
от master (0.1.6). Обе вкладки уже используют общий
`InputBottomSheetWidget` — переделка локализована в трёх точках.

## Э1. core/ui: немодальная панель

- `InputDockedPanelWidget` (новое имя — виджет больше не sheet):
  Surface у нижней грани (Box-слот вызывающего экрана), скругление
  верхних углов, `imePadding()` + `navigationBarsPadding()` — раньше
  инсеты решало диалоговое окно, теперь вручную (риск-зона №1 брифа).
- `BackHandler(enabled = открыта)` → onDismissRequest (Р6: кнопка и
  жест — один системный back).
- Свайп-вниз по панели → dismiss (Р6): вертикальный drag по Surface;
  порог — половина высоты панели.
- Фокус в поле при появлении: перенос withFrameNanos-фикса
  (`PrimaryTextFieldWidget`) — диалога больше нет, проверить что фокус
  и клавиатура поднимаются без него/с ним (риск-зона №3).
- `errorText` под полем — сохраняется как есть.
- Старый `InputBottomSheetWidget` удаляется в Э3 (после переезда обеих
  вкладок).

## Э2. groupstab: переезд шторки группы

- `GroupBottomSheetWidget` → `InputDockedPanelWidget`; в
  `GroupsTabScreen` панель кладётся в Box поверх списка (не в
  ModalBottomSheet-слот).
- Reducer НЕ меняется: open/dismiss/фильтр/submit — прежние Msg.
- Скролл списка прячет клавиатуру (Р4): NestedScrollConnection →
  `keyboardController.hide()`; панель остаётся.
- Тап по строке группы при открытой панели — аккордеон (Р7): работает
  сам собой, фон живой; проверить руками.
- FAB скрыт при открытой панели — как сейчас.

## Э3. wordstab: переезд шторки слова + тап по слову

- `AddWordBottomSheetWidget` → `InputDockedPanelWidget`; Box-слой в
  `WordsTabScreen`.
- Р3 — ветка reducer'а: тап по слову при открытой панели → закрыть
  панель (очистить ввод) + существующая навигация в карточку. Смотреть
  текущие Msg тапа слова; изменение — цепочкой атомов по конвенции.
- Скролл → клавиатура прячется (Р4), лонг-тап/ActionMode не гейтится
  (Р5).
- Удалить `InputBottomSheetWidget` (обе вкладки переехали).

## Э4. Проверка

- Юниты: новые/изменённые ветки reducer'а wordstab; регресс groupstab.
- `assembleDebug` + `:app:lintDebug`.
- Ручники на девайсе (формат manual-tests, с логами):
  1. «Слова»: панель открыта → фильтр → скролл (клавиатура спряталась,
     панель жива) → тап по слову → карточка, панель закрыта, ввод чист.
  2. «Слова»: back-жест закрывает панель; свайп-вниз закрывает.
  3. «Слова»: лонг-тап при открытой панели → ActionMode.
  4. «Группы»: create-фильтр → тап по группе → аккордеон, панель жива.
  5. «Группы»: rename — фокус и клавиатура поднимаются, ошибка
     валидации видна под полем.
  6. Поворот экрана с открытой панелью.
- Регресс: снекбар ошибки гонки dismiss (был невидим под M3-окном —
  теперь окна нет, перепроверить видимость и убрать устаревший
  комментарий, если поведение изменилось).

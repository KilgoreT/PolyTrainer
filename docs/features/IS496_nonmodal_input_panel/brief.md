# IS496 | Немодальная панель ввода — бриф

Решения приняты пользователем в обсуждении 2026-08-30. Статус: согласован.

## Мотивация

Шторки ввода («Слова» — добавление слова; «Группы» — создание/rename
группы) live-фильтруют список позади — но обе построены на
`ModalBottomSheet`. Это отдельное диалоговое ОКНО во весь экран: фон
мёртв независимо от прозрачности скрима (проверено по исходникам
material3 1.3.2 — «Removed dismissOnClickOutside», немодального режима
нет by design). Итог: юзер видит отфильтрованные слова, но не может ни
скроллить их, ни открыть карточку.

## Решения (Р1–Р7)

- **Р1. Уход от диалога:** `ModalBottomSheet` заменяется КАСТОМНОЙ
  докнутой панелью в иерархии экрана (Box: контент + панель внизу).
  Фон живой по построению. `BottomSheetScaffold` отвергнут: чужая
  жестовая механика + host уже владеет Scaffold'ом.
- **Р2. Затемнения нет,** область над панелью полностью интерактивна.
- **Р3. Тап по слову** при открытой панели: панель закрывается
  (ввод очищается — намерение «добавить» отменено тапом по
  существующему), открывается карточка слова. Возврат из карточки — к
  обычному списку, панель не восстанавливается.
- **Р4. Скролл списка** панель НЕ закрывает (иначе сбросится
  фильтр/позиция) — только прячет клавиатуру.
- **Р5. Лонг-тап (ActionMode на «Словах»)** работает как обычно —
  противоречий с открытой панелью нет.
- **Р6. Закрытие панели:** системный back (кнопка и жест — BackHandler)
  и свайп-вниз по самой панели. «Тап мимо = закрыть» упраздняется
  вместе со скримом.
- **Р7. «Группы»: тап по строке группы** при открытой панели — обычное
  раскрытие аккордеона, панель живёт.

## Технический скоуп

- `core/ui`: `InputBottomSheetWidget` → немодальная панель (Surface у
  нижней грани, imePadding, BackHandler, swipe-down dismiss). Фокус и
  клавиатура — вручную (прежний withFrameNanos-фикс фокуса сохраняется).
- `wordstab`: AddWord-шторка переезжает на ту же панель; тап по слову
  при открытой панели — закрыть+навигация (ветка reducer'а).
- `groupstab`: шторка create/rename переезжает; поведение веток
  reducer'а не меняется (открытие/фильтр/submit как были).
- FAB скрыт при открытой панели (как сейчас).

## Вне скоупа

- Отдельный «поиск» как самостоятельная фича.
- Автокомплит-список внутри панели.
- Изменение механики фильтрации.

## Риски

- Клавиатура/imePadding в ручной панели (раньше решал диалог).
- Жесты: конфликт свайпа-вниз панели со скроллом списка внутри неё нет
  (списка в панели нет), но проверить на поле ввода.
- Регресс фокуса при rename (существующий withFrameNanos-фикс).

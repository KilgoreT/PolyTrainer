# IS491 — Корявости к переделке

Список замеченного при прогоне/работе, что надо поправить отдельно (не блокирует
фичу, чиним потом одной пачкой). Дополняется по ходу.

## Открыто

- **[UX] В карточке нет отмены/отката правки значения.**
  Правка коммитится при уходе фокуса, а «назад» тоже уводит фокус → изменения
  сохраняются. Отменить начатую правку (вернуть исходное) нельзя. Решить, нужна ли
  явная отмена (кнопка/жест) или это ок как inline-паттерн. Касается всех значений
  карточки (перевод/определение/captioned), не только IS491.

## Исправлено

- **[UI-термин] Вариант зависимости «Самостоятельный» → «Лексема».**
  `components_target_lexeme`: ru «Самостоятельный»→«Лексема», en «Standalone»→«Lexeme».
- **[UI] Чёрный фон/текст выпадашки подсказок caption.**
  `CaptionField` DropdownMenu — добавлен явный `.background(MaterialTheme.colorScheme.surface)`
  (дефолтный контейнер меню в теме тёмный).

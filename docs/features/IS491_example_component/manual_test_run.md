# IS491 — Ручной прогон: данные и пошаговые тесткейсы

Правила чтения:

- Каждый нумерованный пункт — **одно действие** (один тап / один ввод). Никаких
  склеек через запятую.
- `ВИЖУ` — отдельный блок: что на экране. Перечисления — по строке на пункт.
- `ЛОГ` — отдельный блок: что в logcat. Никогда не в одной строке с действием.
- Ввод дословно в «…».

Как фиксируется значение в карточке (кнопки «Сохранить» в карточке НЕТ):

- Значение фиксируется при уходе с него: другой компонент / другое значение /
  «назад».
- Поле текста captioned по потере фокуса НЕ коммитит; коммит — по уходу с поля
  подписи или при выходе.
- Пустой текст → значение молча не создаётся.
- Кнопка «Создать» есть только в конструкторе компонентов (диалог).

Лог: `adb logcat | grep '###CAPTIONED_TEXT###'`.

### 0.1. Словарь и слова

1. Создать словарь **ES**.
2. Добавить слово «sol», перевод «солнце».
3. Добавить слово «pan», перевод «хлеб».
4. Добавить слово «mar», перевод «море».
5. Добавить слово «rey», перевод «король».
6. Добавить слово «ojo», перевод «глаз».

```
ВИЖУ  у каждого из 5 слов одна лексема с переводом (оформлена)
```

## Раздел 1. Кастомный компонент «Цитата»

### UC1. Создание компонента

1. Открыть конструктор словаря **ES**.
2. Нажать «создать компонент».
3. Выбрать шаблон «Текст с подписью».

```
ВИЖУ  шаблоны:
      «Текст» (активен)
      «Изображение» (недоступен)
      «Выбор» (активен)
      «Текст с подписью» (активен)
```

4. Ввести имя «Цитата».
5. Включить «Несколько значений».
6. Выбрать зависимость «Лексема».
7. Снять «Ядро».
8. Нажать «Создать».

```
ВИЖУ  «Цитата» в списке компонентов словаря
```

9. Открыть карточку слова **sol**.

```
ВИЖУ  среди кнопок добавления есть «Цитата»
```

10. Создать новое слово без перевода (черновик).
11. Открыть это слово.

```
ВИЖУ  «Цитата» НЕ предлагается (черновик, «Цитата» не ядро)
```

12. Выйти и бросить черновик.

### UC2. Первое заполнение (многострочный текст + подпись)

Слово **sol**.

1. Нажать «Цитата».

```

```
ВИЖУ  выпадающего списка нет (подсказок ещё нет)

4. Ввести «uno».
5. Нажать Enter.

8. Ввести «дом».

10. Открыть слово **sol** снова.

### UC25. Правка фиксируется при выходе (отмены нет)

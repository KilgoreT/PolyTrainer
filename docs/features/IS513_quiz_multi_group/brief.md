# IS513 | Бриф: несколько групп для тренировки в квиз-чате

Issue: https://github.com/KilgoreT/PolyTrainer/issues/513
Ветка: `IS513_quiz_multi_group` (от master `cd24a2a8`, после релиза 0.1.11).

## Проблема

Сейчас тренировку в квиз-чате можно ограничить только одной группой
слов или взять весь словарь («Все»). Нужно дать выбрать сразу несколько
групп: раунд собирается из слов любой из выбранных групп.

## Как устроено сейчас (IS500, спека quiz-group-filter)

- **Где выбирают.** Пикер группы живёт на карточке квиз-чата в табе
  «Квизы» (`quiztab/widget/QuizGroupPickerWidget`): контрол «<имя> ▾»,
  меню со списком «Все» + группы словаря, у каждого пункта счётчик слов.
  В самом чате группу не выбирают, только видят: сабтайтл аппбара
  показывает имя группы или «Все».
- **Что выбирают.** Один пункт: `selectedGroupId: Long?`, null = «Все».
- **Порог.** Группа пригодна, если в ней ≥ 3 слов с лексемой
  (`MIN_QUIZ_WORDS`). Непригодные видны серыми и некликабельными. Нет ни
  одного пригодного пункта — карточка квиза disabled.
- **Персист.** Pref `quiz_group_<тип>_dict_<id>` = один `groupId`
  строкой; нет ключа = «Все». При чтении — валидация через доменную
  воронку `resolveQuizGroupState`: мёртвая, усохшая ниже порога или
  мусорная группа → «Все», и pref стирается (фолбэк закрепляется).
- **Выборка.** Три SQL-запроса порции (грейды, «Самые давние», «Частые
  ошибки») фильтруют по `groupId` в WHERE до `ORDER BY/LIMIT`:
  `EXISTS (… word_groups … AND wg.group_id = :groupId)`. Слово может
  состоять в нескольких группах, в выборке оно одно (ключ порции —
  лексема).
- **Счётчики.** Живые Flow: счётчик слов каждой группы и всего словаря.
- **Спека прямо называет мультивыбор вне скоупа v1** (§12) — это он.

## Решения (2026-10-01)

- **Д1. Где выбирать — только на карточке квиза** в табе «Квизы», как
  сейчас. Чат не трогаем: группы в нём только видны в сабтайтле.
- **Д2. «Все» отдельным пунктом сверху, группы галками.** Отметил любую
  группу — «Все» снимается; отметил «Все» — снимаются все группы; снял
  последнюю группу — возвращается «Все». Пустого выбора нет. «Все» — весь
  словарь, включая слова без группы (не сумма групп). В pref пустой набор
  = «Все». Галка есть у всех пунктов, включая «Все» (уточнено после
  анализа): меню однородное, взаимоисключение видно глазами.
- **Д3. Порог — на каждую группу, как сейчас.** Группа < 3 слов с
  лексемой серая и некликабельна; любой допустимый набор даёт ≥ 3 слов.
  Объединение мелких групп — не делаем.
- **Д4. Подпись «Быт +2»** — на карточке (контрол пикера) и в сабтайтле
  чата одинаково: первая выбранная по алфавиту (порядок списка пикера) и
  число остальных. Одна группа — её имя, «Все» — как сейчас.
- **Д5. Общий счётчик по выбранным группам не показываем.**
- **Д6. Пропавшие группы** (удалены, усохли ниже порога, мусор) молча
  выпадают из набора, остальные остаются; если не осталось ни одной —
  «Все». Очищенный набор сразу пишется в pref: выпавшая группа сама не
  вернётся (то же правило закрепления, что в IS500, — поэлементно).
- **Д7. Новый ключ pref, старый одиночный игнорируется.** После
  обновления выбор у всех сбрасывается на «Все». Старый ключ
  `quiz_group_<тип>_dict_<id>` остаётся мусором в prefs — принято (та же
  утечка, что ключи удалённых словарей в IS500).

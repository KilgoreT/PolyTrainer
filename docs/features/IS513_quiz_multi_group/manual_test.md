# IS513 | Ручники фичи — полный набор

Несколько групп для тренировки: галки в пикере карточки chat-квиза,
выборка по объединению групп, подпись «Быт +2» на карточке и в чате,
поэлементное выпадение групп, новый ключ pref. Сборка —
`co.lexeme.app.dev` (`installDebug`), прогон с adb.

## Словарь логов

Снимать: `adb logcat -d | grep -E "###QUIZ###|###CHAT###"`.
Очистка перед кейсом: `adb logcat -c`.

### quizGroupStore — selection-store (`###QUIZ###`)

* `quizGroupStore: read type=chat dict=<id> raw=<строка|none> resolved=<ids|all> dropped=<…|none> garbage=<bool>` — чтение с валидацией.
  * `raw=` — сырое значение pref'а `quiz_groups_chat_dict_<id>` (`none` — не записан);
  * `resolved=` — итоговый набор через запятую (`all` = «Все»);
  * `dropped=` — выпавшие группы с причиной: `<id>:dead` — удалена/чужая, `<id>:below` — усохла ниже порога;
  * `garbage=true` — в pref были нечитаемые токены.
  * За старт сессии read пишется дважды: фильтр выборки + подпись сабтайтла.
* `quizGroupStore: write type=chat dict=<id> groups=<ids|all>` — запись набора.

### Плашка (`###QUIZ###`)

* `groupOptions: dict=… groups=… eligible=… allCount=… selected=<ids|all> garbage=…` — каждый эмит подписки.
* `persistGroupSelection: type=chat dict=… groups=<ids|all>` — эффект записи.
* `Reduce ---step---: pickGroups | groups=…`, `applySelectionLabel | label=<first+N|all>`, `resolveSelection | selected=… dropped=…`.
* `Reduce ---step---: no-op | reason=<same selection|ineligible group|no dictionary|unknown quiz type|card disabled>`.

### Чат (`###CHAT###`)

* `subtitle: group=<first+N|all>` — подпись сабтайтла.
* `getRandomWriteQuizList: groupFilter=<ids|all> cores=[…]` — фильтры порции.

## M1. После обновления — «Все»

**Что доказывает.**

Д7: новый ключ pref, старый одиночный выбор не читается — после
обновления у юзера «Все», без крэша.

**Вход.**

* `installDebug` с master `cd24a2a8` (0.1.11), на карточке квиза выбрана одна группа.
* Затем `installDebug` ветки IS513 поверх (данные не удалять).

**Шаги.**

1. Открой таб «Квизы».

**Ожидание глазами.**

Пикер на карточке — «Все», галка у «Все».

**Маркеры в логах.**

```
groupOptions: … selected=all garbage=false
```

**Анти-проверки.**

* Нет FATAL; в логе нет чтения ключа `quiz_group_chat_dict_` (без «s»).

**Прогон:** ✅

## M2. Две группы за одно открытие меню

**Что доказывает.**

Мультивыбор: меню не закрывается на клик по группе; подпись «Быт +1».

**Вход.**

* Словарь с ≥ 2 пригодными группами (≥ 3 слов в каждой).

**Шаги.**

1. Открой пикер на карточке.
2. Тапни две группы.
3. Тапни вне меню.

**Ожидание глазами.**

После каждого тапа меню остаётся открытым, галки ставятся; у «Все»
галка снимается после первого тапа. Контрол — «<первая по алфавиту> +1 ▾».

**Маркеры в логах.**

```
persistGroupSelection: … groups=<id1>
persistGroupSelection: … groups=<id1>,<id2>
```

**Анти-проверки.**

* Меню не закрылось после первого тапа; один тап — один `persistGroupSelection`.

**Прогон:** ✅

## M3. «Все» ↔ группы, снятие последней

**Что доказывает.**

Д2: «Все» и группы взаимоисключают; снятие последней группы — «Все».

**Вход.**

* Состояние M2 (две группы отмечены).

**Шаги.**

1. Открой пикер, сними одну группу, затем вторую.
2. Отметь группу, затем тапни «Все».

**Ожидание глазами.**

1. После снятия второй — галка у «Все», контрол «Все».
2. Тап «Все» снимает группу и закрывает меню.

**Маркеры в логах.**

```
persistGroupSelection: … groups=all
```

**Анти-проверки.**

* Не бывает состояния без галок вообще.

**Прогон:** ✅

## M4. Раунд из выбранных групп, сабтайтл

**Что доказывает.**

Выборка по объединению выбранных групп; сабтайтл чата — та же подпись.

**Вход.**

* Отмечены две группы; в словаре есть слова вне них.

**Шаги.**

1. Открой квиз-чат, нажми «Начать», пройди раунд.

**Ожидание глазами.**

Сабтайтл «<первая> +1» уже до «Начать». Все слова раунда — из двух групп.

**Маркеры в логах.**

```
subtitle: group=<first>+1
getRandomWriteQuizList: groupFilter=<id1>,<id2> …
```

**Анти-проверки.**

* Ни одного слова вне выбранных групп; слово из обеих групп — один раз.

**Прогон:** ✅

## M5. Выбранная группа удалена или усохла

**Что доказывает.**

Д6: невалидная группа выпадает поэлементно, остальные остаются; pref
перезаписывается очищенным набором.

**Вход.**

* Отмечены две группы A и B.

**Шаги.**

1. На вкладке «Группы» удали группу A.
2. Вернись в таб «Квизы», открой пикер.

**Ожидание глазами.**

Отмечена только B, контрол — «B». A в списке нет.

**Маркеры в логах.**

```
groupOptions: … selected=<B> …
persistGroupSelection: … groups=<B>
```

**Анти-проверки.**

* Не сброс на «Все» целиком; нет мигания A.

**Прогон:** ✅

## M6. Набор переживает перезапуск

**Что доказывает.**

**Вход.**

**Шаги.**

1. Убей приложение свайпом, запусти, открой таб «Квизы».

**Ожидание глазами.**

Те же две группы, подпись «<первая> +1».

**Маркеры в логах.**

```
groupOptions: … selected=<id1>,<id2> garbage=false
```

**Анти-проверки.**

* Нет `persistGroupSelection` сразу после запуска.

**Прогон:** ✅

## M7. Серые группы не отмечаются

**Шаги.**

**Ожидание глазами.**

Ничего не происходит, галка и строка серые.

**Маркеры в логах.**

```
(нет persistGroupSelection)
```

**Анти-проверки.**

* Меню не закрылось и выбор не изменился.

**Прогон:** ✅

## M8. Изоляция набора по словарям

**Что доказывает.**

Ключ по (тип × словарь): у другого словаря свой набор; смена словаря pref не пишет.

**Вход.**

* Два словаря; в первом отмечены две группы.

**Шаги.**

1. Переключи текущий словарь на второй, открой таб «Квизы».
2. Верни первый словарь.

**Ожидание глазами.**

1. У второго — свой выбор («Все», если не выбирали).
2. У первого — те же две группы.

**Маркеры в логах.**

```
groupOptions: dict=<второй> … ; groupOptions: dict=<первый> … selected=<id1>,<id2>
```

**Анти-проверки.**

* Нет `persistGroupSelection` при смене словаря.

**Прогон:** ✅

## M9. Выпавшая группа не возвращается сама

**Что доказывает.**

Закрепление поэлементно: усохшая и выпавшая группа после «исцеления» не
отмечается обратно.

**Вход.**

* Отмечены A и B, в A ровно 3 слова.

**Шаги.**

1. Удали одно слово из A (A усохла), открой пикер: отмечена только B.
2. Верни слово в A, открой пикер.

**Ожидание глазами.**

A снова пригодна, но не отмечена; отмечена только B.

**Маркеры в логах.**

```
quizGroupStore / groupOptions: … selected=<B>
```

**Анти-проверки.**

* A не появилась в наборе сама.

**Прогон:** ✅

## M13. Быстрые тапы по галкам

**Что доказывает.**

Записи сериализованы: быстрые клики не теряют последний и не мигают.

**Вход.**

* 3+ пригодные группы, выбрано «Все».

**Шаги.**

1. Открой пикер, быстро отметь три группы подряд.
2. Закрой меню, убей и запусти приложение.

**Ожидание глазами.**

1. Галки ставятся и не мигают.
2. После перезапуска отмечены все три.

**Маркеры в логах.**

```
quizGroupStore: write … groups=<id1>
quizGroupStore: write … groups=<id1>,<id2>
quizGroupStore: write … groups=<id1>,<id2>,<id3>
```

**Анти-проверки.**

* Последняя запись — полный набор.

**Прогон:** ✅

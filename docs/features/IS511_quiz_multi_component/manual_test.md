## Словарь логов

Снимать: `adb logcat -d | grep "###CHAT###"` (тег `LogTags.CHAT`).

### picker — кандидаты и выбор

* `quizPicker: cores=[…]` — ядра словаря, которыми квиз умеет спросить
  (после фильтра `core && enabled && removedAt == null && TEXT`), по
  `position`. Пусто — спросить нечем.
* `Reduce ---message---: QuizComponentTypesLoaded(types=…, restoredSelectedRefs=…)`
  — загрузка пикера; `restoredSelectedRefs` — набор из prefs (пусто = не
  сохранено).
* `Reduce ---message---: ToggleQuizComponent(ref=…, checked=…)` — клик по
  галке; `SaveQuizPickerSelection(refs=…)` — запись набора.

### portion — порция раунда

* `getRandomWriteQuizList: groupFilter=<all|id> cores=[id, …]` — фильтры
  порции: группа и включённые ядра (id типов).
* `getRandomWriteQuizList: no core types` — пустой список ядер, порция
  пустая без запросов (не должно встречаться в проде).
* `getRandomWriteQuizList: portion grades=N earliest=… errors=… total=N words=N`
  — состав порции.
* `fetchData: no quiz cores for dictionary <id>` — у словаря нет ни одного
  кандидата (словарь без включённого ядра).

### round — раунды

* `RunEffect: LoadQuiz(reload=false)` — первый раунд сессии («Начать»),
  далее `QuizLoaded`; `LoadQuiz(reload=true)` — «Продолжить квиз», далее
  `QuizReLoaded`.
* `RunEffect: DeliverSystemMessages(messages=[…], then=NextQuestion)` —
  правило (и debug-стат) по одному, после последнего — вопрос.
* `Reduce ---message---: NextQuestion(content=MessageContent(value=Question(…)))`
  — вопрос структурный: `header`, `badge`, `value`.

## M1. Один кандидат — подменю скрыто

**Что доказывает.**

С одним ядром выбирать нечего: пункт «Компонент квиза» в меню не
показывается, вопросы идут по этому ядру.

**Вход.**

* Словарь, где единственное ядро — «Перевод» (новый словарь по умолчанию).
* Этот словарь текущий.

**Шаги.**

1. Открой квиз-чат.
2. Открой бургер-меню в аппбаре.

**Ожидание глазами.**

В меню: «Самые давние», «Частые ошибки» (в debug — «Show debug»). Пункта
«Компонент квиза» нет.

**Маркеры в логах.**

```
quizPicker: cores=[translation]
QuizComponentTypesLoaded(types=[…], restoredSelectedRefs=[])
```

**Анти-проверки.**

* Нет задизейбленного подменю с одной галкой (старое поведение).

**Прогон:** ✅

## M2. Два ядра — галки, все включены, последняя задизейблена

**Что доказывает.**

Д1а и Д2: без сохранённого выбора включены все ядра; единственную
включённую галку снять нельзя; подпись «минимум одно» под заголовком.

**Вход.**

* Словарь с двумя ядрами: «Перевод» и пользовательское «Определение»
  (конструктор компонентов: тип с шаблоном «текст», ядро, включён).
* Выбор пикера для словаря не сохранялся (свежая установка или другой
  словарь).

**Шаги.**

1. Открой квиз-чат, открой меню, раскрой «Компонент квиза».
2. Сними галку «Перевод».
3. Попробуй снять галку «Определение».
4. Включи «Перевод» обратно.

**Ожидание глазами.**

1. Под заголовком «Компонент квиза» мелкая подпись «минимум одно»; две
   галки, обе включены, обе активны.
2. «Перевод» снят; «Определение» осталось включённым и стало серым
   (задизейблено).
3. Клик по «Определение» ничего не делает.
4. Обе включены, обе снова активны.

**Маркеры в логах.**

```
ToggleQuizComponent(ref=BuiltIn(key=TRANSLATION), checked=false)
SaveQuizPickerSelection(refs=[UserDefined(name=Определение)])
```

**Анти-проверки.**

* Нет `ToggleQuizComponent(… checked=false)` на шаге 3 с пустым набором
  (редьюсер no-op, записи `SaveQuizPickerSelection` нет).
* Галки не прыгают после записи (подписка переиздаёт тот же набор).

**Прогон:** ✅

## M3. Раунд с двумя ядрами — вопросы обеих сторон

**Что доказывает.**

Д3/Д4: при двух включённых ядрах вопросы приходят то переводом, то
определением (случайно на слово), слово в раунде один раз, в заголовке
имя ядра.

**Вход.**

* Словарь M2, обе галки включены.
* Не меньше 10 слов с переводом, у части из них есть определение.

**Шаги.**

1. Нажми «Начать», пройди раунд целиком (отвечай или «Пропустить»).

**Ожидание глазами.**

Вопрос — пузырь из двух строк: «Перевод:» или «Определение:», ниже
значение жирным. Среди вопросов встречаются оба заголовка (у слов с
определением — случайно какой). Прежних заголовков «Переведи следующее
слово:» / «Какое слово связано с этим определением:» нет.

**Маркеры в логах.**

```
getRandomWriteQuizList: groupFilter=all cores=[1, 2]
NextQuestion(content=MessageContent(value=Question(question=QuizQuestion(header=Перевод, …
NextQuestion(content=MessageContent(value=Question(question=QuizQuestion(header=Определение, …
```

**Анти-проверки.**

* Одно слово не спрашивается дважды за раунд.
* Отчёт («Посмотреть отчёт») показывает значение без заголовка и без
  чипа: «✅ значение - ответ».

**Прогон:** ✅

## M4. Только «Определение» — раунд из слов с определением

**Что доказывает.**

Д3: фильтр порции в SQL — слова без определения в раунд не попадают,
раунд добирается из подходящих (не короче, пока есть из чего).

**Вход.**

* Словарь M2; определения есть у 5–7 слов, переводы у всех.
* В меню включено только «Определение».

**Шаги.**

1. Нажми «Начать», пройди раунд.

**Ожидание глазами.**

Все вопросы с заголовком «Определение:», ни одного «Перевод:». Раунд из
слов с определением (их число, если меньше лимита).

**Маркеры в логах.**

```
getRandomWriteQuizList: groupFilter=all cores=[2]
getRandomWriteQuizList: portion grades=N … total=N
```

**Анти-проверки.**

* Ни одного вопроса по слову без определения.
* Нет пропусков слов на стороне квиза: `total` в порции = число вопросов
  в раунде (страховка `toQuizItem → null` не срабатывает).

**Прогон:** ✅

## M5. Чип части речи

**Что доказывает.**

Д6: часть речи показывается мелким чипом слева от значения; без
значения — чипа нет; пользовательская опция — её текст; крупный системный
шрифт чип не ломает.

**Вход.**

* Словарь с ядром «Перевод» и встроенной «Частью речи».
* Слово A: часть речи «существительное»; слово B: без части речи; слово
  C: пользовательская опция части речи (например, «междометие»); слово D
  с длинным переводом (две строки в пузыре) и частью речи.

**Шаги.**

1. Пройди раунд, дождись вопросов по A, B, C, D.
2. В настройках системы поставь максимальный размер шрифта, вернись в
   чат, продолжи раунд (или начни новый).

**Ожидание глазами.**

1. A: под «Перевод:» строка «[сущ.] значение», чип мелкий, на фоне
   `secondaryContainer`, скруглён. B: значение от края, чипа нет. C: чип с
   текстом опции. D: значение переносится в своей колонке, чип у первой
   строки, вторая строка начинается под первой (висячий отступ).
2. Чип не выше строки значения, не обрезан сверху/снизу; значение
   переносится; чип не съедает ширину.

**Маркеры в логах.**

```
… QuizQuestion(header=Перевод, badge=сущ., value=…
… QuizQuestion(header=Перевод, badge=null, value=…
```

**Анти-проверки.**

* Чип не попадает в отчёт и в «Правильный ответ».
* Чип не меняет кегль/цвет значения (жирный, цвет `secondary`).

**Прогон:** ✅ (крупный шрифт — device-тест `QuestionBubbleTest`, fontScale 2)

## M6. Правило игры один раз

**Что доказывает.**

Д4: «Я даю подсказку — ты пишешь слово.» приходит отдельным пузырём
после «Начать» и только раз за сессию; после «Продолжить квиз» (напрямую
и через отчёт) правила нет, а пузырь юзера — «Продолжить квиз».

**Вход.**

* Любой словарь со словами.

**Шаги.**

1. Нажми «Начать».
2. Пройди раунд до финала, нажми «Продолжить квиз».
3. Пройди раунд, нажми «Посмотреть отчёт», затем «Продолжить квиз».

**Ожидание глазами.**

1. «Начать» превращается в пузырь на месте; после паузы въезжает
   пузырь правила; после паузы — первый вопрос. Три отдельных въезда.
2. Пузырь юзера «Продолжить квиз» (не «Начать»); сразу вопрос, правила
   нет.
3. То же: «Продолжить квиз», вопрос, правила нет.

**Маркеры в логах.**

```
RunEffect: LoadQuiz(reload=false) … QuizLoaded
RunEffect: DeliverSystemMessages(messages=[…chat_quiz_msg_system_rule…], then=NextQuestion)
RunEffect: LoadQuiz(reload=true) … QuizReLoaded
```

**Анти-проверки.**

* Правило и «Начать» не встают одним кадром (нет скачка приветствия).
* `QuizReLoaded` не сопровождается `DeliverSystemMessages` (вне debug).

**Прогон:** ✅ (путь через отчёт не гонялся — та же команда CONTINUE)

## M7. Выбор переживает перезапуск

**Что доказывает.**

Набор галок хранится пословарно в prefs и восстанавливается.

**Вход.**

* Словарь M2.

**Шаги.**

1. В меню оставь только «Определение».
2. Убей приложение (свайп из недавних), запусти, открой квиз-чат, меню.

**Ожидание глазами.**

Включено только «Определение», оно задизейблено; «Перевод» снят.

**Маркеры в логах.**

```
QuizComponentTypesLoaded(types=[…], restoredSelectedRefs=[UserDefined(name=Определение)])
```

**Анти-проверки.**

* Выбор другого словаря не затронут (переключи словарь — там свой набор).

**Прогон:** ✅

## M8. Старое сохранённое значение читается

**Что доказывает.**

Кодек набора читает одиночное значение прежнего формата без миграции.

**Вход.**

* Релиз 0.1.10 (прежний формат prefs: одно значение `user:<имя>`).

**Шаги.**

1. На 0.1.10 в словаре M2 выбери radio «Определение», закрой чат.
2. Обновись на сборку IS511 поверх (без удаления данных), открой чат, меню.

**Ожидание глазами.**

Включено только «Определение» (задизейблено), «Перевод» снят.

**Маркеры в логах.**

```
QuizComponentTypesLoaded(types=[…], restoredSelectedRefs=[UserDefined(name=Определение)])
```

**Анти-проверки.**

* Нет сброса на «все включены».

**Прогон:** ⏭ вручную не гонялся (нужна установка 0.1.10); покрыт unit-тестами кодека `getQuizPickerSelection decodes legacy single …`

## M9. Выбор действует со следующего раунда

**Что доказывает.**

Текущий раунд уже отобран; смена галок посреди раунда его не меняет.

**Вход.**

* Словарь M2, обе галки включены.

**Шаги.**

1. Нажми «Начать», ответь на 2–3 вопроса.
2. В меню оставь только «Определение».
3. Дойди до финала, нажми «Продолжить квиз».

**Ожидание глазами.**

1–2. Оставшиеся вопросы раунда — как были (могут быть «Перевод:»).
3. Новый раунд — только «Определение:».

**Маркеры в логах.**

```
getRandomWriteQuizList: … cores=[1, 2]   ← первый раунд
getRandomWriteQuizList: … cores=[2]      ← после «Продолжить»
```

**Анти-проверки.**

* Нет перезагрузки раунда в момент клика по галке.

**Прогон:** ✅

## M10. Пустой раунд

**Что доказывает.**

Принятое поведение (триаж IS511): если под фильтр не попало ни одной
лексемы, чат не падает и доходит до финала с нулями.

**Вход.**

* Словарь с двумя ядрами, определений нет ни у одного слова.
* Включено только «Определение».

**Шаги.**

1. Нажми «Начать».

**Ожидание глазами.**

«Начать» → правило → «Сессия завершена! 📈 Всего слов: 0 …» → «Твой
следующий шаг?» с кнопками. Без крэша.

**Маркеры в логах.**

```
getRandomWriteQuizList: … total=0
loadData: fetchData returned empty list
```

**Анти-проверки.**

* Нет `FATAL` в `adb logcat -d -b crash`.

**Прогон:** ✅

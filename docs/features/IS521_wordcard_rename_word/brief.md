# IS521 | Бриф: переименование слова в карточке падает со снекбаром

Issue: https://github.com/KilgoreT/PolyTrainer/issues/521
Ветка: `IS521_wordcard_rename_word` (от master `16eb32e6`).
Источник: баг от юзера (2026-10-02), воспроизводится в проде и в `.dev`.

## Проблема

В карточке слова правка самого слова не сохраняется: после ввода нового
значения появляется снекбар «Не удалось сохранить», в базе и в списке
остаётся старое слово. Переименование слова из карточки сломано целиком —
другого пути переименовать слово в карточке нет.

## Воспроизведение

1. Открыть карточку любого слова.
2. Тапнуть по слову, изменить его, подтвердить ввод.
3. Снекбар «Не удалось сохранить»; слово не изменилось.

Лог `.dev` (2026-10-02 13:55:27):

```
E ###WORDCARD###: effect UpdateWord(wordId=8, value=8888оорр) recovered to
OperationFailed(...): java.lang.IllegalStateException: Cannot access database
on the main thread since it may potentially lock the UI for a long period of time.
```

## Ожидаемое поведение

Новое значение слова сохраняется (с обрезкой пробелов, как сейчас),
карточка и список слов показывают новое значение, снекбара нет.

## Вне скоупа

- Проверка на дубль при переименовании в уже существующее слово — отдельная
  задача, если понадобится.

## В скоупе дополнительно

- Тот же дефект в `addWordSuspend` (не `suspend` при имени `…Suspend`) —
  чиним сейчас (решение юзера, 2026-10-02). Других таких методов нет
  (аудит в analysis.md).

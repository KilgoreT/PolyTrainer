# IS540 | Источники рода испанских существительных

Сверено 2026-11-01 на 10429 испанских существительных базы слов — статьи
русского Викисловаря, выгрузка kaikki от 2026-10-01.

## Как мерили

- **Покрытие** — у скольких наших существительных источник даёт один
  род: мужской или женский.
- **Надёжность** — где род есть и в русском издании, и в источнике, какая
  доля совпадает.
- **Дыра** — слова без рода в русском издании: 2683, из них 331 с
  большой буквы, это имена.

## Скачиваемые и бесплатные

- **Русский Викисловарь, категории статьи.** CC BY-SA, выгрузка уже на
  сервере. Род у 7746 существительных из 10429. Импорт его сейчас
  теряет.
- **Английский Викисловарь.** CC BY-SA, выгрузка уже на сервере и уже в
  базе слов, тот же формат. Род в тегах значений. Один род у 8311 из
  10429. С русским совпало 6540, разошлось 32 — 99,5%.
- **FreeLing, испанский словарь форм.** По файлу COPYING репозитория
  все данные пакета, кроме перечисленных там исключений, идут под AGPL, и
  испанский словарь форм в исключения не входит. В старом руководстве
  FreeLing для этого словаря указана LGPL-LR. Файл `data/es/dictionary/entries/MM.nom`
  в репозитории TALP-UPC/FreeLing на GitHub, 3 МБ, около 76 тысяч лемм.
  Род в теге формы: NCMS — мужской, NCFS — женский, NCCS — общий. Один
  род у 8040 из 10429. С русским совпало 6357, разошлось 47 — 99,3%.
  Омонимы с разным родом — corte, capital, orden, cometa, frente —
  помечены общим родом, как dentista и turista, поэтому общий род здесь
  неоднозначен. У papa только мужской, «la papa» нет.
- **Wikidata, лексемы.** CC0, дамп лексем и запросы SPARQL. Испанских
  существительных около 39 тысяч, род почти у всех: женский 19719,
  мужской 19156, без рода 113. Наших слов нашлось 6981, один род у 6245.
  С русским совпало 5012, разошлось 33 — 99,3%. Омонимы — отдельные
  лексемы.
- **Испанский Викисловарь через kaikki.** CC BY-SA, тот же формат, что
  читает наш импорт, выгрузка 2026-10-30 с дампа 2026-10-01. Род в
  заголовке части речи: «Sustantivo masculino», «Sustantivo femenino»,
  «Sustantivo masculino y femenino». Омонимы — отдельными заголовками. На
  выборке 40 слов без рода в русском: род у 24, у 14 нет статьи
  существительного — имена мест и редкие слова, у двух статья без рода.
- **Apertium, испанский словарь.** GPL-2.0, файл
  `apertium-spa.spa.metadix` в репозитории apertium/apertium-spa, 8 МБ.
  Род в парадигме: m, f, mf. По леммам грубо: один род у 1434 слов из
  дыры.

## Механизмы рода: точность и вклад

Мерено 2026-11-01 на 12835 значениях испанских существительных русского
издания, без имён собственных. Точность — совпадение с родом статьи
русского издания там, где он есть. Часть расхождений — ошибки самого
русского издания, как у «мед. кома».

|---|---|---|
| английский Викисловарь | 99,45 | 9081 |
| FreeLing | 99,27 | 8928 |
| испанский Викисловарь | 98,46 | 7619 |
| согласие других источников | 99,35 | 9280 |
| конкретный род сильнее общего | 97,74 | 266 |
| большинство, два против одного | 100 | 71 |
| суффиксы | 99,59 | 1971 |
| примеры значения с артиклем | 98,81 | 168 |
| мост через переводы | 96,0 | 75 |

- **Согласие других источников** — все источники, что знают написание
  существительным, дают один род на все статьи.
- **Конкретный род сильнее общего** — одни источники дают общий род,
  остальные один и тот же конкретный, как у adversario.
- **Суффиксы** — -ción 903 из 907, -sión 104 из 104, -dad 421 из 421,
  -tad, -tud, -umbre без ошибок, -ismo 298 из 301, -aje 41 из 42,
  -miento 148 из 148.
- **Мост через переводы** — значение русского издания связано со
  статьёй английского через русские переводы английского слова в
  русском Викисловаре: «мед. кома» — coma — «кома».

## Расхождения с русским изданием

- **Ошибки русского издания.** autoritarismo, caroteno, chicle, abacá в
  русском женского рода, во всех остальных — мужского. crin и
  confrontación в русском мужского, в остальных — женского.
- **Омонимы.** boa: la boa — змея, el boa — боа-шарф.

## Платные и онлайн

- **ABBYY Lingvo API.** REST API словарей с русским. При запуске в 2016
  году бесплатно в пределах 50 000 символов, словари лицензированы у
  издательств. Нынешние условия и пара испанский–русский не
  подтверждены. Отвечает по слову, базу не даёт.
- **Мультитран.** Продаётся настольная программа для Windows с
  испанским словарём, 257 000 терминов. Продажа базы и API не найдены —
  только письмом разработчику.
- **Яндекс.Словарь API.** Бесплатный ключ, 17 пар языков. В
  документации ответа рода нет, только часть речи.
- **Lexicala, K Dictionaries.** Платный API, род есть. Пары испанский–
  русский нет: испанский идёт на английский, японский, нидерландский и
  другие.
- **RAE, словарь испанского языка.** Род есть у каждого слова, но API
  нет, открытой лицензии нет. Enclave RAE — веб-платформа по подписке,
  открытого API не найдено.

## Ограничения

- Ни один источник не даёт род у всех слов: имена и редкие слова
  остаются.
- Омонимы с разным родом есть везде. Род однозначен, только когда
  источник даёт один род на все значения написания.
- CC BY-SA требует указывать авторство, CC0 — нет.
- AGPL у FreeLing — копилефт с условием для работы по сети: использование
  её данных на сервере может обязать открыть код сервера. Решать до
  подключения FreeLing.

# IS540 | Решения

История фикса. Номера сквозные, не меняются.

- **Д1 (юзер, 2026-10-31). Главное — чтобы приходил род.** Род
  испанского существительного должен приходить в компонент «Род» со
  снимка и из карточки слова. Это цель IS536 Д1, которая перестала
  выполняться после IS536 Д63.
- **Д2 (юзер, 2026-11-01). Род из категорий статьи русского издания.**
  Импорт читает род из категорий статьи русского Викисловаря: мужской,
  женский и общий.
- **Д3 (юзер, 2026-11-01). Нейронка не источник данных.** Род из знаний
  модели отвергнут: нейронка обрабатывает информацию, а не порождает её.
  Угадывание рода по окончанию -o и -a тоже отвергнуто.
- **Д4 (юзер, 2026-11-01). Снимки источников и сборка, без ручной
  правки.** Данные всех словарей хранятся по источникам и сводятся в
  сборку слова, у каждого параметра есть источник. Ошибки словарей руками
  не правятся: если словари спорят, «Род» пустой, списка проверки нет.
- **Д5 (юзер, 2026-11-01). Правила рода.** Род статьи, затем согласие
  испанского и английского Викисловарей и FreeLing, затем «конкретный
  сильнее общего», затем большинство два против одного. Если хоть один
  словарь даёт у написания разный род, одного голоса мало. Суффиксы и
  мост через переводы только проверяют, в том числе род статьи. При
  расхождении «Род» пустой.
- **Д6 (юзер, 2026-11-01). Общий род — мужской по умолчанию.** У слов
  общего рода, как dentista, и у двуродовых, как mar, в «Роде» стоит
  «м.р.».
- **Д7 (юзер, 2026-11-01). Род от нейронки без данных отбрасывается.**
  Если нейронка поставила род значению, у которого рода нет в сборке,
  сервер его отбрасывает и пишет об этом в журнал. Форма ответа не
  меняется.
- **Д8 (юзер, 2026-11-01). Источник параметра — только в базе.**
  Источник хранится в базе вместе с параметром. Ответ сервера не
  меняется.
- **Д9 (юзер, 2026-11-01). Слово без статьи в русском издании.**
  Значение берётся из английского Викисловаря и идёт в «Толкование», род
  берётся оттуда же. Если «Толкования» в словаре нет, сервер рекомендует
  его завести. Это частичный откат IS536 Д63, только для слов без статьи в
  русском издании. Перевод и толкование нейронкой отложены в бэклог.
- **Д10 (юзер, 2026-11-01). Английский текст — в «Перевод» с пометкой
  «англ.».** Уточняет Д9. У слова без статьи в русском издании английский
  текст значения ложится в «Перевод» с пометкой «англ.» и в
  «Толкование», если оно есть в словаре. Рекомендации завести
  «Толкование» нет. Приложение такое значение уже показывает.
- **Д11 (юзер, 2026-11-01). Лемму по тапу выбирает текст.** По тапу
  лемма приходит из разбора текста снимка: fuera в «si yo fuera» — это
  ser. Если у этой леммы нет русских значений, приходит её английский
  текст с пометкой «англ.».
- **Д12 (юзер, 2026-11-01). FreeLing берём.** Это ещё не продукт: данные
  FreeLing под AGPL используем, код бэкенда не открываем. Данные из
  FreeLing лежат отдельным файлом, чтобы при нужде опубликовать их. Перед
  выходом в продукт вернуться к лицензии.
- **Д13 (юзер, 2026-11-01). Рекомендаций компонентов в фиксе нет.**
  Нынешняя рекомендация «Рода» решается по знаниям нейронки и
  противоречит Д3, она снимается. Рекомендации по полям записи — в
  бэклоге, сначала проверка на настоящих словах.
- **Д14 (юзер, 2026-11-01). Проверки рода на сервере нет.** Отменяет Д7.
  Сервер не знает, что компонент пользователя «Род» — это род: у него
  нет ключа, есть только имя и подписи опций. Род только из данных
  держит инструкция нейронки: опцию «Выбора» она ставит только по данным
  значения. Если нейронка всё же поставит род без данных, сервер его
  пропустит, такое ловит контрольный набор. Поля-основания у строк
  «Выбора» нет, заметки об отброшенном роде в журнале нет.
- **Д15 (юзер, 2026-11-01). Схема хранения — отдельной спекой.**
  Устройство базы слов описывает своя спека бэкенда WDB, а не документ
  фикса.
- **Д16 (юзер, 2026-11-01). HLD не нужен.** Если понятно, что и как
  делать, после спек — сразу код.
- **Д17 (юзер, 2026-11-02). Английское толкование — как строка любого
  значения.** Уточняет Д10. Строка значения ложится в первое включённое
  ядро, у английского значения это его толкование. «Перевод» — частный
  случай первого ядра. Особого правила для словаря без «Перевода» нет: у
  него первое ядро другое, туда строка и ляжет. В «Толкование» —
  тоже, если оно есть.
- **Д18 (оркестратор, 2026-11-02). Голос и мост — как в замерах рода.**
  По скрипту `docs/features/IS540_gender_from_record/research/gender_mechanisms.pl`
  бэкенда, давшему одобренные 97,1 из 100. Голос других источников —
  итог правил согласия, «конкретный сильнее общего» и большинства,
  голосует только источник с одним родом на все статьи. Мост ищется,
  только когда английский Викисловарь даёт написанию разный род в разных
  статьях. Формы множественного числа FreeLing рода не дают. Закрывает
  вопрос ревью A-В1.
- **Д19 (оркестратор, 2026-11-02). Отвергнутая выгрузка.** Выгрузка, где
  пропало больше 5% слов, не применяется и заново не скачивается, а
  выгрузка новее проверяется тем же порогом против прежних данных.
  Команды «применить всё равно» нет: это новая функциональность.
  Закрывает вопрос ревью C-В1.

## Словарь логов

Снимать: `adb logcat -d | grep -E "###CHAT###|###DB###"`.

* `Destructive migration: …` (`###DB###`, ERROR) — Room стёр БД; в M1 этой строки быть НЕ должно.
* `NextQuestion(… QuizQuestion(header=…, badge=<сокращение|null>, value=…` (`###LEXEME###`) — чип вопроса.

## M1. Обновление поверх 0.1.12 — данные на месте

**Что доказывает.**

Миграция 14→15 зарегистрирована и прошла: словарь получил 6 новых опций в
новом порядке, слова и их части речи не потерялись. Без регистрации Room
молча стёр бы базу (destructive fallback).

**Вход.**

* На девайсе dev-сборка 0.1.12 (v14) со словами, у части слов выбрана часть речи.
* Затем `installDebug` ветки IS515 поверх (данные не удалять).

**Шаги.**

1. Открой словарь: слова на месте.
2. Открой слово с частью речи: значение то же.
3. Открой выбор части речи у любого слова.

**Ожидание глазами.**

Список из 12: Существительное, Глагол, Прилагательное, Наречие,
Местоимение, Числительное, Предлог, Междометие, Фразовый глагол,
Коллокация, Идиома, Фраза.

**Маркеры в логах.**

```
(нет «Destructive migration»)
```

**Анти-проверки.**

* Слова и группы не пропали; нет сырых ключей вроде `phrasal_verb` вместо названия.
* Чип выбранного значения в карточке — сокращение («колл.»), список выбора — полные названия.

**Прогон:** ✅

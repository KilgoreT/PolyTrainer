# IS525 | Бриф: языки словаря

Issue: https://github.com/KilgoreT/PolyTrainer/issues/525 (подзадача #523,
подфича 1, фаза 0).
Ветка: `IS525_dictionary_languages` (от master `8fd0e508`).
Основание: решение Д5 в `docs/features/IS523_words_from_text/brief.md`.

## Цель

У словаря появляются два языка — **изучаемый** и **язык перевода**. Их
выбирают при создании и редактировании словаря. Нужны будущей фиче «слова
из текста» (распознавание, выбор словарей-источников, перевод), но
полезны и сами по себе: словарь наконец знает, какой язык в нём учат.

## Что есть сейчас (факты из кода)

- **Словарь** (`DictionaryDb`, таблица `dictionaries`): `id`,
  `numericCode` (страна → флаг, **необязательный**), `name`, `addDate`,
  `changeDate`. Языка нет. База — версия 15.
- **Форма словаря** (`modules/screen/dictionary/form`), одна на три входа:
  первичная настройка, создание, редактирование. Раскладка сверху вниз:
  заголовок → строка «превью флага + название» → поиск флага → сетка
  флагов → кнопка. Флаг можно не выбирать и можно снять.
- **Языки стран** уже загружаются в форму: `CountryFlagItem.languages` —
  строки вида `"English (en-US)"`, основной язык первым; сейчас по ним
  только ищется флаг. Полный прогон массива (2026-10-05): 732 строки, 729
  с кодом; без языка 3 необитаемые территории (Антарктида, Буве, Херд) —
  для них действует правило «нет языка → английский».
- **Путь сохранения:** форма → `DictionaryUseCase.addDictionary /
  updateDictionary(name, numericCode)` → `CoreDbApi.DictionaryApi` →
  `WordDao`. Языки нужно протянуть по всей цепочке.
- **Бэкап** («Экспорт / импорт данных») — копия файла базы. Отдельного
  формата нет: новые поля попадают в бэкап сами, старый бэкап при импорте
  проходит миграцию. `DictionaryDump` в коде — мёртвый, не используется.
- **Миграции:** последняя со сменой схемы — 13→14; образец теста —
  `MigrationFrom13to14`; регистрация — `RoomModule`; экспорт схемы —
  `schemas/…/16.json`.

## Решения (из Д5, согласованы с юзером)

1. У словаря пара языков: изучаемый и язык перевода.
2. **Язык перевода** — по умолчанию язык телефона; можно поменять.
3. **Изучаемый язык** — при выборе флага подставляется основной язык
   страны; в выборе — языки страны и возможность выбрать любой другой.
4. ~~Языковые семьи в списках стран не фильтруются.~~ **Пересмотрено
   (юзер, 2026-10-05): фильтруем по четырём критериям**, у источника
   данных (модуль `flags`), чтобы остальное приложение их не видело:
   - Ф1 — строка без кода языка отбрасывается (3 строки: Антарктида,
     Буве, Херд);
   - Ф2 — собирательные коды ISO 639-2 (семьи и группы: `cau`, `tut`,
     `sit`, `inc`, `ber`, `bh`) не предлагаются нигде (6 записей в 3
     странах, ни одна не основной язык);
   - Ф3 — страна без языков после Ф1–Ф2 не попадает в список флагов
     (247 стран из 250);
   - Ф4 — код без названия на устройстве не попадает в полный список
     языков (в юзкейсе; списки стран не трогает — там английское название
     из библиотеки).
   Не фильтруются: макроязыки (`ms`, `sw`), региональные варианты,
   территории с языком (флаг «для красоты»).
5. У существующих словарей языки заполняются автоматически; оба языка
   можно исправить в редактировании словаря.
6. **Оба языка обязательные (юзер, 2026-10-05).** Пустого состояния нет.
   Изучаемый: есть флаг — основной язык страны; **флага нет — английский**.
   Перевод: язык телефона (он есть всегда). Существующие словари заполняет
   сама миграция по тем же правилам.

## Допущения (мои — отменяются одним словом)

- **Код языка — с региональным вариантом, как его даёт библиотека
  флагов** (`es-MX`, `en-GB`, `pt-BR`; без региона — `ru`, `haw`). Юзер
  (2026-10-05): хочет учить именно мексиканский испанский с его
  спецификой — вариант языка не отбрасываем. У 163 стран из 250 основной
  язык идёт с регионом. Показ — «испанский (Мексика)»; общий язык без
  региона выбирается из полного списка. Вариант используется дальше
  (запросы к модели, источники по языку с откатом на общий язык) — в
  следующих подфичах.
- **Язык перевода по умолчанию — язык телефона без региона** (`ru`).
- **Изучаемый язык и язык перевода могут совпадать** (словарь терминов).
- **Смена флага** меняет изучаемый язык на основной язык новой страны,
  пока юзер не выбрал язык вручную; ручной выбор флаг не затирает.
- **Полный список языков** («другой язык») — стандартный список языков
  Android (~190) с поиском; названия — на языке интерфейса.
- **Где ещё показывать языки** — нигде, только в форме словаря.

## Вне скоупа

- Всё остальное из IS523: сеть, бэкенд, фото, распознавание, источники.
- Использование языков где-либо, кроме формы (квиз, карточка слова).

## Решения по форме

- **В1 (2026-10-05). Одна строка-сводка языков, после флагов.** Формат
  «English → Русский»; стоит ниже выбора флага (сначала флаг, потом языки —
  список изучаемых уже отфильтрован по стране). Нажатие открывает лист с
  обоими выборами.

  ```
  [флаг]  НАЗВАНИЕ СЛОВАРЯ
          ______________________

  [ 🔍 Поиск по стране или языку… ]
  (флаги)

  Языки      English → Русский    ›

  [        Создать        ]
  ```

  Допущение (моё): в листе две вкладки — «Изучаю» и «Перевод», в каждой
  список с поиском; у «Изучаю» сверху языки выбранной страны, ниже все
  остальные.

- **В2 (2026-10-05). Флаги — одна горизонтальная строка вместо сетки.**
  Один ряд флагов, листается горизонтально; поиск флага остаётся.
  Допущение (моё): выбранный флаг встаёт в строке первым, чтобы не
  теряться среди 250.

  ```
  [флаг]  НАЗВАНИЕ СЛОВАРЯ
          ______________________

  [ 🔍 Поиск по стране или языку… ]
  (🇦🇫) (🇦🇱) (🇩🇿) (🇦🇸) (🇦🇩) →  листается вбок

  Языки      English → Русский    ›

  [        Создать        ]
  ```

Вопросов не осталось. План реализации — `plan.md`.

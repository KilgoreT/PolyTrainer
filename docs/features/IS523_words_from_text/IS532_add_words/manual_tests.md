Форма — `backend/docs/handbook/feature-flow/spec-checks.md`, раздел 3: заголовок кейса несёт адреса
строк спеки устройства `docs/handbook/specs/words-add-from-photo/spec.md`

название, шаги-атомы, последний шаг «Напиши “ок”». Состояние и лог после
«ок» проверяет агент.

перед кейсом `adb logcat -c`. Кейсы идут по порядку: поздние опираются на
слова, записанные ранними. На время прогона таймаут экрана 30 минут
(`adb shell settings put system screen_off_timeout 1800000`), после —
вернуть прежний (600000).

## Словарь логов

### VOCAB — вкладка «Слова» (`###VOCAB###`)

- `OCR line N: …` — строка распознанного текста.
- `lookup run=N tokens=K` — запрос ушёл: номер запуска, число токенов.
- `lookup run=N outcome=dict=D words=M lemmas=L` — ответ: словарь снимка,
  слова, леммы всех слов; `outcome=denied=<причина>`, `outcome=unavailable`
  — отказ и «сервер не ответил», как в IS529.
- `photoMappingStore: read dict=D raw=<строка|none> parsed=true|false` —
  чтение запомненных соответствий; `raw=none` — для словаря ещё не
  запоминали; `parsed=false` при `raw` — строка не разобралась, идут
  умолчания.
- `photoMappingStore: write dict=D value=translation=<id|none>,gloss=…,
  examples=…,partOfSpeech=…` — соответствия запомнены; `<id>` — id
  компонента словаря.
- `photoForm run=N dict=D outcome=loaded components=C options=O groups=G
  existing=E remembered=true|false` — форма словаря собрана: включённых
  компонентов лексемы, опций «Части речи» (12), групп, лемм словаря с
  текстом лемм ответа, были ли запомненные соответствия;
  `outcome=dictionary missing` — словарь снимка удалён; `outcome=failed:
  <исключение>` — чтение упало.
- `photoAdd run=N outcome=added words=W lexemes=X` — записано: слов, в
  которые легли лексемы, и лексем; `outcome=rejected <Rejected…>` — отказ
  до первой вставки с причиной (`GroupMissing(groupId=…)`,
  `WordMissing(wordId=…)`, `TypeUnavailable(typeId=…)`,
  `NoCoreValue(wordIndex=…, lexemeIndex=…)`, `DictionaryMissing`).

### Reduce — редьюсер вкладки (`###VOCAB###`)

- `Reduce ---message---: <Msg>` — входящее сообщение. Тяжёлые data-Msg
  пишутся именем класса: `TokensReady`, `WordsLookedUp`,
  `PhotoFormLoaded`; остальные — со значениями: `TogglePhotoCard(lemma=run)`,
  `DeletePhotoLexeme(lemma=run, key=ruwiktionary/1.verb.2)`,
  `DeletePhotoExample(lemma=…, key=…, index=0)`, `OpenPhotoSheet(sheet=…)`,
  `ClosePhotoSheet`, `UpdatePhotoDraft(text=…)`, `SubmitPhotoText`,
  `ResetPhotoText(…)`, `SetPhotoPartOfSpeech(…)`, `SetPhotoCardTarget(…)`,
  `SetPhotoCardGroup(…)`, `SetPhotoCommonGroup(groupId=…)`,
  `SetPhotoMapping(kind=…, target=…)`, `TogglePhotoMapping`,
  `TogglePhotoNotAdded`, `RequestPhotoAdd`, `ConfirmPhotoAdd`,
  `CancelPhotoAdd`, `RetryPhotoAdd`, `PhotoAddFinished(lexemeCount=…,
  wordCount=…, requestId=N)`, `PhotoAddRejected(failure=…, requestId=N)`,
  `RequestClosePhotoWords`, `ConfirmClosePhotoWords`, `StayInPhotoWords`.
- `Reduce ---step---: <атом> | k=v` — один шаг состояния; у Msg окна
  цепочка шагов (например, удаление лексемы — `deleteLexeme`, `markDirty`,
  `refreshSummary`). Атомы:
  - запуск (IS529): `showPhotoSourceChooser | requestId=N`,
    `returnToPhotoSourceChooser`, `startRecognizing`, `startLooking`,
    `showNoPhotoWords`, `showPhotoError | errorRes=…`, `hidePhotoWords |
    requestId=N` — закрытие любым путём и после записи;
  - сборка окна (Ш1): `startFormLoading | dictionaryId=D words=M lemmas=L`,
    `applyForm | components=C groups=G cards=K notAdded=J`, `showFormError
    | error=DICTIONARY_MISSING|LOAD_FAILED`;
  - пересчёты: `refreshExistsMarks | exists=E` — лексем с «есть»,
    `refreshCoreMarks | lacksCore=X` — лексем «не попадёт в ядро»,
    `refreshSummary | lexemes=… words=… existing=… lacksCore=… enabled=…`
    — счёт на кнопке и её состояние;
  - карточки (Ш3): `toggleCard | lemma=… expanded=…`, `deleteCard |
    lemma=…`, `deleteLexeme | lemma=… key=…`, `deleteExample | lemma=…
    key=… index=…`, `applyTextEdit | lemma=… key=… field=Translation|Gloss|
    Example(index=…) length=…`, `dropEmptyExamples | … dropped=…`,
    `resetText | … field=…`, `setPartOfSpeech | … optionId=<id|null>`,
    `setCardTarget | lemma=… target=Existing(wordId=…)|NewWord`,
    `setCardGroup | lemma=… group=AsCommon|All|Group(groupId=…)`,
    `setCommonGroup | groupId=<id|null>`, `setMappingTarget | kind=
    TRANSLATION|GLOSS|EXAMPLES|PART_OF_SPEECH target=Component(componentId=
    …)|None`, `toggleMappingExpanded | expanded=…`, `toggleNotAddedExpanded
    | expanded=…`, `openSheet | sheet=CommonGroup|CardGroup|CardTarget|
    PartOfSpeech|MappingTarget|TextEdit`, `closeSheet`, `updateSheetDraft |
    length=…`, `markDirty` — первое изменение, после него закрытие с
    вопросом;
  - запись (Ш4, В3): `askAddConfirm | lexemes=… words=…`,
    `closeAddConfirm`, `startAdding | words=… lexemes=…`, `showAddFailure |
    failure=…`, `clearAddFailure`, `resetDeadGroup | groupId=…`,
    `resetDeadTarget | wordId=…`, `dropComponent | typeId=… mapping=…`;
  - закрытие (В2): `askCloseConfirm`, `closeCloseConfirm`.
- `Reduce ---step---: no-op | reason=…` — событие пришло и намеренно
  проигнорировано: `… foreign run N` — результат чужого или закрытого
  запуска; `requestPhotoAdd: already adding` / `button disabled` / `already
  asking`; `confirmPhotoAdd: already adding` — второе нажатие «Да»;
  `openPhotoSheet: adding`, `requestClosePhotoWords: adding` — окно
  неактивно на время записи; `retryPhotoAdd: nothing failed`.
- `RunEffect: <эффект>` под `###MATE###` — эффект ушёл в handler:
  `LoadPhotoForm(…)`, `AddPhotoWords(…)`, `SavePhotoMapping(…)`.

### NETWORK — слой сети (`###NETWORK###`)

- `POST /v1/words/lookup -> <код> in <мс>ms` — одна строка на обмен; ключ
  не печатается.

### Сервер (`ssh … docker logs lexeme-server`)

- `lookup words run_id=N subject=kilg tokens=K words=M took=…` — та же
  пара номер запуска / число слов, что на устройстве.

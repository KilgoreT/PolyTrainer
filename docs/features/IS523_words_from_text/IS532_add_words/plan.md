## Риски и неочевидное

- **Размер ответа:** толкования и примеры идут дважды — в `candidates`
  для старых клиентов и в `lemmas`; у «run» 60–70 КБ, страница с десятком
  частотных глаголов — около мегабайта без сжатия. Сжатие — в Э3;
  измеренный размер — граница для снятия `candidates` отдельной правкой
  контракта после Э8.
- **Размер State окна:** сотни карточек с десятками значений; лог
  редьюсера — только сводкой (Э6).
- **Одно нажатие — сотни лексем:** страница в 150 слов даёт до 750
  лексем-кандидатов в словарь и в тренировку; откат — новые слова
  выделением на вкладке, лексемы в существующих словах — по одной в
  карточке. Страховка — алерт Д23; добавление по одной лемме — Backlog.
- **Лексемы без источника в коде:** `source` — непрозрачная строка, новые
  источники (Cambridge, LLM) появятся в окне без релиза приложения;
  правила окна от источника не зависят.
- **Сеть до сборки базы** — без лексем английского Викисловаря (WFT-74).
- **Омонимы одной части речи** — одна карточка; разложить их по разным
  словам за один раз нельзя.
- **Правленое значение** («брать» вместо «брать; хватать; …») при
  следующем снимке «есть» не получит.
- **IS523 Д14:** с ним соответствия переезжают из
  `photo_words_mapping_dict_<id>` в поле типа компонента, ключ удаляется.
- **Кеш WFT-46** (отложен): ключ кеша без языка перевода. При включении
  кеша лексемы с переводом станут багом — учесть в той задаче.

# IS532 | Набросок экрана: добавление слов со снимка

Набросок окна добавления на проверку глазами. Опора — [бриф](brief.md),
решения Д1–Д18, спека `docs/handbook/specs/words-add-from-photo/spec.md`
(AWP). Версия 3 (2026-10-12): окно — черновик (Д15), без галочек:
ненужное удаляется, нужное правится, всё оставшееся добавляется одним
нажатием; пять лексем у леммы, часть речи у лексемы (Д16, Д20); общая
группа «Все» и своя
у карточки (Д17); примеры в «Пример» (Д18).

- **Данные в набросках настоящие**: строки выгрузок Викисловаря
  (`backend/testdata/kaikki`, `source_samples.md` IS530) — «run», «bank»,
  «fuera», «London». Числа «take» — с прода.
- **Пометки**: 📌 остаётся как в IS529, 🔄 меняется, ❇️ новое.
- **Набросок — не макет**: отступы, цвета и шрифты — в плане, по
  прецедентам экрана слов.

> [!NOTE]
> Технические и мелкие решения наброска — мои, помечены «(моё)», отменяются
> одним словом.

## Три сценария на этом экране (Д1)

- **Новое слово с лексемой и частью речи** — развернуть карточку, удалить
  лишние лексемы-кандидаты крестиками, «Добавить». Куда — «новое слово»,
  часть речи — у карточки.
- **Лексема в существующее слово** — у карточки выбрать «в «run»», удалить
  лишнее, «Добавить».
- **Слово со всеми лексемами** — ничего не удалять, «Добавить»: в словарь
  лягут все пять лексем-кандидатов карточки (Д16).

## Что меняется относительно IS529

- 📌 Выбор источника (камера, галерея), индикатор с подписью фазы, «Слов не
  найдено» и ошибки — тот же диалог, без изменений.
- 🔄 Список слов: был диалог на 80 % высоты, одна строка на слово, только
  просмотр. Стал окном-черновиком на весь экран: карточки, удаление,
  правка.
- ❇️ Шапка: общая группа «Все» (Д17) и «куда пишем» (Д11, Д18).
- ❇️ Карточка слова: пять лексем-кандидатов (Д16), крестики удаления,
  пометки «есть» и «англ.», правка текстов, своя группа (Д2, Д3, Д5, Д12,
  Д15, Д17).
- ❇️ Панель «Добавить» внизу (Д5, Д9).
- 📌 Подпись «Данные: Wiktionary, CC BY-SA 4.0» — в конце списка, как
  сейчас.

## 1. Окно целиком

**Окно на весь экран, а не диалог**: у слова несколько карточек по пять
лексем с примерами, плюс клавиатура при правке — в диалог на 80 % высоты
это не влезает. Выбор камеры и галереи, индикатор и ошибки остаются диалогом;
окно открывается на месте диалога, когда слова пришли, и любым закрытием
возвращает на вкладку «Слова» того же словаря.

```text
┌──────────────────────────────────────────────┐
│ ×  Слова с фото                              │
├──────────────────────────────────────────────┤
│ Группа для всех                        Все ▾ │
│ Куда пишем: перевод → «Перевод»,             │
│ часть речи → «Часть речи»,                   │
│ примеры → «Пример»                  изменить │
├──────────────────────────────────────────────┤
│ run                           есть в словаре │
│ в тексте: ran, run                           │
│ бежать, бегать · бег · In a liquid … ▸ × │
├──────────────────────────────────────────────┤
│ ran                                          │
│ в тексте: ran                                │
│ Yarns coiled on a spun-yarn winch.       ▸ × │
├──────────────────────────────────────────────┤
│ bank                       есть в словаре: 2 │
│ в тексте: bank                     ⌂ Finance │
│ банк (финансовое учреждение) · банк …    ▸ × │
├──────────────────────────────────────────────┤
│ London                                       │
│ в тексте: London                             │
│ Лондон · лондонский                      ▸ × │
├──────────────────────────────────────────────┤
│ Не добавить: 1                             ▸ │
├──────────────────────────────────────────────┤
│ Данные: Wiktionary, CC BY-SA 4.0             │
╞══════════════════════════════════════════════╡
│ [     Добавить 17 значений в 4 слова       ] │
└──────────────────────────────────────────────┘
```

- **Окно — черновик** (Д15): всё, что в нём видно, будет добавлено. Счёт
  на кнопке — то, что осталось. Галочек и статусов нет.
- **«×» и системная «Назад»** — закрыть окно. Если что-то удалял или
  правил — сначала вопрос (раздел 9); во время «Добавляю…» не действуют.
- **Окно модальное**: пока открыто, словарь и вкладку не сменить. Смерть
  процесса — окно не восстанавливается, удаления и правки теряются (как
  ожидание ответа, WFT-65). Портрет (IS529 Д7).
- **Шапка** — общая группа и «куда пишем» (раздел 2). Первый элемент
  списка, уезжает при прокрутке.
- **Карточка — одна на лемму** (Д4, Д20): «ran» и «run» в тексте дают
  одну карточку «run» с лексемами всех частей речи; часть речи — у
  каждой лексемы. Порядок — по первому появлению в тексте. В наброске
  опущена карточка «rin» — диалектного варианта «run».
- **Карточки свёрнуты** (моё): снимок страницы — 50–150 слов, развёрнутые
  карточки растянули бы список на сотни строк.
- **Свёрнутая карточка — три строки**:
  - лемма и «есть в словаре» (Д3), если таких слов несколько — их число;
  - слова из текста, из которых пришла лемма, и своя группа «⌂ Finance»,
    если поставлена (Д17);
  - первые тексты перевода. «▸» — развернуть, «×» — удалить карточку
    (Д15).
- **«Не добавить»** — свёрнутый блок в конце: «не найдено» и «не
  загрузилось» (раздел 8).
- **Панель внизу закреплена**: кнопка со счётом, причина неактивной
  кнопки (раздел 9).
- **Карточек нет** (все слова «не найдено»): шапки и панели нет, блок «Не
  добавить» развёрнут, над ним «Добавить нечего».

```text
┌──────────────────────────────────────────────┐
│ ×  Слова с фото                              │
├──────────────────────────────────────────────┤
│ Добавить нечего                              │
├──────────────────────────────────────────────┤
│ Не добавить: 3                             ▴ │
│ qwrt — не найдено                            │
│ Grimmauld — не загрузилось                   │
│ hjkl — не найдено                            │
├──────────────────────────────────────────────┤
│ Данные: Wiktionary, CC BY-SA 4.0             │
└──────────────────────────────────────────────┘
```

## 2. Шапка: группа и «куда пишем»

```text
┌──────────────────────────────────────────────┐
│ Группа для всех             Harry Potter 1 ▾ │
├──────────────────────────────────────────────┤
│ Куда пишем                          свернуть │
│ Перевод (русский)                «Перевод» ▾ │
│ Толкование (англ.)            не добавлять ▾ │
│ Часть речи                    «Часть речи» ▾ │
│ Примеры                           «Пример» ▾ │
│ Выбор запомнится для этого словаря           │
└──────────────────────────────────────────────┘
```

Подписи строк — от языков словаря: «Перевод (русский)» по языку
перевода, «Толкование (англ.)»; у словаря с языком перевода en —
«Перевод (English)», потому что толкование там и есть текст перевода.

**Группа для всех** (Д7, Д17):

- общая на все добавляемые слова; у карточки можно поставить свою, она
  переопределяет общую (раздел 3);
- по умолчанию всегда «Все» — без группы; не запоминается: каждый снимок
  выбирается заново;
- только существующая группа словаря или «Все»; нижний лист с одним
  выбором и подсказкой, где создать группу (Д8, моё).

```text
┌──────────────────────────────────────────────┐
│ Группа для всех слов                         │
├──────────────────────────────────────────────┤
│ (•) Все                                      │
│ ( ) Harry Potter 1                           │
│ ( ) Неправильные глаголы                     │
├──────────────────────────────────────────────┤
│ Новую группу создают на вкладке «Группы»     │
└──────────────────────────────────────────────┘
```

**«Куда пишем»** — блок соответствий (Д11, Д18):

- свёрнут в сводку с настоящими именами компонентов словаря, «изменить»
  раскрывает;
- четыре строки: русский перевод, английское толкование, часть речи,
  примеры;
- у каждой — компонент словаря или «не добавлять»;
- умолчания: перевод — в «Перевод», если он выключен — в первое
  включённое текстовое ядро; толкование не добавляется; часть речи — в
  «Часть речи»; примеры — в «Пример»;
- выбор запоминается для словаря.

**Что можно выбрать в строке** (моё):

- перевод и толкование — включённые компоненты словаря шаблона «текст»;
- часть речи — только встроенная «Часть речи» или «не добавлять» (IS523
  Д16);
- примеры — включённые компоненты шаблона «текст с подписью»;
- один компонент — один вид данных: выбрал компонент, занятый другим видом,
  — тот вид переходит в «не добавлять»;
- толкование без перевода идёт в одно место: в свой компонент, если он
  ядро, иначе в компонент перевода (строка «англ.»).

```text
┌──────────────────────────────────────────┐
│ Английское толкование →                  │
├──────────────────────────────────────────┤
│ (•) не добавлять                         │
│ ( ) «Перевод» · сейчас в нём перевод     │
│ ( ) «Определение»                        │
└──────────────────────────────────────────┘
```

**Ядро обязано заполниться** (Д6): проверяется у каждой лексемы-кандидата.
Та, у которой при текущих соответствиях ядро осталось бы пустым
(например, «перевод → не добавлять», «толкование → ядро», а у лексемы
Русского Викисловаря толкования нет), помечена «не попадёт в ядро». Пока
она в окне, «Добавить» неактивна — причина на панели внизу, потому что
шапка уезжает при прокрутке. Выход — удалить её крестиком или поправить
соответствия. Если ни один вид данных не идёт в ядро, сводка красная.

```text
┌──────────────────────────────────────────────┐
│ Куда пишем                          свернуть │
│ Русский перевод               не добавлять ▾ │
│ Английское толкование         «Определение» ▾│
│ Часть речи                    «Часть речи» ▾ │
│ Примеры                           «Пример» ▾ │
├──────────────────────────────────────────────┤
│ бежать, бегать          не попадёт в ядро  × │
│ To move swiftly.                     англ. × │
└──────────────────────────────────────────────┘
```

## 3. Карточка развёрнута

Пример: в словаре уже есть слово «run» со значением «управлять».

```text
┌──────────────────────────────────────────────┐
│ run                           есть в словаре │
│ в тексте: ran, run                         × │
│ Куда: в «run» ▾        Группа: как у всех ▾  │
├──────────────────────────────────────────────┤
│ глагол ▾                                     │
│ бежать, бегать                             × │
├──────────────────────────────────────────────┤
│ сущ. ▾                                       │
│ бег                                        × │
├──────────────────────────────────────────────┤
│ прил. ▾                                      │
│ In a liquid state; melted or molten. англ. × │
├──────────────────────────────────────────────┤
│ глагол ▾                                     │
│ управлять                             есть × │
├──────────────────────────────────────────────┤
│ глагол ▾                                     │
│ проехать (практически всегда имеется       × │
│   в виду красный сигнал светофора)           │
├──────────────────────────────────────────────┤
│ ещё 125 значений                             │
└──────────────────────────────────────────────┘
```

- **Карточка — лемма** (Д20): «run» одна, в ней лексемы разных частей
  речи. Омонимы («bank» — банк и берег) — одна карточка, лексемы подряд,
  как в словаре: номера омонимов двух Викисловарей друг другу не
  соответствуют.
- **«×» в шапке карточки** — удалить лемму целиком, со всеми лексемами
  (Д15).
- **«глагол ▾» у лексемы** — часть речи вручную (Д5), своя у каждой
  лексемы: 12 опций «Части речи» и «без части речи». Пришла часть речи
  без опции (артикль, союз) — «без части речи ▾».
- **«Куда: в «run» ▾»** — куда класть лексемы карточки (Д2, раздел 5).
- **«Группа: как у всех ▾»** — своя группа карточки (Д17): лист с «как у
  всех», «Все» и группами словаря. Поставлена — в свёрнутой карточке
  видна «⌂ Finance», лемма идёт в неё вместо общей.
- **Пять лексем-кандидатов** в карточке (Д16, Д20): по одной на каждую
  часть речи в порядке сервера — у «run» глагол, сущ., прил., — затем
  добор до пяти по порядку сервера: ещё два глагола. Внутри части речи
  порядок сервера: сначала Русский Викисловарь, там готовый перевод,
  потом английский: с русским переводом, затем без, редкие и устаревшие
  в конец. Источник у строки не подписан (моё): порядок его и так задаёт,
  а строк всего пять. «ещё 125 значений» — просто текст, не
  раскрывается: нужны ещё — ищи сам. Удалённые из пяти не замещаются
  скрытыми.
- **Строка лексемы-кандидата** (Д12, Д15):
  - над текстом — часть речи «глагол ▾»;
  - верхний текст — то, что ляжет в компонент перевода, у английской
    лексемы с переводом порядок: толкование, под ним русский перевод (так
    видно, откуда перевод);
  - «×» — удалить лексему безвозвратно, вместе с её примерами;
  - примеры — под переводом, в кавычках, у каждого свой «×»;
  - «англ.» — русского перевода нет, в компонент перевода ляжет английский
    текст (IS523 Д7(в));
  - «есть» — в одном из слов с этим текстом уже есть лексема с таким же
    переводом или толкованием в любом текстовом компоненте (Д3). Не
    удалил — при добавлении пропускается, дубля нет (Д21); в счёт на
    кнопке не входит, на панели «N уже есть — не добавятся». Правка текста
    на новый снимает пометку, и лексема добавится.
- **Нажатие на текст — правка** (раздел 6): перевод, толкование, пример.
- **Родительское значение** («To move swiftly.») — тоже лексема-кандидат
  со своим «×», его уточнения — с отступом под ним (моё). В пятёрку
  входит на общих основаниях.

## 4. Сколько видно у «take»

- **«take»**: глагол 109 (16 Русского Викисловаря и 93 английского) и
  сущ. 16 → видно 5: глагол, сущ., затем три глагола из Русского, «ещё 120
  значений». 5 строк вместо 125.
- **«run»**: глагол, сущ., прил., затем два глагола, «ещё 125».
- **Свёрнутая карточка** — 3 строки при любом числе значений.
- Больше пяти человек в этом окне не оценит (Д16); точный выбор по
  контексту текста потом даст модель.

## 5. Куда класть: новое слово или существующее

```text
┌──────────────────────────────────────────────┐
│ bank                       есть в словаре: 2 │
│ Куда: в «bank» (банк) ▾                      │
├──────────────────────────────────────────────┤
│ Куда добавить значения «bank»                │
│ (•) в «bank»: банк, банкомёт · 2 значения    │
│     группы: Finance                          │
│ ( ) в «bank»: берег · 1 значение             │
│     без групп                                │
│ ( ) новое слово «bank» — третье в словаре    │
├──────────────────────────────────────────────┤
│ Слово войдёт в группу «Harry Potter 1»       │
│ вместе со своими 2 старыми значениями.       │
└──────────────────────────────────────────────┘
```

- **Выбор у каждой карточки** (Д2): существующее слово с текстом леммы или
  новое слово.
- **Одинаковых слов несколько** — у каждого его первые переводы, число
  значений и группы, чтобы отличить (Д5) и видеть, что уже добавлено
  (Д13).
- **Подсказка о группе** (Д13): существующее слово входит в группу
  целиком, вместе со старыми значениями, — это сказано прямо в листе.
  Группа — своя у карточки, если поставлена, иначе общая. Если «Все»,
  подсказки нет.
- **Умолчание** (моё): слова с этим текстом нет — «новое слово»; есть —
  первое по порядку словаря.
- **Лексемы разных частей речи** ложатся в одно слово: у «run» лексема
  «бежать» с «Частью речи» глагол и «бег» с сущ. — одна лемма «run»
  (Д20).

## 6. Правка текстов

```text
┌──────────────────────────────────────────────┐
│ брать; хватать; взять, схватить            × │
│   (также перен.)                             │
├──────────────────────────────────────────────┤
│ [брать                                     ] │
│   было: брать; хватать; взять, …    сбросить │
├──────────────────────────────────────────────┤
│ брать                             изменено × │
└──────────────────────────────────────────────┘
```

- **Нажатие на текст открывает правку** (Д15): перевода, толкования или
  примера. Правят то, что запишется. Толкование можно упростить своими
  сокращениями.
- **«сбросить»** возвращает текст из словаря.
- **Пробелы по краям обрезаются.** Пустой перевод — «не попадёт в ядро»;
  пустой пример — пример удалён.
- **После правки — пометка «изменено».** «Есть» сверяется по новому тексту:
  сократил до «брать», а «брать» в словаре уже есть — появится «есть».
  Правленое значение при следующем снимке «есть» не получит.

## 7. Несколько лемм: «fuera» в испанском словаре

```text
┌──────────────────────────────────────────────┐
│ fuera                                        │
│ в тексте: fuera                              │
│ снаружи · out!, get out! · наружу …      ▸ × │
├──────────────────────────────────────────────┤
│ ser                                          │
│ в тексте: fuera                              │
│ to be (essentially or identified as) …   ▸ × │
├──────────────────────────────────────────────┤
│ ir                                           │
│ в тексте: fuera                              │
│ to go (away from speaker and listener)   ▸ × │
└──────────────────────────────────────────────┘
```

- **Слово из текста даёт карточку на каждую лемму**: «fuera» — сама
  «fuera», а как форма — «ser» и «ir» (Д5, «несколько лемм»). В тексте
  было одно из трёх — две лишние карточки удаляются крестиками.

```text
┌──────────────────────────────────────────────┐
│ fuera                                        │
│ в тексте: fuera                            × │
│ Куда: новое слово ▾    Группа: как у всех ▾  │
├──────────────────────────────────────────────┤
│ наречие ▾                                    │
│ снаружи                                    × │
├──────────────────────────────────────────────┤
│ междометие ▾                                 │
│ out!, get out!                       англ. × │
├──────────────────────────────────────────────┤
│ наречие ▾                                    │
│ наружу                                     × │
├──────────────────────────────────────────────┤
│ наречие ▾                                    │
│ на улице; вне дома                         × │
├──────────────────────────────────────────────┤
│ наречие ▾                                    │
│ вон!; долой!                               × │
├──────────────────────────────────────────────┤
│ ещё 2 значения                               │
└──────────────────────────────────────────────┘
```

- **У междометия только его английское значение** «out!, get out!»:
  русские значения наречия ему не достаются (WFT-73).

## 8. Слова, которые не добавить

```text
┌──────────────────────────────────────────────┐
│ Не добавить: 2                             ▴ │
│ qwrt — не найдено                            │
│ Grimmauld — не загрузилось                   │
└──────────────────────────────────────────────┘
```

- **«не найдено» и «не загрузилось» остаются в списке для информации,
  добавить их нельзя** (Д14): пользователь ищет такие слова сам. Повтора
  запроса для «не загрузилось» в этой итерации нет.
- **Блок в конце списка, свёрнут** (моё): чаще всего это мусор
  распознавания. Если карточек нет вовсе — развёрнут (раздел 1).

## 9. Добавление

```text
┌──────────────────────────────────────────────┐
│ [     Добавить 23 значения в 4 слова       ] │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│ Добавлять нечего                             │
│ [                 Добавить                 ] │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│ [                Добавляю…                 ] │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│ 2 значения не попадут в ядро                 │
│ [                 Добавить                 ] │
└──────────────────────────────────────────────┘
```

- **На кнопке — счёт того, что осталось в окне** (Д15): лексемы и слова.
  Одно нажатие добавляет всё (Д5, «много слов за раз»).
- **Всё удалено** — кнопка неактивна, «Добавлять нечего». Остались только
  «есть» — то же.
- **«N уже есть — не добавятся»** на панели (Д21): такие лексемы в счёт не
  входят и не пишутся.
- **Нажатие активной кнопки — вопрос** (Д23), всегда, не только на больших
  страницах; «отмена» — окно как было.

```text
┌──────────────────────────────────────┐
│ Добавить 17 значений в 4 слова?      │
├──────────────────────────────────────┤
│ Отмена                            Да │
└──────────────────────────────────────┘
```
- **Причина неактивной кнопки — на панели**: «не попадут в ядро» (Д6),
  «ни одно ядро не заполняется»; шапка со сводкой уезжает при прокрутке,
  панель — нет.
- **Группы**: каждая лемма идёт в свою группу карточки, если поставлена,
  иначе в общую (Д17). В группу входит и существующее слово вместе со
  старыми лексемами (Д13).
- **«Добавляю…»** — окно неактивно до конца записи, второго нажатия нет:
  дублей нет (Д5).
- **Всё добавилось** — окно закрывается, виден экран слов (Д9). Внизу —
  сообщение со счётом (моё).

```text
┌──────────────────────────────────────────────┐
│ Добавлено 23 значения в 4 слова              │
└──────────────────────────────────────────────┘
```

- **Запись одна на всё** (моё): содержимое окна пишется одной транзакцией
  — добавилось всё или ничего. Ошибка — окно остаётся как было,
  «Повторить» (Д5, без дублей).

```text
┌──────────────────────────────────────────────┐
│ Не добавилось — ничего не записано           │
│ [                Повторить                 ] │
└──────────────────────────────────────────────┘
```

- **Закрыть после удалений или правок** («×» или «Назад») — сначала
  вопрос (моё). Если ничего не трогал — окно закрывается сразу.

```text
┌──────────────────────────────────────┐
│ Закрыть без добавления?              │
├──────────────────────────────────────┤
│ Остаться                     Закрыть │
└──────────────────────────────────────┘
```

- **Примеры идут в «Пример»** с подписью «Wiktionary» (Д18), если
  компонент включён и примеры не удалены. **«Тренировать» нет** (Д9).

## 10. Что набросок требует от сервера

- **Лемма без части речи**: сервер склеивает записи одной леммы разных
  частей речи в одну (Д20), лексемы идут по частям речи в порядке статьи,
  внутри — сначала Русский Викисловарь, потом английский; у английского —
  сначала с переводами, потом без, редкие и устаревшие в конец (WFT-71).
- **У лексемы** — часть речи ключом опции приложения, русские переводы
  без повторов, английское толкование, примеры, подпись таблицы у
  непривязанных переводов, пометы («авиац.», «спорт.» — серым, в словарь
  не пишутся), признак родительского значения и ссылка на него у
  уточнений. «London» получает «Лондон» Русского Викисловаря с ключом
  `noun`, хотя в английском он имя собственное.
- **Без правила «все блоки»** (WFT-66.7, WFT-73). Пока база слов на
  сервере не собрана — только лексемы Русского Викисловаря.
- Слова текста, из которых пришла лемма, и отсечение до пяти приложение
  делает само — сервер отдаёт все лексемы.

# IS523 | Поверхностное исследование (2026-10-05)

Цель: получить ровно столько фактов, чтобы уверенно разбить фичу на
подфичи. Глубокие исследования (качество распознавания на реальных фото,
промпты, надёжность источников) — внутри подфич.

Чего здесь **нет**: реальных вызовов моделей (ключа нет) и замеров
качества. Стоимость — расчёт по ценам каталога и оценкам объёма.

## Коротко

### Деньги

Сценарий «фото → список слов → значения 10 слов» стоит:

| Класс модели | Пример | Сценарий |
|---|---|---|
| Дешёвые | `gpt-5-nano`, `gemini-2.5-flash-lite` | $0.006–0.008 |
| Средние | `gemini-3.1-flash-lite`, `gpt-5-mini` | $0.024–0.028 |
| Дорогие | `claude-haiku-4.5`, `claude-sonnet-5` | $0.09–0.17 |

- **Распознавание фото моделью** стоит $0.0003–0.002 — несколько
  процентов сценария. Экономить на нём через ML Kit незачем. Выбор «ML Kit
  или модель» — вопрос качества и языков, а не денег.
- **Основная цена — разбор словарных страниц**, 60–75 % суммы.
  Двухшаговый флоу (Д10: сначала список слов, значения только для
  отмеченных) бьёт ровно сюда.
- На дешёвых моделях сценарий стоит около цента. При своём бэкенде (Д13)
  это расход сервера на один сценарий пользователя — основа для будущих
  лимитов и тарифов.

### Словари

- **Free Dictionary API** не отвечал во время проверки: три запроса, все с
  ошибкой 522. Причина не выяснена, решения по нему нет — разбираемся в
  исследовании подфичи 5.
- **Wiktionary** отвечает быстро и структурированно: определения на
  английском, части речи, примеры, фразовые глаголы. Русского перевода в
  структурном виде нет.
- **Идея со ссылками работает.** Cambridge отдал страницы на запросы с
  подписью Android-приложения, без блокировок. Словарная статья — 1–2
  тысячи токенов, разбор слова — $0.0004–0.002. Англо-русская страница
  даёт переводы («взаимодействовать, общаться»). Проверено одиночными
  запросами с домашнего IP; под нагрузкой не проверялось.
- **Веб-поиск нейронкой** — $0.007 за запрос плюс токены, примерно в 10
  раз дороже прямой ссылки. В первую версию не берём.

### Что изменилось против прежней нарезки

- **Бэкенд сразу (Д13).** Приложение ходит только на свой тонкий бэкенд,
  бэкенд — в OpenRouter. Ключ, промпты и выбор модели — на сервере. Экран
  ввода ключа и поле модели в настройках не делаются. Подфичи 4 и 5
  состоят из серверной части (адрес + промпт) и клиентской. Словарные
  страницы загружает телефон, на бэкенд уходит текст статьи.
- **Решение Д2 «распознаём через ML Kit» снято.** Движок выбирается
  внутри подфичи 4 замером на реальных фото. Модель умеет все языки,
  включая кириллицу, и может вернуть текст и список слов одним вызовом.
- **«Открытый словарь» и «свои ссылки» — один механизм** (подфича 5).
  Wiktionary становится предустановленной ссылкой-шаблоном. Отдельно
  остаётся только управление источниками (7).
- **Подфича 3 сама по себе ничего не показывает пользователю.** Её можно
  слить с четвёртой, но тогда четвёртая станет самой большой и
  рискованной — поэтому оставлены раздельно.

## 2. Открытые словари

| Источник | Проба | Результат |
|---|---|---|

Причина не выяснена (разовый сбой, закрытие сервиса, ограничение по региону?) — вывод о пригодности делается в исследовании подфичи 5. |
| Wiktionary REST (`en.wiktionary.org/api/rest_v1/page/definition/{слово}`) | `interact`, `hola`, `break_down` | http 200 за 0.4–0.7 с. Структура: язык → часть речи → значения с примерами. | Русский Викисловарь | `interact` | REST-значений нет (http 501); через `action=parse` — сырой викитекст, для иностранных слов заполнен редко. |

**Перевода на русский в структурном виде открытые словари не дают.** В
английском Викисловаре переводы — редкие шаблоны в викитексте (`interact`
→ один: «взаимодействовать»).

**Вывод.** Рабочий открытый источник на момент проверки — Wiktionary:
определения на английском, части речи, примеры — да; русский перевод —
нет. Free Dictionary API — открытый вопрос. Перевод берётся из
двуязычного источника по ссылке (см. §3) или его делает нейронка.

## 3. Свои источники по ссылке (Cambridge)

Пробы с домашнего IP, 2026-10-05:

| Запрос | Ответ |
|---|---|
| `dictionary.cambridge.org/dictionary/english/interact`, UA `curl` | http 200, 334 КБ, 0.4 с |
| то же, UA `okhttp/4.12.0` (как у Android-приложения) | http 200, 334 КБ |
| то же, UA мобильного Chrome | http 200, 334 КБ |
| `…/english-russian/interact` | http 200, 270 КБ; переводы есть: «взаимодействовать, общаться», «воздействовать, влиять друг на друга» |
| `…/english/break-down` | http 200, 369 КБ; 10 значений |

- Блокировок и проверок «я не робот» на одиночных запросах **нет**. Под
  нагрузкой и с серверных IP не проверялось.
- HTML страницы — 270–370 КБ, но после снятия разметки: весь текст —
  ~3–4 тыс. токенов, сама словарная статья — ~1–2 тыс. Отсюда оценка
  «4000 токенов на слово» в §1.
- У Cambridge устойчивые классы разметки (`def ddef_d`, `trans dtrans`,
  `eg deg`) — конкретный сайт можно разбирать и без нейронки; для
  произвольной ссылки юзера универсален только разбор нейронкой.
- Словосочетания: дефис в ссылке (`break-down`); у Wiktionary —
  подчёркивание (`break_down`). Правило — часть шаблона источника.

**Вывод.** Идея «юзер даёт ссылку со словом» технически работает и
дёшева: $0.0004–0.002 за слово на дешёвых и средних моделях. Wiktionary —
тот же механизм (шаблон ссылки + разбор ответа), а не отдельная подфича.

## 4. Веб-поиск нейронкой

Документация OpenRouter (`/docs/features/web-search`): поиск Exa —
**$0.007 за запрос** (до 10 результатов), сверх того — токены модели на
обработку результатов; «родной» поиск провайдера — по его тарифам.

**Вывод.** На дешёвой модели слово через веб-поиск — около $0.008 против
$0.0006 по прямой ссылке: **в ~10 раз дороже**, результат менее
предсказуем. Веб-поиск — не основа, а возможный запасной путь позже.

## 5. Что это меняет в брифе

  фото; модель умеет все языки и может вернуть текст и список слов одним

- **Д4** — подтверждается: источники значений = шаблон ссылки + разбор
  нейронкой; Wiktionary — предустановленный шаблон; Free Dictionary API —
  открытый вопрос (не отвечал во время проверки, разобраться в подфиче 5);
  русский перевод — из двуязычной ссылки или от нейронки.
- **Веб-поиск** — вне первой версии.
- Нарезка — см. brief.md, раздел «Нарезка на подфичи».

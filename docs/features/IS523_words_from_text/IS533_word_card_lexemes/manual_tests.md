# IS533 | Ручники: значения из словаря в карточке слова

Форма — как у IS532 (`../IS532_add_words/manual_tests.md`): заголовок кейса
несёт адреса строк спеки `docs/handbook/specs/word-card-lexemes/spec.md`
(WCL). Словарь логов — тот же, что у окна снимка, плюс строки карточки
слова под `###WORDCARD###`: `candidates lookup run=N word=W outcome=…`,
`candidates form run=N word=W outcome=…`, `candidates add run=N word=W
outcome=…`, шаги атомов `Reduce ---step---: openCandidates | wordId=…
requestId=…`, `applyCandidatesForm | components=… cards=…`,
`refreshCandidatesExists | exists=…`, `refreshCandidatesSummary | …`,
`startAddingCandidates | lexemes=…`, `hideCandidates | requestId=…`.

Кейсы написаны на словаре «био» после прогона IS532 («run» с пятью
лексемами, три «bank», группы Finance и Harry Potter 1, компонент
«Definition»). Прогон 2026-10-13 юзер делал на своём словаре «Mexico»
(es→ru, слова «semana», «corrían», «qwrtk») короткими кейсами по одному;
итоги — в строках «Прогон». Кейс WCL-15 добавлен после прогона (Д5) и
не гонялся.

## WCL-08.1, WCL-08.2, WCL-08.3, WCL-07.1, WCL-07.3, WCL-07.4 Кнопка в карточке и диалог

Вход:
- dev-сборка с ключом; слово «run» в «био» (5 лексем) и новое слово «take»
  без лексем, заведённое панелью «+»

Шаги:
1. Открыть карточку «take»: под списком лексем кнопка «Добавить значения из
   словаря». Нажать.
2. Дождаться разделов; прокрутить до атрибуции и обратно.
3. Закрыть крестиком; открыть карточку «run» — кнопка на месте.

Ожидания:
- экран (1): кнопка есть у пустого слова; после нажатия признак загрузки,
  затем заголовок «take», строка «Куда пишем» с «изменить», раздел с пятью
  строками и «ещё 121 значение», «Данные: Wiktionary, CC BY-SA 4.0»,
  внизу «Добавить 5 значений»
- экран (2): список прокручивается, кнопка видна всегда; у строк нет «Куда»
  и «Группа», общей группы и блока «не добавить»
- экран (3): кнопка есть и у слова с лексемами
- сборка без ключа (`LEXEME_ACCESS_KEY` пустой) → кнопки нет
- лог: `candidates lookup run=1 word=… outcome=dict=6 words=1 lemmas=1`,
  `candidates form run=1 … outcome=loaded … existing=1 remembered=…`,
  `applyCandidatesForm | components=4 cards=1`

Прогон: ✅ 2026-10-13 (юзер, словарь «Mexico» после смены языка на es→ru; первый заход на ru→en дал «Язык словаря не поддерживается»): «semana» — диалог, пятёрка, кнопка со счётом; удаления и запись одного значения; кнопка на месте у слова с лексемами. Прокрутка отдельно не проверялась. Замечание юзера → переделка: вместо большой кнопки — вторая FAB над «+».

## WCL-04.1, WCL-04.2, WCL-06.1 Леммы-формы и пометка «есть»

Шаги:
1. Открыть карточку «run» → кнопка → дождаться разделов.
2. Завести слово «running» панелью «+», открыть карточку → кнопка.

Ожидания:
- экран (1): первый раздел без заголовка — лемма «run»; второй с
  заголовком «форма слова «rin»» и пометкой «past participle»; у пяти
  лексем «run», добавленных окном снимка, пометка «есть», «5 уже есть — не
  добавятся», «Добавлять нечего»
- экран (2): первый раздел — «running» (прилагательное, наречие,
  существительное…), второй — «форма слова «run»» с пометкой «present
  participle and gerund»
- лог: `refreshCandidatesExists | exists=5` у «run», `exists=0` у «running»

Прогон: ✅ 2026-10-13 (юзер): «corrían» → один раздел «форма слова «correr»» с пометкой, пятёрка; «semana» после записи — «есть», «1 уже есть — не добавится», «Добавить 3 значения». Замечание юзера → Д5: у раздела формы нужен выбор «переименовать слово» (кейс WCL-15).

- экран (3): без вопроса — «Добавляю…», диалог закрылся, внизу карточки

## WCL-15.1, WCL-15.2, WCL-15.3 Переименование слова-формы в лемму

Шаги:
1. Открой карточку «corrían» → кнопка словаря.
2. Под заголовком «форма слова «correr»» нажми «переименовать слово в
   «correr»» — маркер ●; нажми ещё раз — ○; нажми снова — ●.
3. Удали всё, кроме двух строк; «Добавить 2 значения».
4. Посмотри карточку.

Ожидания:
- экран (2): выбор снят по умолчанию, переключается нажатием
- экран (4): заголовок карточки «correr», две новые лексемы; на вкладке
  «Слова» слово «correr»
- лог: `toggleCandidatesRename | renameTo=correr`, `startAddingCandidates
  | lexemes=2 renameTo=correr`, `candidates add … added words=1 lexemes=2`

Прогон: ✅ 2026-10-13 (юзер, одно значение вместо двух): `toggleCandidatesRename | renameTo=correr` → `startAddingCandidates | lexemes=1 renameTo=correr` → `candidates add run=1 word=16 outcome=added words=1 lexemes=1`; карточка «correr» по слову юзера. После Д7 шаги атомов называются `toggleCandidatesLemmaWord | choice=Rename(lemma=correr)` и `startAddingCandidates | lexemes=N choice=…`.

## WCL-15.1, WCL-15.3, WCL-15.4 Перенос в существующее слово

Вход:
- в словаре есть «correr» с лексемой «бегать» (заведено руками) и слово
  «corrían» без лексем

Шаги:
1. Открой карточку «corrían» → кнопка словаря.
2. Под «форма слова «correr»» проверь две строки: «переименовать слово в
   «correr»» и «перенести в «correr» и удалить «corrían»».
3. Нажми «перенести…» — маркер ●; у строки-кандидата «бегать» пометка
   «есть в «correr»», под выбором «в «correr» уже есть 1 такое же
   значение».
4. Удали всё, кроме «бегать» и ещё одной строки; «Добавить 1 значение».
5. Посмотри список слов.

Ожидания:
- экран (3): кнопка внизу считает без «бегать»
- экран (4): диалог и карточка закрылись, открыт список
- экран (5): одно слово «correr» с лексемами «бегать» и новой; «corrían»
  нет
- лог: `refreshCandidatesLemmaExists | existsInLemma=1 sameValues={correr=1}`,
  `toggleCandidatesLemmaWord | choice=Transfer(lemma=correr, wordId=…)`,
  `startAddingCandidates | lexemes=1 choice=Transfer(…)`, `candidates add
  … outcome=added words=1 lexemes=1`, `hideCandidates`, затем выход
  карточки (`NavigateBack`)

Прогон: ✅ 2026-10-13 (юзер, слово «corren» без своих лексем, одно значение): `candidates form … existing=2`, `refreshCandidatesLemmaExists | existsInLemma=1 sameValues={correr=1}`, `toggleCandidatesLemmaWord | choice=Transfer(lemma=correr, wordId=16)`, `startAddingCandidates | lexemes=1 choice=Transfer(…)`, `candidates add run=1 word=18 outcome=added words=1 lexemes=1`; база: «corren» удалено, у «correr» две лексемы, сирот нет; список по слову юзера.

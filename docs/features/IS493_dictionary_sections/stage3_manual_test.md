# IS493 / Э3 — Ручной прогон: создание групп (корневой уровень)

Формат — по `docs/handbook/guides/manual-test-scenarios.md`.

## Шапка

- Выполнять построчно сверху вниз. Один пункт — одно действие.
- `ВИЖУ` — сверить с экраном дословно. Пометка `НЕТ` — элемента быть не должно.
- **Логи:** фичевого лог-контракта в Э3 нет (ошибки мутаций пишутся тегом
  `###GROUPS###` — смотреть только при сбоях). Блоки `ЛОГ` отсутствуют.
- Сборка: `debug` APK после фазы 3, ветка `IS493_dictionary_sections`.
- ТК10 требует смену языка устройства (ru ↔ en) — выполнять последним из
  основных: меняет локаль всего девайса.
- Данные: словарь Э2-прогона (12+ слов); группы этап создаёт сам.

## Подготовка

1. Открыть приложение, таб словаря, вкладка «Группы».
2. Убедиться: строка «Все» на месте (голубой фон), групп ниже нет.

---

## ТК1. Создание группы: FAB → шторка → группа в списке

1. Тап по FAB «+».

```
ВИЖУ  шторка снизу с полем ввода — вид как у шторки
      добавления слова на «Словах» (тот же скрим-затемнение)
      список («Все») виден позади сквозь затемнение
      НЕТ FAB (скрыт, пока шторка открыта)
```

2. Ввести «Дом».
3. Тап по кнопке отправки в поле.

```
ВИЖУ  шторка закрылась
      под «Все» — строка «Дом» со счётчиком «0» и шевроном
      у строки «Дом» есть kebab (⋮)
      у строки «Все» kebab'а НЕТ
      FAB «+» вернулся
```

## ТК2. Алфавитный порядок и место «Все»

1. Создать группу «Быт» (FAB «+», ввести, отправить).
2. Создать группу «Аптека».

```
ВИЖУ  порядок сверху вниз:
      «Все» (первая всегда)
      «Аптека»
      «Быт»
      «Дом»
```

## ТК3. Live-фильтр при вводе

1. Тап по FAB «+».
2. Ввести «б».

```
ВИЖУ  сквозь затемнение: в списке осталась «Быт»
      «Все» на месте (вне фильтра)
      НЕТ «Аптека», НЕТ «Дом»
```

3. Стереть ввод (пустое поле).

```
ВИЖУ  все три группы вернулись
```

4. Закрыть шторку свайпом вниз (или «назад»).

```
ВИЖУ  шторка закрылась
      список полный: «Аптека», «Быт», «Дом»
      FAB вернулся
```

## ТК4. Дубликат: «Дом» и «дом» — одно имя

1. Тап по FAB «+».
2. Ввести «дом».
3. Тап по кнопке отправки.

```
ВИЖУ  шторка ОСТАЛАСЬ открытой, ввод «дом» сохранён
      под полем текст «Имя уже занято»
      НЕТ новой группы в списке
```

4. Заменить текст на «Сад» — текст ошибки исчез при вводе.
5. Тап по кнопке отправки.

```
ВИЖУ  шторка закрылась
      порядок: «Аптека», «Быт», «Дом», «Сад»
```

## ТК5. Резерв: «Все» создать нельзя

1. Тап по FAB «+».
2. Ввести «все».
3. Тап по кнопке отправки.

```
ВИЖУ  шторка открыта, ввод сохранён
      под полем текст «Имя зарезервировано»
```

4. Закрыть шторку свайпом вниз.

## ТК6. Переименование через kebab

1. Тап по kebab (⋮) строки «Сад».

```
ВИЖУ  меню из двух пунктов:
      «Переименовать» (с иконкой карандаша)
      «Удалить» (с иконкой корзины)
```

2. Тап по «Переименовать».

```
ВИЖУ  шторка с предзаполненным «Сад»
      список позади отфильтрован по имени (видна «Сад» и «Все»)
```

3. Стереть, ввести «Огород».
4. Тап по кнопке отправки.

```
ВИЖУ  шторка закрылась
      «Огород» в списке, «Сад» НЕТ
      порядок: «Аптека», «Быт», «Дом», «Огород»
      (позиция изменилась по алфавиту — известное поведение)
```

## ТК7. Переименование в занятое и своё имя

1. Kebab «Огород» → «Переименовать».
2. Стереть, ввести «дом».
3. Тап по кнопке отправки.

```
ВИЖУ  шторка открыта, ввод «дом» сохранён
      под полем «Имя уже занято»
      в списке по-прежнему «Огород»
```

4. Стереть, ввести «ОГОРОД» (своё имя в другом регистре).
5. Тап по кнопке отправки.

```
ВИЖУ  шторка закрылась, snackbar'а НЕТ (своё имя — не дубликат)
      в списке «ОГОРОД»
```

## ТК8. Удаление с конфирмом

1. Тап по kebab строки «ОГОРОД».
2. Тап по «Удалить».

```
ВИЖУ  диалог «Удалить группу?»
      кнопка «Удалить»
      НЕТ FAB (скрыт под конфирмом)
```

3. Тап по кнопке «Удалить».

```
ВИЖУ  диалог закрылся
      «ОГОРОД» исчез из списка
      порядок: «Все», «Аптека», «Быт», «Дом»
      FAB вернулся
```

4. Kebab «Аптека» → «Удалить» → в диалоге нажать «назад»/мимо диалога.

```
ВИЖУ  диалог закрылся
      «Аптека» НА МЕСТЕ (отмена ничего не удалила)
```

## ТК9. Раскрытие пустой группы

1. Тап по строке «Быт».

```
ВИЖУ  шеврон «Быт» повернулся вверх
      под строкой текст «пусто»
```

2. Тап по строке «Быт» повторно.

```
ВИЖУ  свернулась, «пусто» исчез
```

## ТК10. Резерв на другой локали (смена языка девайса)

1. Сменить язык устройства на English.
2. Открыть приложение, вкладка «Группы».

```
ВИЖУ  строка «All» первой (виртуальная, локализована)
      группы «Аптека», «Быт», «Дом» на месте (имена как введены)
```

3. Тап по FAB «+», ввести «All», отправить.

```
ВИЖУ  шторка открыта, под полем ошибка резерва (англ. текст)
```

4. Заменить текст на «Все», отправить.

```
ВИЖУ  та же ошибка резерва под полем (резерв обеих локалей
      работает на любом языке устройства)
```

5. Закрыть шторку. Вернуть язык устройства на русский.

## ТК11. Рестарт: группы переживают

1. Убить приложение (свайп из recents).
2. Открыть заново, вкладка «Группы».

```
ВИЖУ  «Все», «Аптека», «Быт», «Дом» — как до рестарта
```

## ТК12. Смена словаря: группы пословарные

1. Сменить словарь через AppBar на второй словарь.

```
ВИЖУ  список групп второго словаря ПУСТ (только «Все»)
      НЕТ «Аптека»/«Быт»/«Дом»
```

2. Создать здесь группу «Тест».
3. Сменить словарь обратно.

```
ВИЖУ  «Аптека», «Быт», «Дом» (без «Тест»)
```

## Автоматически покрытое (вручную не проверять)

- Вся валидация (normalize trim+NFC, дубли case-insensitive, self-exclusion
  rename, резерв, Valid(normalized)) — юнит-тесты domain (8) + транзакционные
  androidTest `GroupMutationsTest` (17: включая NFC на реальной БД, дубль
  после trim, create после rename-освобождения, rename в резерв/soft-deleted,
  физическую чистку word_groups прямым счётчиком).
- Шторка/фильтр/kebab/конфирм-логика (25 reducer-кейсов: гонки dismiss,
  спам submit, фильтр Create-only, чистка expandedGroups) — юнит-сюита
  groupstab (44).
- Живой список (переэмит groupTree после create/delete) — androidTest;
  сортировка кириллицы Collator'ом — юнит + мутационная проверка.
- Механика «Все»/окна — Э2-сюиты (не тронута, регресс зелёный).
- Компиляция/lint — CI.

## Шпаргалка данных

- Группы: «Дом», «Быт», «Аптека» (ТК1–ТК2), «Сад»→«Огород»→«ОГОРОД»
  (ТК4–ТК7, удаляется в ТК8), «Тест» (ТК12, второй словарь).
- Ошибочные вводы: «дом» (дубль), «все»/«All»/«Все» (резерв).
- Словари: основной + второй (ТК12).

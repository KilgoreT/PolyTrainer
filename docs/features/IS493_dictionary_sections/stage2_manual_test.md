# IS493 / Э2 — Ручной прогон: группа «Все» — аккордеон со всеми словами

Формат — по `docs/handbook/guides/manual-test-scenarios.md`.

## Шапка

- Выполнять построчно сверху вниз. Один пункт — одно действие.
- `ВИЖУ` — сверить с экраном дословно. Пометка `НЕТ` — элемента быть не должно.
- **Логи:** фичевого лог-контракта в Э2 нет. Блоки `ЛОГ` отсутствуют.
- Сборка: `debug` APK после фазы 5, ветка `IS493_dictionary_sections`.
- ТК1 требует девайс с установленной сборкой Э1 и данными (апдейт поверх).
- ТК12–ТК13 сносят данные приложения (переустановка) — выполнять строго
  в конце основного прогона.
- ТК14–ТК16 (окно/«Ещё») — обычная сборка: `CHUNK_SIZE = 10`, словаря из
  12 слов достаточно.

## Подготовка

1. Девайс со сборкой Э1 (или старее, БД v12) и данными: словарь с 12
   словами из шпаргалки Э1.
2. Собрать новый debug APK (фаза 5 завершена).

## ТК1. Миграция апдейтом: данные живы

1. Установить новый APK поверх старого (`adb install -r`).
2. Открыть приложение на табе словаря.

```
ВИЖУ  вкладки «Слова | Группы»
      список слов на месте (те же слова, что до апдейта)
```

3. Тап по любому слову.

```
ВИЖУ  карточка слова открылась
      лексемы и значения компонентов на месте
```

4. Нажать «назад».
5. Тап по вкладке «Группы».

```
ВИЖУ  строка «Все» со счётчиком
      счётчик равен числу слов словаря
      НЕТ заглушки «Здесь появятся группы»
```

## ТК2. Свежий словарь: счётчик и раскрытие «Все»

1. Создать через AppBar новый словарь (любой язык, далее — «тестовый»).
2. Убедиться, что тестовый словарь выбран текущим.
3. На вкладке «Слова» добавить по одному 12 слов в порядке: «дом», «кот»,
   «мир», «сад», «лес», «море», «окно», «стол», «хлеб», «рука», «ночь»,
   «снег» (FAB «+», ввести слово, тап по кнопке отправки).
4. Тап по вкладке «Группы».

```
ВИЖУ  строка «Все» со светло-голубым фоном
      (отличается от белых карточек слов)
      счётчик «12»
      НЕТ списка слов под строкой (узел свёрнут)
      НЕТ FAB
```

5. Тап по строке «Все».

```
ВИЖУ  под строкой — 10 карточек слов, сверху вниз:
      «снег», «ночь», «рука», «хлеб», «стол»,
      «окно», «море», «лес», «сад», «мир»
      (новые сверху — порядок как на «Словах»)
      кнопка «Ещё»
      текст «показано 10 из 12»
```

6. Тап по строке «Все» повторно.

```
ВИЖУ  узел свернулся
      НЕТ карточек слов
      счётчик «12» на месте
```

## ТК3. Вёрстка строк и переход в карточку

1. Тап по строке «Все» (раскрыть).
2. Сравнить карточку «снег» с карточкой «снег» на вкладке «Слова»
   (переключиться туда-обратно).

```
ВИЖУ  карточка слова выглядит одинаково на обеих вкладках
      (та же вёрстка: слово, лексемы)
```

3. На вкладке «Группы» тап по карточке «снег».

```
ВИЖУ  открылась карточка слова «снег»
```

4. Нажать «назад».

```
ВИЖУ  вкладка «Группы»
      «Все» раскрыта, список на месте
```

## ТК4. Read-only: long-press в «Все» ничего не делает

1. Long-press по карточке «мир» в раскрытой «Все».

```
ВИЖУ  ничего не изменилось
      НЕТ рамки выделения на «мир»
      НЕТ action-бара (AppBar «Словарь» на месте)
```

## ТК5. Новое слово: появляется живьём (v3 — живое окно)

1. «Все» раскрыта. Тап по вкладке «Слова».
2. Добавить слово «луг» (FAB «+», ввести, отправить).
3. Тап по вкладке «Группы».

```
ВИЖУ  счётчик «13»
      «Все» раскрыта
      «луг» ПЕРВЫМ в списке (появился сам, без пересворачивания)
      скролл не дёрнулся, остальные слова на месте
```

4. Тап по слову «луг» (открыть карточку).
5. Добавить лексему с переводом «meadow» (тап «+», ввести перевод).
6. Нажать «назад».

```
ВИЖУ  вкладка «Группы», «Все» раскрыта
      у «луг» виден перевод «meadow» (правка из карточки
      обновилась в списке живьём)
```

## ТК6. Удаление слова: уходит из списка и счётчика

1. «Все» раскрыта. Тап по вкладке «Слова».
2. Long-press по слову «луг».
3. Тап по иконке корзины.
4. Тап по кнопке «Удалить».

```
ВИЖУ  snackbar «Слово удалено»
      «луг» НЕТ в списке слов
```

5. Тап по вкладке «Группы».

```
ВИЖУ  счётчик «12»
      «Все» раскрыта
      НЕТ «луг» в списке слов узла
```

## ТК7. Смена словаря

1. «Все» раскрыта (тестовый словарь, счётчик «12»).
2. Сменить словарь через AppBar на первый словарь — не уходя с «Групп».

```
ВИЖУ  «Все» свёрнута (сброс раскрытия)
      счётчик = числу слов первого словаря
      НЕТ слов тестового словаря на экране
```

3. Тап по вкладке «Слова».
4. Сменить словарь через AppBar обратно на тестовый.
5. Тап по вкладке «Группы».

```
ВИЖУ  счётчик «12»
      «Все» свёрнута
```

## ТК8. Пустой словарь: «Все» с нулём

1. Создать через AppBar новый словарь без слов (далее — «пустой»).
2. Убедиться, что пустой словарь выбран текущим.
3. Тап по вкладке «Группы».

```
ВИЖУ  строка «Все»
      счётчик «0»
```

4. Тап по строке «Все».

```
ВИЖУ  узел раскрылся (шеврон повернулся)
      НЕТ карточек слов
      НЕТ кнопки «Ещё»
```

5. Сменить словарь через AppBar обратно на тестовый.

## ТК9. Поворот экрана

1. На вкладке «Группы» раскрыть «Все» (тестовый словарь).
2. Повернуть устройство в альбомную ориентацию.

```
ВИЖУ  вкладка «Группы» активна
      «Все» раскрыта, список слов на месте
      счётчик «12»
```

3. Вернуть портретную ориентацию.

```
ВИЖУ  «Все» раскрыта, состояние не потеряно
```

## ТК10. Переключение вкладок: состояние обеих живо

1. «Все» раскрыта. Тап по кнопке «Ещё» (видны все 12).
   Проскроллить список узла вниз до «дом».
2. Тап по вкладке «Слова».
3. Проскроллить список слов в самый низ.
4. Тап по вкладке «Группы».

```
ВИЖУ  «Все» раскрыта
      позиция скролла сохранена (виден низ списка узла)
```

5. Тап по вкладке «Слова».

```
ВИЖУ  список на той же позиции (виден низ)
      список не мигал пустым состоянием
```

## ТК11. Регресс «Слов» после выноса виджета строки

1. На вкладке «Слова» тап по FAB «+».
2. Ввести «пар».
3. Тап по кнопке отправки.

```
ВИЖУ  слово «пар» в списке
```

4. Long-press по слову «пар».

```
ВИЖУ  action-бар со счётчиком «1»
      карточка «пар» обведена рамкой
```

5. Тап по иконке корзины.
6. Тап по кнопке «Удалить».

```
ВИЖУ  snackbar «Слово удалено»
      «пар» НЕТ в списке
      обычный AppBar вернулся
```

## ТК12. Свежая установка: v13 с нуля

1. Удалить приложение (`adb uninstall` или через систему).
2. Установить debug APK.
3. Открыть приложение, пройти создание словаря.
4. Добавить по одному 12 слов в порядке: «дом», «кот», «мир», «сад»,
   «лес», «море», «окно», «стол», «хлеб», «рука», «ночь», «снег».
5. Тап по вкладке «Группы».

```
ВИЖУ  строка «Все»
      счётчик «12»
```

6. Тап по строке «Все».

```
ВИЖУ  10 карточек слов, «снег» первым, «мир» последним
      кнопка «Ещё»
      текст «показано 10 из 12»
```

## ТК13. Нет словарей: empty-state (разрушительный, опционально)

1. Удалить ВСЕ словари через настройки приложения.
2. Открыть таб словаря.
3. Тап по вкладке «Группы».

```
ВИЖУ  текст «Здесь появятся группы» (empty-state «нет словаря»)
      НЕТ строки «Все»
      НЕТ краша
```

4. Восстановить: создать словарь заново (данные ТК12 утеряны — это
   ожидаемо).

# Секция окна («Ещё»)

Окно — `CHUNK_SIZE = 10` (решение 2026-08-11): на словаре из 12 слов
кнопка «Ещё» достижима на ОБЫЧНОЙ сборке, спец-сборка не нужна.

Данные: словарь из ТК12 (12 слов, «снег» новейшее).

## ТК14. Окно: раскрытие показывает порцию, «Ещё» расширяет

1. Тап по вкладке «Группы».
2. Тап по строке «Все».

```
ВИЖУ  10 карточек слов, сверху вниз:
      «снег», «ночь», «рука», «хлеб», «стол»,
      «окно», «море», «лес», «сад», «мир»
      под ними кнопка «Ещё»
      текст «показано 10 из 12»
```

3. Тап по кнопке «Ещё».

```
ВИЖУ  12 карточек слов, добавились: «кот», «дом»
      НЕТ кнопки «Ещё»
      НЕТ текста «показано … из …» (футер только при неполной загрузке)
```

## ТК15. Спам по «Ещё» не дублирует слова

1. Тап по строке «Все» (свернуть).
2. Тап по строке «Все» (раскрыть).

```
ВИЖУ  10 карточек, «показано 10 из 12»
```

3. Два быстрых тапа подряд по кнопке «Ещё» (дятлинг).

```
ВИЖУ  12 карточек слов
      НЕТ дубликатов (каждое слово встречается один раз)
      НЕТ краша
```

## ТК16. Новое слово при частичной загрузке: живое окно + компенсация

1. «Все» свёрнута. Тап по строке «Все» (раскрыть — показано 10 из 12).
2. Тап по вкладке «Слова».
3. Добавить слово «юг» (FAB «+», ввести, отправить).
4. Тап по вкладке «Группы».

```
ВИЖУ  «юг» ПЕРВЫМ в показанных словах (окно живое)
      текст «показано 11 из 13» (окно расширилось на дельту —
      нижнее слово НЕ вытеснено, компенсация)
      кнопка «Ещё» на месте
      НЕТ дубликатов
```

5. Тап по кнопке «Ещё».

```
ВИЖУ  13 карточек слов
      НЕТ дубликатов
      НЕТ кнопки «Ещё»
```

## Автоматически покрытое (вручную не проверять)

- Миграция 12→13 и chained 11→13 со сверкой схемы против 13.json, cascade
  при удалении слова/словаря — androidTest `MigrationFrom12to13`
  (ручной ТК1 — только смоук апдейта поверх реальных данных).
- `membershipSlice`: порядок id DESC, слово в мёртвой группе, переэмит при
  вставке слова, изоляция словарей — DAO-тесты androidTest.
- Дедуп wordId, счётчик distinct, порядок AllWords — юнит-тесты
  `domain/group` (buildDisplayTree).
- Вся оконная математика (v3): расширение окна «Ещё», компенсация
  вытеснения при росте словаря, сбросы при смене словаря, игнор спама
  LoadMore, ошибки подписок (WindowLoadFailed/SliceLoadFailed) —
  reducer-тесты groupstab; живость окна (limit + переэмит на вставку) —
  DAO-тест `flowTermsWindow`.
- Host: DictionaryChanged/isDictResolved, SelectTab — reducer-тесты
  vocabulary.
- Логика words (reducer/ext) — существующая сюита wordstab (зелёная после
  переезда на wordrow).
- Компиляция/lint — CI (`assembleDebug`, `testDebugUnitTest`, `lintDebug`).

## Шпаргалка данных

- Базовое наполнение словаря (порядок добавления важен): «дом», «кот»,
  «мир», «сад», «лес», «море», «окно», «стол», «хлеб», «рука», «ночь»,
  «снег» — 12 слов; список показывает их в обратном порядке («снег» сверху).
- Тестовые слова кейсов: «луг» (ТК5–ТК6, добавление и удаление),
  «пар» (ТК11, регресс), «юг» (ТК16, дозагрузка), «снег» (ТК3, карточка),
  «мир» (ТК4, long-press).
- Словари: первый (данные Э1, ТК1/ТК7), «тестовый» (ТК2+), «пустой» (ТК8).
- Окно: `CHUNK_SIZE = 10` (обычная сборка, спец-сборка не нужна).

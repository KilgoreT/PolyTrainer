# IS493 / Э1 — Ручной прогон: вкладки «Слова | Группы»

Формат — по `docs/handbook/guides/manual-test-scenarios.md`.

## Шапка

- Выполнять построчно сверху вниз. Один пункт — одно действие.
- `ВИЖУ` — сверить с экраном дословно. Пометка `НЕТ` — элемента быть не должно.
- **Логи:** фичевого лог-контракта в Э1 нет (host и заглушка не логируют).
  Блоки `ЛОГ` в кейсах отсутствуют по факту реализации.
- Сборка: `debug` APK после фазы 4 (rename), ветка `IS493_dictionary_sections`.

## Подготовка

1. Открыть приложение на табе словаря.
2. Если в текущем словаре меньше 12 слов — добавить недостающие из шпаргалки
   (FAB «+», ввести слово, тап по кнопке отправки в поле).
3. Если в приложении один словарь — создать второй словарь через AppBar
   (любой язык), затем вернуться в первый.

## ТК1. Вкладки видны, «Слова» работают

1. Открыть таб словаря.

```
ВИЖУ  AppBar с заголовком «Словарь»
      под AppBar две вкладки:
      «Слова» (активна)
      «Группы»
      список слов карточками
      FAB «+» справа внизу
```

2. Тап по слову «дом».

```
ВИЖУ  открылась карточка слова «дом»
```

3. Нажать «назад».

```
ВИЖУ  вкладка «Слова» со списком
```

## ТК2. Заглушка «Групп»

1. Тап по вкладке «Группы».

```
ВИЖУ  текст «Здесь появятся группы» по центру
      вкладка «Группы» подсвечена как активная
      AppBar «Словарь» на месте
      НЕТ FAB
      НЕТ списка слов
```

2. Тап по вкладке «Слова».

```
ВИЖУ  список слов
      FAB «+» вернулся
```

## ТК3. Регресс: добавление слова

1. Тап по FAB «+».

```
ВИЖУ  шторка снизу с полем ввода
      кнопка отправки в поле неактивна
      НЕТ FAB (спрятан, пока шторка открыта)
```

2. Ввести «луг».

```
ВИЖУ  кнопка отправки активна
```

3. Тап по кнопке отправки.

```
ВИЖУ  шторка закрылась
      слово «луг» есть в списке
      FAB «+» вернулся
```

## ТК4. Регресс: ActionMode и удаление со snackbar

1. Long-press по слову «луг».

```
ВИЖУ  вместо AppBar — action-бар:
      крестик слева
      счётчик «1»
      иконки действий (карандаш, перемещение, корзина)
      статусбар окрашен (не прозрачный)
      карточка «луг» обведена рамкой
```

2. Тап по иконке корзины.

```
ВИЖУ  диалог «Удалить слово?»
      кнопка «Удалить»
```

3. Тап по кнопке «Удалить».

```
ВИЖУ  диалог закрылся
      снизу snackbar «Слово удалено»
      слова «луг» НЕТ в списке
      обычный AppBar «Словарь» вернулся
```

## ТК5. ActionMode сбрасывается при переключении вкладки

1. Long-press по слову «кот».

```
ВИЖУ  action-бар со счётчиком «1»
      статусбар окрашен
```

2. Тап по вкладке «Группы».

```
ВИЖУ  заглушка «Здесь появятся группы»
      обычный AppBar «Словарь»
      статусбар обычный (прозрачный)
      НЕТ action-бара
```

3. Тап по вкладке «Слова».

```
ВИЖУ  список слов
      НЕТ action-бара
      НЕТ рамки выделения на «кот»
```

## ТК6. Тап по УЖЕ активной вкладке не сбрасывает выделение

1. Long-press по слову «кот».

```
ВИЖУ  action-бар со счётчиком «1»
```

2. Тап по вкладке «Слова» (она уже активна).

```
ВИЖУ  action-бар на месте
      счётчик «1»
      рамка на «кот» на месте
```

3. Тап по крестику в action-баре.

```
ВИЖУ  обычный AppBar
      НЕТ рамки выделения
```

## ТК7. Скролл переживает переключение вкладок

1. Проскроллить список слов в самый низ.
2. Тап по вкладке «Группы».
3. Тап по вкладке «Слова».

```
ВИЖУ  список на той же позиции (виден низ списка)
      список не мигал пустым состоянием
```

## ТК8. Поворот экрана и «назад»

1. Тап по вкладке «Группы».
2. Повернуть устройство в альбомную ориентацию.

```
ВИЖУ  вкладка «Группы» активна
      заглушка на месте
```

3. Вернуть портретную ориентацию.
4. Нажать «назад».

```
ВИЖУ  приложение свернулось (обычное поведение главного экрана;
      вкладки «назад» не перехватывают)
```

## ТК9. Смена словаря

1. Открыть приложение на табе словаря, вкладка «Слова».
2. Сменить словарь через AppBar на второй словарь.

```
ВИЖУ  список слов второго словаря (или пустой список)
      вкладки «Слова | Группы» на месте
```

3. Тап по вкладке «Группы».

```
ВИЖУ  заглушка «Здесь появятся группы»
```

4. Сменить словарь через AppBar обратно на первый.
5. Тап по вкладке «Слова».

```
ВИЖУ  список слов первого словаря
```

## Автоматически покрытое (вручную не проверять)

- Host-reducer: исходная вкладка WORDS, переключение, same-tab без изменений —
  `VocabularyHostReducerTest` (3 юнит-теста).
- Вся логика words (reducer/ext) — существующая сюита `wordstab` (прошла без
  правок после рефактора).
- Компиляция/lint — CI-таски `assembleDebug`, `testDebugUnitTest`, `lintDebug`.

## Шпаргалка данных

- Слова для наполнения: «дом», «кот», «мир», «сад», «лес», «море», «окно»,
  «стол», «хлеб», «рука», «ночь», «снег».
- Тестовые слова кейсов: «луг» (добавление и удаление), «дом» (карточка),
  «кот» (выделение).
- Словари: основной + любой второй (для ТК9).

# IS493 — Группы (структурные подсловари) в словаре

Issue: [#493](https://github.com/KilgoreT/PolyTrainer/issues/493)
Статус: **ТЗ, решения приняты** (Д1–Д14, обсуждение 2026-08-03). Основной термин —
**группа**; «раздел» — синоним.

> **КОНЦЕПТ-ПРАВКИ 2026-08-06 (canonical — spec.md):** виртуальная группа
> одна — **«Все»** (первая на корне, ВСЕ слова словаря); «Не разобрано»
> отменена везде. Введён инвариант **«папка или лист»**: в группу с
> подгруппами нельзя добавлять слова, в группу со словами — создавать
> подгруппы (смешанных узлов нет). Соответственно отменены/изменены: Д10, Д14,
> В1, часть Д-контента ниже — при расхождении верить spec.md.

## Суть

На табе словаря — **верхние вкладки** (2 шт.):

1. **«Слова»** — текущее отображение (список слов словаря, без изменений).
2. **«Группы»** — управление группами: создать группу (пока только имя), дерево
   групп с раскрытием. Групп может быть много.

**Группа** — структурная единица словаря (подсловарь): выделяет часть слов словаря.
Это **не тег** — это способ структурировать словарь. Свойства:

- Слово, добавленное в группу, **остаётся в главном словаре** (группа не переносит
  слово).
- Одно слово может быть **в нескольких группах** (механизм — many-to-many; но по
  смыслу это структура, а не метки).
- Группы образуют **дерево** — внутри группы могут быть подгруппы, без лимита
  глубины (UI рассчитан на удобные 2–3 уровня, глубже — на свой страх).
- Группа может содержать **и подгруппы, и слова напрямую**. Прямые слова такой
  группы показываются в виртуальной группе **«Не разобрано»** (слова, ещё не
  разложенные по подгруппам) — рядом с подгруппами, на том же уровне.
- **Тренируется отдельно** (см. «Вне скоупа»): выбранная для тренировки группа
  тренируется вместе со всем своим **поддеревом**. Саму тренировку делаем отдельной
  фичей; модель это поддерживает.

## Модель данных

Группа привязана к словарю, образует дерево; принадлежность слов — many-to-many.

```
dictionary_groups                        -- имя решено (НЕ groups: reserved-ish в SQL)
  id                PK
  dictionary_id     FK → dictionaries.id (CASCADE)   -- группа пословарная
  parent_group_id   FK → dictionary_groups.id (CASCADE), NULL  -- дерево; null = корневая
  name              TEXT                              -- имя (пока единственное поле)
  created_at / updated_at / removed_at                -- audit + soft-delete

word_groups (join)
  word_id       FK → words.id (CASCADE)
  group_id      FK → dictionary_groups.id (CASCADE)
  created_at
  PRIMARY KEY (word_id, group_id)
```

Поля `position` НЕТ (В7): порядок сиблингов — алфавитный по имени (locale-aware
в Kotlin); reorder в будущем — аддитивная миграция.

- Слово по-прежнему `words.dictionary_id` (главный словарь) — не меняется.
- Принадлежность группам — только через `word_groups`; слово привязывается к
  КОНКРЕТНОМУ узлу дерева (любого уровня, в т.ч. к узлу, у которого есть подгруппы —
  тогда оно в его «Не разобрано»).
- **Дерево:** `parent_group_id` self-FK; null = корневая. Инварианты: родитель из
  того же словаря; **запрет циклов** (группа не может стать своим предком) —
  валидация как в IS486 (`createsCycle`).
- **«Не разобрано» — виртуальная**, НЕ строка в БД: срез «слова, чей
  `word_groups.group_id` = эта группа», показанный отдельной группой, когда у
  группы есть подгруппы. Имя зарезервировано (нельзя создать одноимённую).
- Инвариант: `word_groups.group_id` и `word.dictionary_id` — из одного словаря.

**Соотношение с компонентами (IS486):** группы — НЕ компоненты. Компоненты — на
**лексеме** (значение слова), группы — на **слове**. Разные слои, отдельная модель,
не пересекается с `component_*`.

## Экраны и поток

### Таб словаря — вкладки

- TabRow над контентом: «Слова» | «Группы».
- «Слова» — существующий `DictionaryTabScreen` без изменений.
- «Группы» — новый экран: **дерево с раскрытием на месте (аккордеон)**. Видны
  корневые группы; тап по группе раскрывает её прямо в списке (подгруппы с отступом
  + «Не разобрано» со словами, если есть И подгруппы, И прямые слова); корневые
  остаются видимы, можно доскроллить. Пусто → empty-state.
- **Листовая группа** (слова без подгрупп) показывает слова напрямую, без
  обёртки «Не разобрано» (В2) — тем же виджетом строки слова, что на вкладке
  «Слова», read-only: тап открывает карточку; снятие с группы — только через
  пикер карточки (В6).
- **Корневой уровень вкладки** имеет свою виртуальную группу «Не разобрано» —
  слова словаря, не входящие ни в одну группу (В1). Вкладка покрывает весь
  словарь.
- **Счётчик** на строке группы — distinct-слова всего поддерева (В3).
- **Создание** (В4): FAB контекстный — на «Слова» «добавить слово» (как
  сейчас), на «Группы» — создать корневую группу (диалог: только имя); на
  строке любой группы — действие «создать подгруппу» (родитель = эта группа,
  диалог: только имя). Выбора родителя из дерева на вкладке нет.
- **Back** (В5): вкладки не перехватывают «назад» — обычное поведение.
- Сортировка групп — алфавитная (В7).

### Карточка слова — группы

- Группы слова показываются **в том же виджете шапки, где слово, дата и флаг
  словаря** — там же иконка добавления.
- Иконка → пикер: **всё дерево групп словаря** с чекбоксами (отмеченные = где слово
  уже состоит), мультивыбор по узлам; тоггл → add/remove. В пикере можно **создать
  новую группу**, выбрав ей родителя из дерева (или корень).

## Решения (Д1–Д14)

- **Д1.** Группа — структурная единица (подсловарь), НЕ тег. Хранение — m2m (слово
  в нескольких группах). Тренировка группы = всё её поддерево.
- **Д2.** Просмотр — на вкладке «Группы»: аккордеон (раскрытие на месте), корневые
  остаются видимы. Без drill-down.
- **Д3.** Группы строго пословарные; глобальных нет.
- **Д (контент группы).** Группа может иметь одновременно подгруппы и прямые слова;
  прямые → виртуальная группа «Не разобрано».
- **Д4.** Rename — только имя. Delete — снимает группировку (слова остаются);
  с подгруппами → каскад поддерева + импакт (Д11).
- **Д5.** Удаление слова из словаря → каскадно чистит `word_groups` (FK CASCADE).
- **Д6.** Создание группы доступно и в пикере карточки (всё дерево + выбор родителя).
- **Д7.** Иконка/показ групп — в шапке карточки (со словом, датой, флагом).
- **Д8.** Имя: trim + не пустое; **уникально среди соседей** (у одного родителя /
  среди корневых). «Не разобрано» — зарезервировано.
- **Д9.** Тренировка по группе — **вне v1**, отдельной фичей (модель поддержит);
  будущее — выбор группы внутри тренировок.
- **Д10.** Дефолтная группа прямых слов — **«Не разобрано»** (показывать, когда у
  группы есть подгруппы и есть прямые слова).
- **Д11.** Удаление группы с подгруппами — каскад всего поддерева + импакт-конфирм
  («удалится N подгрупп, у M слов снимется группировка»).
- **Д12.** Перемещение группы (reparent) — **не делаем** (вне скоупа).
- **Д13.** Лимита глубины нет; UI рассчитан на 2–3 уровня.
- **Д14.** Привязка слова к узлу с подгруппами — разрешена (→ «Не разобрано»).

## Публикация (вводная 2026-08-04, решения П1–П3)

Группы будут публиковаться: другие пользователи видят их в каталоге, добавляют
себе и учат. Сама фича — сильно позже; семантика зафиксирована в
`analysis_sharing_import.md`, ограничения на v1 — в `architecture.md` §6.3.
Кратко: импорт всегда в текущий словарь (каталог по языку словаря);
совпадение текста слова — сигнал для preview-ревью, не идентичность;
импортированное слово — всегда новая строка (дубли легальны, reuse/склейки нет).

## Вне скоупа v1

- Тренировка по группе (Д9 → бэклог: выбор группы в тренировках).
- Перемещение группы в другого родителя (Д12).
- Перенос/копирование слов между словарями.
- Доп. поля группы (описание, цвет, иконка) — пока только имя.
- Фильтр по группе на вкладке «Слова» (просмотр — через вкладку «Группы»).

## Оценка объёма

- **Данные:** новые `dictionary_groups` (+ self-FK дерево) и `word_groups` (m2m);
  ядро слов не меняется. Существенная доля объёма — data/domain/host-слои
  (транзакционный агрегат, host-рефактор), не только UI (уточнено ревью).
- **Модули:** нижний таб словаря расщепляется 1 → 3 (vocabulary host + wordstab
  + grouptab, см. architecture §4.1); ActionMode — только на вкладке «Слова».
- **Пикер:** галочка дизейблится на время записи (per-membership), состояние —
  из Flow базы. Инварианты (циклы, каскад поддерева) — паттерны IS486.
- **UI (основной прирост):** вкладки на табе словаря; аккордеон-дерево на «Группы»;
  tree-пикер с созданием в карточке; показ групп в шапке карточки.
- Ориентир: заметно объёмнее плоского варианта; прирост распределён между UI
  дерева, host-рефактором и транзакционным доменом.

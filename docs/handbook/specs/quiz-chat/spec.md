# Квиз-чат — спецификация

Тренировка «напиши слово по подсказке» в виде чата с ботом. Доменная
модель (слово, лексема, ядро, что можно спросить) —
[word-model/spec.md](../word-model/spec.md); отбор порции —
[quiz-group-filter/spec.md](../quiz-group-filter/spec.md) §7.1;
компоненты и ядра — [component-constructor/spec.md](../component-constructor/spec.md).
Анимации ленты — не предмет спеки (см. `docs/features/IS508_quiz_no_duplicates/`).

Статус: написана при IS511 (2026-09-30); разделы с пометкой **IS511** —
новое поведение этой задачи, остальное — как в 0.1.10.

---

## 1. Сущности

- **Сессия** — один заход в чат: от приветствия до ухода с экрана.
  Внутри — один или несколько **раундов**.
- **Раунд** — порция вопросов (лимит — настройка квиза), отобранная по
  правилам порции (§7.1 quiz-group-filter): лексема в раунде не более
  раза, предпочтение разных слов, добавки «самые давние» и «частые
  ошибки» по тумблерам меню.
- **Вопрос** — лексема, показанная одним из своих **ядер** (word-model
  §2.6). Ответ — слово. Варианты реакции: ответ текстом, «Показать
  ответ», «Пропустить».
- **Оценка** — реакция бота на ответ: верно / неверно (+ правильный ответ).
- **Итог раунда** — счётчики и кнопки следующего шага; **отчёт** — список
  вопросов с ответами.

**Аппбар.** Заголовок «Квиз чат», под ним сабтайтл — охват тренировки,
всегда: «Все», имя группы или «Быт +2» (первая выбранная по алфавиту и
сколько ещё; «+N» не обрезается). Группы выбираются на карточке квиза
в табе «Квизы», не в чате (quiz-group-filter §9–§10).

## 2. Поток (пузыри)

Пузыри бота — слева с аватаром (аватар у последнего в цепочке), пользователя — справа. Строки — ключи ресурсов из §5.

| # | Кто | Что | Ключ / правило |
|---|---|---|---|
| 1 | Бот | «Привет! Готов начать тренировку? 💪» | `chat_quiz_msg_system_welcome` |
| 2 | Системная кнопка | «Начать» → превращается в пузырь пользователя «Начать» | `chat_quiz_start_button_title` / `chat_quiz_msg_user_start` |
| 3 | Бот | **IS511.** Правило игры: «Я даю подсказку — ты пишешь слово.» Один раз за сессию. | `chat_quiz_msg_system_rule` |
| 4 | Бот | Вопрос: «Имя ядра:» / `[часть речи]` **значение** (§3). Под ним чипы «Показать ответ» / «Пропустить». Поле ввода активно. | §3 |
| 5a | Пользователь | Ответ текстом (пузырь из поля) | — |
| 6a | Бот | Оценка: случайная фраза «верно» ИЛИ «неверно» + «Правильный ответ:» + слово | `chat_quiz_system_correct` / `chat_quiz_system_incorrect`, `chat_quiz_msg_system_answer` |
| 5b | Пользователь | «Пропустить» (чип → пузырь) | `chat_quiz_msg_user_skip` |
| 5c | Пользователь | «Показать ответ» (чип → пузырь) | `chat_quiz_msg_user_show_answer` |
| 6c | Бот | «Правильный ответ:» / **слово** | `chat_quiz_msg_system_answer` |
| 7 | Бот | Следующий вопрос (п. 4) … пока раунд не кончится | |
| 8 | Бот | «Сессия завершена!» + «📈 Всего слов: N» / «✅ Правильных ответов: N» / «➖ Пропущено: N» / «❌ Ошибок: N» | `chat_quiz_msg_system_session_end`, `chat_quiz_summary_*` |
| 9 | Бот (отдельный пузырь) | «Твой следующий шаг?» + кнопки «Продолжить квиз» / «Посмотреть отчет» / «Завершить» | `chat_quiz_msg_system_session_end2`, `chat_quiz_system_btn_*` |
| 10a | Пользователь | «Посмотреть отчет» | `chat_quiz_system_btn_result` |
| 11a | Бот | «Список ответов:» + строки «✅ значение - ответ» / «❌ значение - ответ» | `chat_quiz_summary_detail_title` |
| 12a | Бот (отдельный пузырь) | «Твой следующий шаг?» + «Продолжить квиз» / «Завершить» | |
| 10b | Пользователь | «Продолжить квиз» → новый раунд с п. 4 (**без** правила п. 3) | `chat_quiz_msg_user_continue` |
| 10c | — | «Завершить» → выход с экрана | `chat_quiz_system_btn_finish` |

Правила потока:
- Сообщения бота идут **по одному**, каждое после паузы «бот думает»;
  пачки (8→9, 11a→12a) разнесены паузой.
- Пока бот «думает» (между ответом и оценкой, оценкой и вопросом) поле
  ввода выключено; чипы есть только под текущим вопросом.
- После «Пропустить» правильный ответ не показывается; в отчёте — «➖».
- Плейсхолдер поля: «Введите ответ» (`chat_quiz_placeholder_text`).
- **Пустой раунд** (под фильтр §4 не попала ни одна лексема, например
  включено только ядро, которого нет ни у одного слова): после «Начать»
  и правила сразу п. 8–9 с нулями. Отдельного сообщения нет (решение
  IS511; идея — в Backlog).

## 3. Вопрос (IS511)

Формат пузыря вопроса:

```
<Имя ядра>:
[сущ.] <значение ядра жирным>
```

- **Имя ядра:** встроенный перевод — `chat_menu_item_component_translation`
  («Перевод»), тот же ключ, что подпись галки в меню (§4), чтобы имена не
  разъехались; пользовательское ядро — его имя как есть.
- **Какое ядро:** случайно из включённых в меню, у которых у этой
  лексемы есть живое значение. Лексема без такого значения в раунд не
  попадает (фильтр порции, §7.1).
- **Раскладка пузыря:** верхняя строка «Имя ядра:» отдельно; под ней
  строка значения: слева место под метку, справа значение. Длинное
  значение переносится в своей колонке (висячий отступ), метка остаётся у
  первой строки. Метка — отдельный элемент, не часть текста; пузырь
  знает о ней только размер: не выше одной строки значения (потолок
  растёт вместе с системным шрифтом) и не шире примерно трети пузыря,
  длинный текст метки режется многоточием.
- **Чип части речи:** если у лексемы заполнена часть речи — он и есть
  метка слева от значения. Мелкий чип (11–12sp, фон `secondaryContainer`,
  скруглённый). Текст: для встроенных опций — сокращения `part_of_speech_short_*`
  (§5), для пользовательской опции — её текст. Нет значения — метки нет,
  значение начинается от края. Другие атрибуты в вопрос не выводятся
  (настраиваемый набор — Backlog).
- Прежние заголовки «Переведи следующее слово:» и «Какое слово связано
  с этим определением:» удалены.

## 4. Меню (бургер в аппбаре)

| Пункт | Тип | Ключ | Поведение |
|---|---|---|---|
| Самые давние | галка | `chat_menu_item_earliest_reviewed` | добавка в раунд: давно не повторявшиеся |
| Частые ошибки | галка | `chat_menu_item_mistakes` | добавка: с ошибками (только с `error_count > 0`) |
| Компонент квиза | подменю с галками (**IS511**) | `chat_menu_item_quiz_component`, подпись `chat_menu_quiz_component_hint` | см. ниже |
| Show debug | галка, только debug-сборка | `chat_menu_item_show_debug` | статистика по грейдам в чате |

**Компонент квиза (IS511).**
- **Кандидаты** = ядра словаря: включённые, не удалённые, с шаблоном,
  который квиз умеет показать (сегодня TEXT), в порядке словаря.
- **Один кандидат** — подменю не показывается; вопросы по нему.
- **Несколько** — галки (не переключатель), можно несколько; по умолчанию
  (нет сохранённого выбора) включены все.
- **Минимум одно:** единственная включённая галка задизейблена (снять
  нельзя); под заголовком подменю статичная подпись «минимум одно». Чтобы
  оставить единственным другое ядро — включить его, потом выключить
  текущее.
- Подпись галки: перевод — `chat_menu_item_component_translation`,
  пользовательское — имя.
- Выбор **пословарный**, переживает перезапуск; пропавшие ядра (удалены /
  выключены) из выбора выпадают; если выбор опустел — снова все.
- Изменение выбора действует со следующего раунда (текущий раунд уже
  отобран).

## 6. Инварианты

1. Лексема в раунде не более раза; раунд — только лексемы с живым
   значением хотя бы в одном включённом ядре.
2. Выбор ядер непуст, если кандидатов ≥ 1; при одном кандидате выбор =
   он, меню нет.
3. Пауза бота длиннее анимации ленты (темп в одном месте, `ChatTiming`).
4. Правило игры — ровно один раз за сессию, после «Начать».
5. Имя ядра в вопросе = подпись галки в меню.

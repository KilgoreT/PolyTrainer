# AWP — добавление слов со снимка

- Экран сценария снимка: кнопка-камера, ожидание, окно со списками слов,
  плашки под словом по тапу, добавление в словарь по одной лексеме.
  Только устройство.
- Что присылает сервер: перевод и списки слов — LFT
  `backend/docs/handbook/specs/lemmas-from-text/spec.md`, значения слова —
  LFL `backend/docs/handbook/specs/lexemes-from-lemma/spec.md`. Снимок и
  распознавание — TFP `backend/docs/handbook/specs/tokens-from-photo/spec.md`.
  Доступ и лимиты — ACC и LIM.
- Формат — `backend/docs/handbook/feature-flow/spec-format.md`. Префикс
  номеров `AWP`, адрес строки `AWP-NN.k`. Исполнитель всегда устройство,
  поле «Исполняет» опущено.
- Версия v3. Прошлые — `spec-v1.md` и `spec-v2.md` рядом.

## Термины

Термины спеки — в глоссарии `backend/docs/handbook/glossary.md`, своих у
неё нет.

## Флоу

### Ш1 Кнопка-камера
- На вкладке «Слова» рядом с кнопкой добавления записи стоит
  кнопка-камера. Она есть, только когда ключ доступа задан, по ACC.
- Пока открыта панель ввода записи, обеих кнопок нет.
- Дальше: нажатие кнопки-камеры → Ш2.

### Ш2 Выбор способа
- Пользователь выбирает, откуда снимок: камера — системное приложение,
  галерея — системный выбор снимка. Нет приложения камеры — только
  галерея.
- Повторное нажатие кнопки-камеры второй выбор не открывает.
- Дальше:
  - способ выбран → снимок и распознавание по TFP, на экране → Ш3
  - выбор закрыт → конец

### Ш3 Ожидание
- Индикатор с подписью этапа: «Распознаю текст…», пока телефон
  распознаёт снимок по TFP, потом «Анализирую текст…», пока сервер делает
  перевод и списки по LFT. У индикатора — «отменить».
- Дальше:
  - сервер прислал перевод и списки → Ш4
  - «отменить» → индикатор закрывается, конец
  - ошибка снимка, распознавания или сети, отказ сервера → В1
  - слов не найдено → В2
  - приложение убито системой → В7

### Ш4 Подготовка окна
- Из словаря снимка загружаются его форма, группы и леммы с текстами
  слов из списков.
- Слово, у которого в словаре есть лемма с тем же текстом, получает
  пометку «в словаре».
- Дальше:
  - всё загружено → Ш5
  - форма словаря, леммы или группы не загрузились → В3

### Ш5 Окно
- На месте индикатора открывается окно на весь экран. Наверху общая
  группа: в неё ложится добавленное слово без своей группы. Под ней —
  перевод текста свёрнутым блоком.
- Списки по порядку: смысловые, имена собственные, служебные, «не
  разобрано». Слова — в порядке текста, с пометкой «в словаре».
  Добавленное слово из списка ушло.
- Дальше:
  - тап по слову → Ш6
  - закрытие окна → Ш10
  - приложение убито системой, в том числе на Ш6–Ш9 → В6

### Ш6 Тап по слову
- Тап по слову раскрывает под ним плашки. Раскрытых слов может быть
  несколько. Повторный тап сворачивает всё под словом, следующий
  раскрывает как было, без нового запроса.
- **А. Слово «в словаре»:**
  - под словом по плашке на каждое слово словаря с этим текстом: группа
    слова или «Все», дата добавления, сохранённые лексемы. У слова без
    лексем плашка пустая. Слово написано один раз, над плашками. На
    сервер ничего не уходит
  - под плашками кнопки «Проверить по тексту» и «Убрать из списка»
- **Б. Новое слово:**
  - устройство сразу шлёт на сервер лемму слова с исправленным текстом
    снимка и переводом — LFL. Слово из «не разобрано» уходит как есть,
    словарную форму ищет LFL
  - пока сервер не ответил — признак загрузки на слове
- Дальше:
  - «Проверить по тексту» → Ш7
  - сервер ответил новому слову → Ш8
  - «Убрать из списка» → слово уходит из списка → Ш5
  - сервер ответил «не найдено» или ошибкой → В4

### Ш7 Проверка по тексту
- «Проверить по тексту» шлёт на сервер лемму слова с исправленным текстом
  снимка и переводом — LFL, как для нового слова.
- Пока сервер думает — признак загрузки под плашками словаря, плашки на
  месте.
- Дальше:
  - сервер ответил → Ш8
  - сервер ответил «не найдено» или ошибкой → В4

### Ш8 Плашки нейронки
- Ниже плашек словаря, у нового слова — сразу под словом, по плашке на
  каждую лексему-кандидата: компоненты по порядку — перевод,
  определение, часть речи, род, примеры. Первая плашка — лексема,
  которую сервер счёл употреблённой в тексте снимка, с пометкой «в
  тексте». Лексемы выглядят так же, как в карточке слова. Под плашками
  разделы «Замечания» и «Сопоставление», подпись источника и лицензии.
- Лексема-кандидат, чьё ядро совпало с сохранённой лексемой любого слова
  словаря с этим текстом, помечена «уже в словаре» и в запись не идёт.
- У каждой плашки поле «Куда»: по умолчанию «новое слово», по тапу —
  любое слово словаря с этим текстом. Слов с этим текстом нет — поля
  нет. Своя группа слова — только при «новое слово».
- Правки внутри плашки: удалить одно значение множественного
  компонента, править значение текстового компонента, «сбросить»
  возвращает присланное, сменить опцию «Выбора». Удалённое не
  возвращается. После правки пересчитываются «не попадёт в ядро» и
  доступность кнопки.
- Кнопка у плашки по полю «Куда»: «Создать» — в новое слово,
  «Перенести» — в выбранное. «Не нужно» у плашки — лексема-кандидат уходит
  без записи.
- Дальше:
  - «Создать» или «Перенести» → Ш9
  - «Не нужно» → плашка уходит, остальные на месте → Ш8
  - «Не нужно» у последней плашки → слово уходит из списка → Ш5
  - закрытие окна → Ш10

### Ш9 Запись лексемы
- До записи проверяется: словарь, выбранное слово и группа живы,
  компоненты сопоставления включены, ядро заполнено.
- Одной транзакцией. «Создать»: новое слово с этой лексемой, слово — в
  свою или общую группу. «Перенести»: лексема в выбранное слово, группы
  слова не меняются. Сохранённые лексемы не меняются. Компонент без
  значения не создаётся.
- После записи плашка уходит, плашки словаря под словом перечитываются:
  созданное слово появляется тут же со своей лексемой, перенесённая
  лексема видна в своём слове. После «Создать» у оставшихся плашек
  нейронки «Куда» становится созданным словом, кнопка — «Перенести».
- Ушла последняя плашка нейронки — слово уходит из списка вместе с
  плашками словаря.
- Дальше:
  - записано, плашки нейронки остались → Ш8
  - записано, плашек не осталось → Ш5
  - отказ проверки или запись не удалась → В5

### Ш10 Закрытие окна
- Есть слова, у которых плашки нейронки пришли или идут с сервера и не
  все разобраны, — вопрос, закрыть ли окно, с их числом. Нет таких — окно
  закрывается сразу.
- Дальше:
  - «остаться» → Ш5
  - «закрыть» или закрыто сразу → Ш11

### Ш11 После окна
- Вкладка «Слова» показывает леммы словаря, в том числе новые.
  Добавленные лексемы оформлены и попадают в тренировку.
- Дальше: конец.

### В1 Ошибка до окна
- Из Ш3: камера не запустилась, снимок не декодируется, распознавание
  упало, сети нет, сервер не ответил или отказал.
- Индикатор закрывается, пользователь видит причину, приложение не
  падает. Тексты: нет ключа или он чужой — «нет доступа к серверу»,
  лимит — «лимит на сегодня исчерпан», текст велик — «слишком много
  слов», языка словаря нет в базе — «язык словаря не поддерживается»,
  нейронка не ответила — «анализ текста сейчас недоступен, попробуй
  позже», сеть или сервер — «сервер не ответил».
- Ошибка сети, сервера или нейронки — «Повторить» с теми же токенами,
  без нового снимка. При отказе по ключу или лимиту повтора нет.
- Дальше:
  - «Повторить» → Ш3
  - закрытие → конец

### В2 Слов не найдено
- Из Ш3: распознавание не дало токенов или в ответе сервера ни словарной
  формы, ни «не разобрано».
- Пользователь видит «слов не найдено».
- Дальше: закрытие → конец.

### В3 Окно не собралось
- Из Ш4: форма словаря, леммы или группы не загрузились.
- Признак загрузки закрывается, пользователь видит текст ошибки.
  Приложение не падает.
- Дальше: закрытие → конец.

### В4 «Не найдено» или ошибка на слове
- Из Ш6 или Ш7: сервер ответил «не найдено» или ошибкой.
- Под словом причина и «Убрать из списка». Плашки словаря, если были, на
  месте, плашек нейронки нет. Ошибка сети, сервера или нейронки — ещё
  «Повторить». Отказ по ключу, лимиту, размеру или языку — без
  «Повторить».
- Дальше:
  - «Повторить» → откуда пришли: Ш6 или Ш7
  - «Убрать из списка» → Ш5
  - плашки свёрнуты → Ш5

### В5 Запись не удалась
- Из Ш9: отказ проверки до записи или ошибка транзакции.
- В словарь ничего не записано, плашка остаётся. Всё в ней на месте,
  кроме выбора, ставшего недействительным: удалённая группа → «Все» или
  «как у всех», удалённое слово → «новое слово», выключенный компонент →
  его значения сняты.
- Под плашкой — «не добавилось» и «Повторить».
- Дальше:
  - «Повторить» → Ш9
  - пользователь вернулся к плашкам → Ш8

### В6 Перезапуск при открытом окне
- Из Ш5–Ш9: система убила приложение при открытом окне.
- После возврата окна нет. Добавленные слова уже в словаре, остальные
  слова и правки потеряны.
- Дальше: конец.

### В7 Перезапуск во время ожидания
- Из Ш3: система убила приложение во время распознавания или ожидания
  ответа сервера.
- После возврата ничего не показывается, запуск считается завершённым.
- Дальше: конец.

## Стороны

Исполнители шагов:

- Ш1–Ш11, В1–В7 — устройство.

Устройство → сервер:

- токены снимка — LFT, «Стороны»
- лемма слова с исправленным текстом и переводом — LFL, «Стороны»

Сервер → устройство:

- исправленный текст, перевод, три списка слов и «не разобрано» — LFT
- лексемы-кандидаты слова — LFL

Окно → словарь снимка, запись по одной лексеме:

- «Создать» — новое слово с лексемой, слово в свою или общую группу
- «Перенести» — лексема в выбранное слово, группы слова не меняются
- значения компонентов лексемы — по сопоставлению и правкам пользователя

## Векторная правда

### Инварианты

#### AWP-01 Словарь снимка
Проверка: unit · Статус: реализовано · Шаг: все

**ВСЕГДА** форма словаря, леммы, группы и запись идут по словарю снимка —
словарю, на вкладке которого сделан снимок, — а не по текущему словарю в
момент действия.

Примеры:
- [1] снимок на вкладке словаря «English», ответ пришёл → форма и леммы
  «English»

Границы:
- [2] снято: пока идёт запрос, словарь не удалить — окно модальное, у
  пальцев одно дело за раз

Связи: запуск — TFP-01

#### AWP-02 Дубли при записи
Проверка: unit, ручной · Статус: реализовано · Шаг: все

**ВСЕГДА** одно нажатие «Создать» или «Перенести» у плашки нейронки даёт
одну запись в словарь: повторные нажатия во время записи не действуют.

Примеры:
- [1] два быстрых нажатия «Создать» у плашки «бежать» слова «run» → в
  словаре одно слово «run» с одной лексемой «бежать»

Границы:
- [2] «Повторить» после ошибки → одна запись, дублей от неудачной попытки
  нет (AWP-21)
- [3] пока пишется плашка «бежать», нажато «Создать» у плашки
  «управлять» того же слова → не действует: кнопки всех плашек слова
  неактивны до конца записи (AWP-47.4)

#### AWP-03 Плашка — черновик
Проверка: unit · Статус: реализовано · Шаг: все

**ВСЕГДА** в словарь ложится ровно то, что осталось в плашке нейронки на
момент нажатия: её лексема-кандидат с правками и оставшимися значениями
компонентов; переключателей «добавлять / не добавлять» у значений нет.

Примеры:
- [1] у «run» три плашки, «Не нужно» у двух → осталась одна, «Создать»
  пишет одну лексему
- [2] у лексемы-кандидата 3 примера, удалены 2 → в «Пример» ляжет один

Границы:
- [3] ничего не удалено и не правлено → в плашке всё, что прислал сервер,
  и всё это ложится в словарь
- [4] снято: кнопка при «не попадёт в ядро» — AWP-47
- [5] снято: у плашки «уже в словаре» кнопки записи нет — AWP-50.12

### Ш1

#### AWP-35 Кнопка-камера по ключу
Проверка: unit, ручной · Статус: реализовано · Шаг: Ш1

**ГДЕ ВКЛЮЧЕНО** *в сборке есть ключ доступа к серверу*, на вкладке
«Слова» есть кнопка-камера рядом с кнопкой добавления записи.

Примеры:
- [1] сборка с ключом, вкладка «Слова» → кнопка-камера есть

Границы:
- [2] сборка без ключа → кнопки-камеры нет
- [3] вкладка «Группы» → кнопки-камеры нет

Связи: ключ не задан — ACC-19; тот же признак у кнопки в карточке слова
— WCL-08

#### AWP-36 Кнопки прячутся с панелью ввода
Проверка: ручной · Статус: реализовано · Шаг: Ш1

**ПОКА** *открыта панель ввода записи*, кнопки-камеры и кнопки добавления
записи нет.

Примеры:
- [1] панель открыта → обеих кнопок нет
- [2] панель закрыта → обе кнопки снова есть

Границы:
- границ нет

### Ш2

#### AWP-37 Выбор способа
Проверка: unit, ручной · Статус: реализовано · Шаг: Ш2

**КОГДА** *пользователь нажимает кнопку-камеру*, открывается выбор
способа получения снимка — камера или галерея.

Примеры:
- [1] нажатие кнопки-камеры → выбор «камера / галерея»

Границы:
- [2] два нажатия кнопки-камеры подряд → один выбор, второго не
  открывается
- [3] выбор закрыт → вкладка «Слова» как была

Связи: способы — TFP-06; камера не запустилась — TFP-07; возврат без
снимка — TFP-18

### Ш3

#### AWP-38 Индикатор этапа
Проверка: unit, ручной · Статус: реализовано · Шаг: Ш3

**ПОКА** *идёт распознавание или ожидание ответа сервера*, на вкладке
виден индикатор с подписью этапа и кнопкой «Отменить».

Примеры:
- [1] снимок получен → индикатор «Распознаю текст…»
- [2] токены отправлены на сервер → подпись «Анализирую текст…» до
  ответа

Границы:
- [3] поворот экрана во время ожидания → индикатор и подпись на месте
- [4] сервер молчит 120 секунд → индикатор виден, ошибки нет
- [5] снято: отмена — TFP-21

Связи: прогресс по словам и долгое ожидание — бэклог бэкенда

### Ш4

#### AWP-39 Пометка «в словаре»
Проверка: unit · Статус: реализовано · Шаг: Ш4, Ш5

**КОГДА** *в словаре снимка есть лемма с тем же текстом, что у слова
списка (без учёта регистра, краёв и формы Unicode)*, слово в списке
помечено «в словаре».

Примеры:
- [1] в словаре лемма «run», в смысловых «run» → «run» помечено «в
  словаре»

Границы:
- [2] в словаре «Run» → «run» помечено: регистр не важен
- [3] лемм с таким текстом нет → пометки нет
- [4] в словаре «ёж», в списке «еж» → пометки нет: «ё» и «е» разные
- [5] «run» создано из окна по «Создать», строка «run» ещё в списке →
  пометка «в словаре» появилась (AWP-63.5)

Связи: форма Unicode — NFC; плашки такого слова — AWP-46; слово,
созданное из окна, — AWP-63

### Ш5

#### AWP-40 Окно на месте индикатора
Проверка: unit, ручной · Статус: реализовано · Шаг: Ш5

**КОГДА** *сервер прислал перевод и списки и окно собрано*, индикатор
закрывается и на его месте открывается окно на весь экран: наверху
общая группа, под ней перевод текста, ниже списки — смысловые, имена
собственные, служебные, «не разобрано»; слова в каждом списке — в
порядке текста.

Примеры:
- [1] абзац учебника из контрольного набора → индикатора нет, окно:

Проверка: unit, ручной · Статус: отложено · Шаг: Ш8

плашки выбор: «перенести» в выбранное слово, по умолчанию, или
«заменить» сохранённую лексему, которую выберет пользователь.

Примеры:
- [1] у «run» сохранено только «Перевод: бежать», прислано «Перевод:
  управлять» → у «управлять» выбор, стоит «перенести»

Границы:
- [2] «управлять» и «работать» на «заменить» → сохранённое «бежать»
  можно выбрать только у одного: у второго его в списке нет
- [3] у выбранного «run» лексем нет → у каждой плашки только
  «перенести», «заменить» нет

Связи: сравнение — AWP-50; запись «заменить» — AWP-59; до возврата у
несовпавшей лексемы-кандидата только «перенести», выбора нет

#### AWP-64 Не нужно
Проверка: unit, ручной · Статус: реализовано · Шаг: Ш8

**КОГДА** *пользователь нажимает «Не нужно» у плашки нейронки*, плашка
безвозвратно уходит без записи, остальные плашки слова на месте.

Примеры:
- [1] «run», плашки «бежать», «управлять», «работать», «Не нужно» у
  «управлять» → две плашки: «бежать», «работать»

Границы:
- [2] отмены нет; закрыть окно и сделать новый снимок — плашка вернётся
- [3] два быстрых нажатия «Не нужно» у «управлять» → ушла одна она,
  соседняя на месте
- [4] «Не нужно» у последней плашки → слово уходит из списка (AWP-62)
- [5] у плашки «уже в словаре» тоже «Не нужно»: убирает её, как любую

### Ш9

#### AWP-20 Запись одной лексемы
Проверка: инструментальный, ручной · Статус: реализовано · Шаг: Ш9

**КОГДА** *пользователь нажимает «Создать» или «Перенести» у плашки
нейронки*, её лексема-кандидат записывается одной транзакцией в словарь
снимка: при «Создать» — новое слово с этой лексемой и его членство в
общей или своей группе, при «Перенести» — лексема в выбранное слово, его
группы и сохранённые лексемы не меняются.

Примеры:
- [1] снято: запись по одной лексеме — [9], [10]
- [2] общая «Все», своей группы у плашки нет, «Создать» → слово без
  членства

Границы:
- [3] у «run» плашки глагола и существительного, «Создать» у первой,
  «Перенести» у второй в созданное «run» → одно слово «run» с двумя
  лексемами, у них разная «Часть речи»
- [4] снято: у плашки «уже в словаре» кнопки записи нет (AWP-50.12)
- [5] «Перенести»: старые лексемы слова не меняются и не удаляются
- [6] снято: компонент без значения — AWP-32
- [7] у плашки «bank» своя группа «Finance» при общей «Harry Potter 1»,
  «Создать» → «bank» в «Finance»
- [8] снято: запись по одной лексеме, пачки из окна нет
- [9] «run» — новое слово, плашка «бежать», общая группа «Harry Potter 1»,
  «Создать» → новое слово «run» с одной лексемой, «run» в «Harry Potter
  1»
- [10] «bank» (берег) выбрано в «Куда», общая группа «Harry Potter 1»,
  «Перенести» → у «bank» (берег) новая лексема, группы «bank» как были,
  в «Harry Potter 1» оно не входит
- [11] у «run» две плашки, «Создать» у первой, у второй «Куда»
  переключено назад на «новое слово», «Создать» → два слова «run», по
  лексеме в каждом

Связи: членство — `word_groups`; кнопки — AWP-47; запись «заменить» —
AWP-59; плашки после записи — AWP-63

#### AWP-59 Запись «заменить»
Проверка: инструментальный, ручной · Статус: отложено · Шаг: Ш9

**КОГДА** *«Перенести» пишет лексему-кандидата с «заменить»*, выбранная
сохранённая лексема остаётся той же: присланные компоненты встают на
место её компонентов, остальные компоненты и статистика квизов остаются.

Примеры:
- [1] «заменить» у «управлять», выбрано сохранённое «бежать»,
  «Перенести» → у той же лексемы «Перевод: управлять», статистика квизов
  прежняя

Границы:
- [2] при «заменить» «Пример» заменяется присланными целиком: свои
  примеры сохранённой лексемы уходят
- [3] при «заменить» «Часть речи» сменилась с «существительное» на
  «глагол» → «Род» снят: он зависит от опции (LFL-78.1)
- [4] у сохранённой лексемы своя картинка, у присланной картинки нет →
  картинка остаётся

Связи: выбор «заменить» — AWP-58; запись одной транзакцией — AWP-20; до
возврата присланные лексемы только добавляются, сохранённые не меняются

#### AWP-32 Компоненты лексемы по сопоставлению
Проверка: инструментальный, unit · Статус: реализовано · Шаг: Ш9

**ВСЕГДА** лексема из лексемы-кандидата получает значения компонентов по
сопоставлению с правками пользователя: текстовому компоненту — текст поля,
«Выбору» — опцию, множественному — все оставшиеся значения, значению из
ответа в компоненте шаблона «текст с подписью» — подпись «Wiktionary»;
компонент без значения не создаётся.

Примеры:
- [1] «perro», `ruwiktionary/1.noun.1` (`es-perro.json`), сопоставление
  как в AWP-29.1 → «Перевод» = «собака; пёс (также ругательство)», «Часть
  речи» = опция `noun`, «Род» = опция «м.р.», других компонентов нет
- [2] «corrían», `ruwiktionary/1.verb.3` (`es-corrían.json`) → «Перевод» =
  «течь, литься, струиться (о жидкости)», «Часть речи» = опция `verb`,
  других компонентов нет

Границы:
- [3] «zarpó», `enwiktionary/1.verb.1` (контракт, 2.4) → «Перевод» = «to
  embark; to set sail», «Толкование» = то же, «Часть речи» = опция `verb`
- [4] снято: дубль AWP-16.1
- [5] опция сменена пользователем → ложится новая
- [6] все примеры удалены → «Пример» не создаётся
- [7] текст ядра изменён рукой → в компонент ложится введённый текст
- [8] «Выбор» с признаком «несколько» и двумя строками сопоставления → два
  значения компонента
- [9] «Часть речи» записана опцией: после «отменить» удаления лексемы в
  карточке слова часть речи на месте
- [10] «run», `enwiktionary/1.verb.1` (`en-run.json`), `translations` →
  «Перевод» без «несколько» → одно значение «Перевод» = «бегать,
  побегать, бежать, побежать»; у «Перевода» с «несколько» — четыре
  значения
- [11] «perro», `ruwiktionary/1.noun.1`, «Часть речи» сменена на «глагол»
  (AWP-17.6) → «Род» не пишется
- [12] строка `pronunciations` → «Транскрипция» → «Транскрипция» =
  «/ˈbæŋk/»
- [13] «sister», `ruwiktionary/1.noun.1` (`en-textbook.json`), строка
  `examples` → «Пример» → три значения «Пример» с подписью «Wiktionary»
  в порядке записи, первое «Emily is Sophie's younger sister.»

Связи: сопоставление — LFL-87; опция пишется как `option_id`; «Пример» —
несколько значений у лексемы

#### AWP-63 Плашки словаря после записи
Проверка: unit, ручной · Статус: реализовано · Шаг: Ш9

**КОГДА** *запись лексемы прошла*, плашки словаря под словом
перечитываются из словаря снимка: после «Создать» появляется плашка
нового слова с этой лексемой, после «Перенести» лексема видна в плашке
выбранного слова; у оставшихся плашек нейронки с «Куда: новое слово»
после «Создать» в «Куда» встаёт созданное слово и кнопка становится
«Перенести»; пометки «уже в словаре» пересчитываются.

Примеры:
- [1] новое «run», плашки «бежать» и «управлять», «Создать» у «бежать» →
  под «run» плашка словаря: «Все», сегодняшняя дата, «Перевод: бежать»;
  у «управлять» «Куда: run — бежать», кнопка «Перенести»
- [2] «run» «в словаре» с «бежать», после проверки плашка «управлять»,
  «Перенести» в это «run» → в плашке словаря «run» «Перевод: бежать»,
  «Перевод: управлять»

Границы:
- [3] в словаре «bank» (банк) и «bank» (берег), плашки «банкомёт» с «Куда:
  новое слово» и «набережная» с выбранным «bank» (берег), «Создать» у
  «банкомёт» → третья плашка словаря «bank» с «банкомёт» первой; у
  «набережная» по-прежнему «bank» (берег): явный выбор не переезжает
- [4] после «Перенести» «Куда» остальных плашек не меняется
- [5] после «Создать» у «run» строка «run» в списке получает пометку «в
  словаре» (AWP-39)
- [6] запись не удалась → плашки словаря как были (AWP-21)

Связи: плашки словаря — AWP-46; «Куда» — AWP-18; сравнение — AWP-50;
запись — AWP-20

- [1] «accorc» `not_found` (LFL-50.2) → под словом «Не найдено» и
  «Убрать из списка»

Границы:
- [2] снято: → AWP-61.1
- [3] снято: → AWP-61.2
- [4] снято: → AWP-61.3
- [5] снято: → AWP-61.4
- [6] снято: → AWP-61.5
- [7] слово `found`, `lemmas: []` (LFL-100.2) → «Значений нет», «Убрать
  из списка»
- [8] снято: → AWP-61.6
- [9] снято: → AWP-61.7
- [10] «run» «в словаре», `not_found` → под плашками словаря «Не
  найдено» и «Убрать из списка» (AWP-49.5)

Связи: статусы слова — LFL-50; ошибка и отказ — AWP-61; те же тексты —
в диалоге карточки слова (WCL-11)

#### AWP-61 Ошибка или отказ на слове
Проверка: unit, ручной · Статус: реализовано · Шаг: В4

**ЕСЛИ** *на запрос значений слова сервер ответил ошибкой или отказом*,
**ТО** под словом причина и «Убрать из списка», а при ошибке сети,
сервера или нейронки — ещё и «Повторить».

Примеры:
- [1] 503 `llm_unavailable` (LFL-99) → «Сервер сейчас недоступен,
  попробуй позже», «Повторить» и «Убрать из списка»

Границы:
- [2] сети нет или сервер не ответил (LFL-22, LFL-23) → «Сервер не
  ответил», «Повторить» и «Убрать из списка»
- [3] 429 (LIM-110) → «Лимит на сегодня исчерпан», повтора нет, «Убрать
  из списка» на месте
- [4] 401 (ACC-26) → «Нет доступа к серверу», повтора нет, «Убрать из
  списка» на месте
- [5] слово `error`, `lemmas: []` (LFL-97.2) → «Сервер сейчас недоступен,
  попробуй позже», «Повторить» и «Убрать из списка»
- [6] 400 `unsupported_language` (LFL-30) → «Язык словаря не
  поддерживается», повтора нет: отказ, как по ключу; «Убрать из списка»
  на месте
- [7] «Повторить» → запрос заново, признак загрузки (AWP-57)
- [8] 413 `request_too_large` (LFL-106) → «Слишком много слов», повтора
  нет, «Убрать из списка» на месте

Связи: статусы слова — LFL-50; те же тексты — в диалоге карточки слова
(WCL-11)

### В5

#### AWP-21 Запись не удалась
Проверка: инструментальный, unit · Статус: реализовано · Шаг: Ш9, В5

**ЕСЛИ** *запись отклонена проверкой или завершилась ошибкой*, **ТО** в
словаре нет ни слова, ни лексемы, ни членства из этой попытки, плашка
остаётся как была, кроме выбора, ставшего недействительным, а под
плашкой — «не добавилось» и «Повторить».

Примеры:
- [1] ошибка на последнем значении лексемы → число слов, лексем,
  значений компонентов и членств в группах как до нажатия; плашка на
  месте, под ней «Не добавилось — ничего не записано», «Повторить»

Границы:
- [2] «Повторить» после устранения причины → записано как в AWP-20,
  дублей нет
- [3] общая группа удалена между выбором и записью → отказ до первой
  вставки, ничего не записано, общая группа → «Все», свои группы плашек
  на месте, «Повторить»
- [4] выбранное в «Куда» слово удалено между выбором и записью → отказ
  до первой вставки, ничего не записано, у плашки «Куда» → «новое
  слово», кнопка «Создать»
- [5] своя группа плашки удалена → «как у всех», остальное на месте
- [6] компонент из сопоставления выключен между приходом плашек и
  записью → отказ до первой вставки, его значения у плашек сняты,
  пометки «не попадёт в ядро» пересчитаны
- [7] после отказа плашки словаря как были: словарь не менялся

Связи: AWP-20; отказ до первой вставки — типизированный, с причиной;
сбой после первой записи — откат транзакции

#### AWP-26 Повтор записи
Проверка: unit, ручной · Статус: реализовано · Шаг: В5

**КОГДА** *пользователь нажимает «Повторить» под плашкой*, запись идёт
заново с содержимым плашки после сбросов AWP-21.3–21.6.

Примеры:
- [1] «friendship», плашка «дружба», первая запись упала разовой ошибкой
  транзакции, «Повторить» → в словаре слово «friendship» с лексемой
  «дружба» (`ruwiktionary/1.noun.1`, `en-textbook.json`), строки
  «friendship» в смысловых нет (AWP-62)

Границы:
- [2] закрыть окно из этого состояния → как при закрытии окна (AWP-51,
  AWP-60)

Связи: AWP-21

### В6

#### AWP-27 Перезапуск при открытом окне
Проверка: ручной · Статус: реализовано · Шаг: В6

**ЕСЛИ** *система убила приложение при открытом окне*, **ТО** после
возврата окна нет: добавленные слова в словаре, остальные слова,
удаления и правки потеряны.

Примеры:
- [1] процесс убит при открытом окне после удалений → вкладка «Слова» без
  окна; новый снимок → окно собрано заново из ответа, группа «Все»

Границы:
- [2] процесс убит во время записи → после возврата окна нет, в словаре
  либо лексема со своим словом, либо ничего из этой попытки: одна
  транзакция (AWP-20)
- [3] «friendship» добавлено, «sibling» загружено, процесс убит → после
  возврата «friendship» в словаре, «sibling» нет

Связи: TFP-23

### В7

#### AWP-56 Перезапуск во время ожидания
Проверка: ручной · Статус: реализовано · Шаг: В7

**ЕСЛИ** *система убила приложение во время распознавания или ожидания
ответа*, **ТО** после возврата на вкладке «Слова» нет ни индикатора, ни
окна.

Примеры:
- [1] снято: дубль TFP-23.1

Границы:
- [2] новый снимок после возврата → обычный запуск с начала

Связи: TFP-23

## Ссылки

Ссылки вида `backend/...` ведут в репозиторий сервера lexeme через
симлинк `backend` в корне PolyTrainer (`backend` → `~/dev/lexeme`). В git
его нет: он записан в `.git/info/exclude`. У другого человека рядом с
PolyTrainer должен лежать клон lexeme, а симлинк `backend` на него
создаётся руками. Адреса `LFT-NN`, `LFL-NN`, `TFP-NN`, `ACC-NN` и
`LIM-NN` — тезисы спек `backend/docs/handbook/specs/…`, `WCL-NN` — спеки
диалога в карточке слова `docs/handbook/specs/word-card-lexemes/spec.md`.

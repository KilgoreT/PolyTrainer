# Слово и лексема — доменная модель

Словарь терминов и правил, на которые ссылаются остальные спеки. Без кода:
только сущности, их смысл и поведение. Контракты и детали конструктора —
в [component-constructor/spec.md](../component-constructor/spec.md), порция
тренировки — в [quiz-group-filter/spec.md](../quiz-group-filter/spec.md) §7.1
(до появления спеки квиз-чата).

Документ читается на двух уровнях: §1 — как это выглядит для человека,
который просто учит слова; §2 — полная модель для того, кто строит
собственную структуру словаря. Оба описывают одно и то же.

---

## 1. Для того, кто учит слова

**Словарь** — набор слов одного языка, который ты учишь. Словарей может
быть несколько; внутри словаря слова можно раскладывать по **группам**
(темы, уроки).

**Слово** — то, что ты учишь: «dog». У слова есть **перевод** («собака»).
Может быть **определение** («домашнее животное…»), **пример** («The dog
barks»), **часть речи**. Перевод обязателен по смыслу: слово без перевода
и без определения — ещё не слово, а заготовка.

**Тренировка** показывает тебе перевод (или определение) и просит назвать
слово. Каждое слово в одном раунде спрашивается один раз. Если у слова
есть и перевод, и определение, тренировка может показать любое из них —
это один и тот же вопрос про одно и то же слово, просто с другой стороны.
В меню тренировки можно выбрать, какими сторонами спрашивать.

Больше про устройство знать не нужно. Всё ниже — для тех, кому нужно
больше, чем перевод.

---

## 2. Полная модель

### 2.1. Слово и лексемы

**Слово** — написание («bank»). У слова одна или несколько **лексем** —
значений: «bank» = берег и «bank» = банк — одно слово, две лексемы.
Лексема — единица смысла; именно лексему учат, тренируют и оценивают.
Слово без лексем — пустая оболочка (сценарии карточки слова L5.1).

### 2.2. Компоненты и значения

Лексема описывается **компонентами**. Компонент — это тип поля, заданный
на уровне словаря: «Перевод», «Определение», «Часть речи», «Пример»,
«Ярлык уровня» и любые свои. У каждой лексемы у компонента есть
**значение** (или нет). Компонент отвечает на вопрос «какие поля бывают у
слов этого словаря», значение — «что записано в этом поле у этой лексемы».

Компонент имеет **шаблон** — форму значения: текст, текст с подписью,
выбор из опций; шаблонов может становиться больше (например, картинка).

Набор компонентов — **пословарный**: каждый словарь получает при
создании встроенные «Перевод», «Часть речи», «Пример» и может добавлять
свои, выключать и удалять любые (с одним ограничением, §2.4).

### 2.3. Ядро и атрибуты

Компоненты делятся на два рода по смыслу:

- **Ядро** — то, из чего лексема **состоит**: несёт её смысл и
  идентифицирует его. Перевод — ядро. Определение — ядро. Лексема
  **оформлена**, когда заполнено хотя бы одно ядро; до этого она —
  **черновик**. Ядер может быть несколько, и это разные лица одного
  смысла.
- **Атрибут** — то, что на лексему **навешивается** и сам по себе
  смысла не задаёт: часть речи, пример, ярлык уровня. Атрибуты
  открываются для заполнения, когда лексема оформлена: у заготовки без
  смысла нет и части речи.

Признак «ядро» ставится компоненту в конструкторе словаря. Ядром может
быть только корневой компонент (§2.5). Словарь «только определения»
законен: сделай «Определение» ядром и выключи «Перевод».

### 2.4. Включение и удаление

Любой компонент словаря можно **выключить** (он перестаёт предлагаться
для новых значений, старые значения живут) или **удалить**. Единственный
запрет: нельзя потерять **последнее включённое ядро** словаря — ни
выключить, ни удалить, ни перепривязать. Иначе новым словам нечем
оформиться, словарь мёртв.

### 2.5. Корневые и зависимые компоненты

По устройству (не по смыслу) компоненты бывают:

- **Корневой** — прицеплен к самой лексеме. Все ядра — корневые. Часть
  речи, пример, ярлык — тоже корневые (они атрибуты лексемы).
- **Зависимый** — прицеплен к другому компоненту или к конкретной его
  опции: «Род» доступен только при части речи «существительное».
  Зависимые открываются, когда заполнена/выбрана их цель.

«Корневой» и «ядро» — разные понятия: первое про место в дереве, второе
про смысл. Ядро всегда корневое, корневой не всегда ядро.

### 2.6. Что можно спросить в тренировке

**Вопрос тренировки — это лексема, показанная через одно из своих ядер:**
«вот смысл (перевод / определение), назови слово». Ответ — слово.

- Спрашивать можно **только ядрами**. Атрибуты вопросом не бывают: по
  «существительное» или «A1» слово не угадать. Отдельного свойства «может
  быть вопросом» нет — это и есть ядро.
- Ядро годится в вопрос, если оно **включено**, не удалено и его шаблон
  тренировка **умеет показать**. Сегодня тренировка умеет текст; список
  растёт с новыми рендерами и это свойство тренировки, не домена.
- У лексемы в вопросе используется то ядро, которое у неё **заполнено**.
  Если включённых ядер с заполненным значением несколько — какое
  показать, тренировка выбирает **случайно**. Если ни одного — лексема
  в этот раунд не попадает.
- В раунде лексема встречается **один раз**: показать её переводом и
  отдельно определением — не два вопроса, а один и тот же, поэтому дубли
  запрещены. У одного слова с несколькими лексемами каждая лексема —
  свой вопрос; порция предпочитает разные слова (quiz-group-filter §7.1).
- В меню тренировки пользователь выбирает, **какими ядрами** разрешено
  спрашивать (галки). Если пригодное ядро одно — выбора нет и меню не
  показывается. Минимум одно ядро всегда включено.

## 3. Словарь терминов

| Термин | Что это |
|---|---|
| Словарь | Набор слов одного языка со своим набором компонентов и группами |
| Группа | Подмножество слов словаря (тема, урок); слово может быть в нескольких |
| Слово | Написание; оболочка для лексем |
| Лексема | Значение слова; единица смысла, учёбы и тренировки |
| Компонент | Тип поля лексемы, заданный на уровне словаря |
| Значение | Содержимое компонента у конкретной лексемы |
| Шаблон | Форма значения: текст, текст с подписью, выбор из опций, … |
| Ядро | Компонент, несущий смысл лексемы; оформляет её; может быть вопросом |
| Атрибут | Компонент, навешенный на оформленную лексему; вопросом не бывает |
| Корневой | Компонент, прицепленный к лексеме (все ядра и атрибуты лексемы) |
| Зависимый | Компонент, прицепленный к другому компоненту или его опции |
| Черновик | Лексема без единого заполненного ядра |
| Оформленная | Лексема хотя бы с одним заполненным ядром |
| Вопрос | Лексема, показанная одним из своих ядер; ответ — слово |
| Раунд | Порция тренировки; лексема встречается в нём не более раза |

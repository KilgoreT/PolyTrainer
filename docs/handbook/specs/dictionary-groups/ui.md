# UI Layout — группы словаря

Раскладка двух поверхностей фичи по факту реализации v1 (IS493).
Контракт логики — [spec.md](spec.md).

---

## 🗺 Вкладка «Группы» (host `vocabulary`)

```
Scaffold (host)
├── TabRow: «Слова | Группы»          — верх content, НЕ topBar-слот
├── LazyColumn
│   ├── «Все» (виртуальная, всегда первая, kebab НЕТ)
│   │   ├── строка: имя + счётчик слов словаря
│   │   └── [раскрыта] строки слов (виджет wordrow, как на «Словах»)
│   │       └── «Ещё» (окно +10) / «показано X из Y»
│   ├── Группа × N (алфавит, Collator)
│   │   ├── строка: имя (ellipsis) + счётчик + kebab (⋮)
│   │   │   └── kebab: «Переименовать» | «Удалить»
│   │   └── [раскрыта] слова группы / заглушка «пусто» ПОД строкой
│   └── empty-state + CTA (групп нет)
└── FAB «создать группу»              — скрыт под шторкой/конфирмом
```

- Тап по строке узла — только раскрытие/сворачивание (аккордеон,
  корневые остаются видимы); действия — только через kebab.
- Строки слов read-only: тап → карточка слова.

## 📝 Шторка создания/переименования

`InputBottomSheetWidget` (core/ui): скрим прозрачный, при вводе в
Create-режиме список позади live-фильтруется (видно похожие/дубли);
фильтр работает в обоих режимах. Ошибка валидации — строкой ПОД полем
(снекбар под шторкой и клавиатурой не виден — ручной прогон Э3);
сбрасывается вводом. Submit задизейблен на время записи.

## 🗑 Конфирм удаления (ЕДИНЫЙ диалог, Э6)

`AlarmDialogWidget` + динамика по state:

| Состояние | Текст | Кнопка |
|---|---|---|
| count = 0 | «Удалить группу?» | «Удалить» |
| count ≥ 1, галка снята | `group_delete_words_stay` («В группе слов: N…останутся в словаре») + галка `group_delete_with_words_label` | «Удалить» |
| галка отмечена | `group_delete_with_words_warn` («С группой будут удалены слова: N») | «Удалить всё (5…1)» disabled → «Удалить всё» |

- Деструктивная кнопка: `theme.destructiveColor = 0xFFDC2626`
  (насыщенно-красный; `colorScheme.error` темы — бледно-розовый, НЕ
  подходит), текст `whiteColor`.
- Disabled обязан ВЫГЛЯДЕТЬ неактивным: `dividerColor` фон +
  `grayTextColor` текст (`AlarmButtonWidget` → `LexemeButton`:
  `titleOverride`/`enabled`/`containerColor`).
- Счётчик 5→0 — В НАЗВАНИИ кнопки; тикает effect handler
  (`StartDeleteCountdown`/`DeleteCountdownTick`), не LaunchedEffect.
- Переоткрытие конфирма — галка всегда чистая.

## 🃏 Блок групп карточки слова

```
WordFieldWidget (карточка)
├── Row
│   ├── Column (weight 1): слово; «добавлено» + дата
│   └── флаг словаря (38dp, в конце Row — БЕЗ Box-overlay)
└── чипы групп (wrap; порядок словарного списка)
```

- Иконка `ic_groups` в топбаре (перед kebab) и тап по чипу → пикер.
- Чипы-индикаторы без trailing-иконки: `primary` фон / `onPrimary` текст.

## ☑️ Пикер групп (шторка карточки)

- `containerColor = onPrimary` (фон), имена групп `color = secondary`.
- Плоский LazyColumn (maxHeight 400dp, скроллится от ~20 групп) с
  чекбоксами; отмечено = слово в группе; «Все» в списке НЕТ.
- Тап → запись сразу (без «сохранить»); галочка с летящей записью
  задизейблена (keyed in-flight), остальные живут.
- Пустой словарь групп — заглушка `group_picker_empty`.

## 🎨 Палитра

Правило: новый Compose-виджет — явные цвета парами из прецедента,
никаких M3-дефолтов (три нечитаемых элемента подряд в прогоне Э5).

- Фон шторок/пикера — `onPrimary`; текст — `secondary`.
- Чипы — `primary` / `onPrimary`.
- Деструктив — `destructiveColor` / `whiteColor`.
- Disabled — `dividerColor` / `grayTextColor`.

## 🖼 Иконки

- `ic_groups` — вход в пикер из топбара карточки.
- Kebab строк — общий `iconDropDowned`-паттерн.

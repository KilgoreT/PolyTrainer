# Mate — руководство пользователя

**Mate** — TEA-библиотека для Kotlin: чистый цикл
`Msg × State → (State, Effects)` с гарантиями раннера, декларативными
подписками, навигацией-как-данными и сценарным тест-харнесом, который
гоняет бизнес-логику всего приложения на JVM за миллисекунды.

Это руководство — пошаговая инструкция: как подключить библиотеку к
проекту, собрать первый экран и дойти до сценарных тестов. Читается
по порядку; каждая глава опирается на предыдущие.

## Артефакты

| Артефакт | Что даёт | Кому нужен |
|---|---|---|
| `mate-core` | Раннер, reducer, эффекты, подписки, observer | прод |
| `mate-navigation` | Таблица навигации + единый nav-handler с гейтом | прод |
| `mate-test` | `runMateTest` для юнитов раннера | юнит-тесты |
| `mate-app-test` | Сценарный харнес: стек экранов, DSL, трасса | сценарные тесты |
